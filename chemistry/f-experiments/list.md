## 第1章 基础与装置

### HXF-01　必一、必二实验基础 常用仪器、试剂保存与实验安全（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-01`
清单考点：F1　考法：选择题 ★★
1. 可加热的仪器：直接加热与垫陶土网加热
2. 计量仪器的精度：量筒、托盘天平、滴定管、容量瓶
3. 使用前要检漏的仪器：容量瓶、滴定管、分液漏斗
4. 试剂的保存（一）：见光分解的放棕色瓶（浓硝酸、AgNO₃、氯水）
5. 试剂的保存（二）：碱性溶液不用玻璃塞，HF 不用玻璃瓶，Na 保存在煤油中
6. 实验安全：防倒吸、防暴沸、点燃可燃性气体前验纯
7. 意外事故的处理：酸碱溅到皮肤上、着火
8. 基本操作规范：pH 试纸、检查气密性、焰色试验

### HXF-02　综合 装置图正误判断（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-02`
清单考点：F2　考法：选择题 ★★★（北京卷必有一道看图判断）
1. 判断四步法：试剂 → 装置 → 导管进出 → 条件
2. 气体发生装置：固固加热、固液不加热、固液加热
3. 收集装置：排水法、向上排空气、向下排空气，导管长进短出
4. 洗气与干燥：长进短出，干燥剂的选择
5. 分离装置：过滤、蒸发、蒸馏、分液的常见错误
6. 验证性质的装置：试剂能否达到实验目的
7. 常见陷阱汇总：缺加热、缺尾气处理、试剂选错

## 第2章 制备与分离提纯

### HXF-03　必一 2.2、必二 5.1～5.2 气体的制备、净化与尾气处理（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-03`
清单考点：F3　考法：双考 ★★
1. Cl₂ 的实验室制法：MnO₂ 与浓盐酸加热
2. NH₃ 的实验室制法：NH₄Cl 与 Ca(OH)₂ 加热
3. SO₂、O₂、CO₂ 的实验室制法
4. 除杂顺序：先除杂质气体，后干燥
5. 干燥剂的选择：浓硫酸不能干燥 NH₃，碱石灰不能干燥酸性气体
6. 收集方法的选择：密度与溶解性
7. 尾气处理：吸收、燃烧、收集；防倒吸装置
8. 装置连接顺序：发生 → 净化 → 干燥 → 收集或性质 → 尾气处理

### HXF-04　必一、选必三 1.2 物质的分离与提纯（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-04`
清单考点：F4　考法：双考 ★★★
1. 分离提纯的原则：不增、不减、易分离、易复原
2. 过滤：一贴二低三靠
3. 蒸发结晶与冷却结晶：含结晶水或受热易分解的物质用“蒸发浓缩、冷却结晶”
4. 萃取与分液
5. 蒸馏与分馏
6. 重结晶
7. 沉淀的洗涤与检验洗净（答题模板）
8. 常见物质的除杂（气体、溶液、有机物）

## 第3章 检验与定量

### HXF-05　必一、必二 物质与离子的检验（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-05`
清单考点：F5　考法：双考 ★★★
1. 检验的答题四要素：取样、操作、现象、结论
2. 阳离子检验（一）：Fe³⁺、Fe²⁺
3. 阳离子检验（二）：NH₄⁺、Na⁺、K⁺（焰色试验）
4. 阴离子检验（一）：Cl⁻、SO₄²⁻（先加盐酸排除干扰）
5. 阴离子检验（二）：CO₃²⁻、SO₃²⁻、I⁻
6. 气体检验：Cl₂、SO₂、NH₃、CO₂、O₂、H₂
7. 有机物与 I₂ 的检验：淀粉、醛基、酚羟基、碳碳双键
8. 检验顺序与干扰的排除

### HXF-06　选必一 3.2 定量实验：滴定与纯度计算（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-06`
清单考点：F6　考法：大题 ★★★（流程题与实验题最后一问）
1. 一定物质的量浓度溶液的配制与误差
2. 氧化还原滴定（一）：KMnO₄ 法，自身作指示剂
3. 氧化还原滴定（二）：碘量法，用淀粉作指示剂、Na₂S₂O₃ 滴定
4. 关系式法：找出已知量与待求量的对应关系
5. 纯度与含量的计算：单位换算统一
6. 误差分析：归结到消耗标准液的体积
7. 滴定终点的规范描述

## 第4章 判断与探究

### HXF-07　综合 “操作-现象-结论”判断（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-07`
清单考点：F7　考法：选择题 ★★★
1. 判断三看：操作是否规范、现象是否正确、结论是否唯一
2. 陷阱一：干扰离子没有排除
3. 陷阱二：褪色不一定是漂白（氧化还原、稀释、中和）
4. 陷阱三：沉淀不一定是某种物质
5. 陷阱四：比较实验中变量不唯一（浓度不同、类型不同）
6. 陷阱五：K_sp 比较、酸性比较、氧化性比较的设计是否合理
7. 解题方法：逐项找“还有没有别的可能”

### HXF-08　综合 实验探究（上）：方案设计与控制变量（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-08`
清单考点：F8　考法：大题 ★★★（北京卷压轴大题）
1. 探究题的结构：目的 → 假设 → 实验 → 现象 → 结论 → 反思
2. 读懂探究目的与猜想
3. 控制变量：只改变一个条件
4. 对照实验与空白实验的设计
5. 排除干扰：设计对比实验排除某物质的影响
6. 补全实验方案的答题规范
7. 常见主题：氧化还原能否发生、沉淀与配位的竞争

### HXF-09　综合 实验探究（下）：用原理解释现象（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/f-experiments/projects/hxf-09`
清单考点：F9 F8　考法：大题 ★★★（分值最高的“解释原因”）
1. 解释现象的答题模板：写出平衡或反应 → 浓度变化 → 移动方向 → 现象
2. 用氧化还原能力解释：浓度、酸碱性影响氧化性和还原性
3. 用沉淀溶解平衡解释：沉淀的生成、溶解与转化
4. 用配位平衡解释：颜色变化与沉淀溶解
5. 用速率与限度解释：先出现后消失的现象
6. 用电化学装置验证猜想〔课外，北京卷常考〕
7. 反思与改进：方案的不足与改进措施
