大题答题模板

第一电离能 / 电负性比较

写出两者的价层电子排布 → 指出某一方为半充满或全充满的稳定结构（或核电荷数、原子半径差异）→ 失去一个电子所需能量更大 → 结论。

键角大小比较

中心原子杂化方式相同 → 孤电子对数不同 → 孤电子对对成键电子对的排斥力更大 → 孤电子对越多键角越小。杂化方式不同时先比杂化方式。

熔沸点 / 溶解性解释

先判断晶体类型 → 同类型比作用力（分子晶体看氢键和相对分子质量，离子晶体看离子半径和电荷）→ 作用力越强熔沸点越高。

平衡移动解释

写出存在的平衡 → 指明改变的条件使某浓度或温度怎样变化 → 平衡向哪个方向移动 → 导致观察到的现象或数据变化。

温度对产率"先增后减"

低温段：升温速率加快，未达平衡，产率上升；高温段：反应放热，升温平衡逆移（或催化剂失活、副反应增多），产率下降。

实验探究结论

对比实验 X 与 Y，只有某条件不同 → 现象差异 → 说明该条件影响……；若有干扰，补"排除了……的干扰"。结论要回扣题目的探究目的。

沉淀洗涤与检验洗净

沿玻璃棒向漏斗中加蒸馏水至浸没沉淀，自然流下，重复 2–3 次。取最后一次洗涤液，加入某试剂，若无某现象，则已洗净。

浸出时"提高速率"措施

粉碎增大接触面积、适当升温、适当增大酸的浓度、搅拌。注意"适当"二字，并说明过高的弊端（挥发、分解、副反应）。

怎么用这份清单复习

  1. 先清"双考 ★★★"。点上方"双考"和"只看 ★★★"，这些考点选择题和大题都会碰到，投入产出比最高。
  2. 选择题考点专项刷。切到"选择题爱考"，按题位练：STSE、化学用语、周期律、方程式与事实、有机结构、高分子、实验装置、机理图、电化学、溶液图像、探究型选择。目标是每题 2 分钟内拿下。
  3. 大题按 5 种题型模板化。切到"大题爱考"，每种大题对照上面的映射表，各练一套完整真题，背熟答题模板，重点练"从结构/平衡角度解释"的文字表达。
  4. 用易错点自查。每个考点下的"易错"一行就是丢分点，做错题时对照检查是不是落在这里。
  5. 回到逻辑主线。每个板块开头那条主线是串记忆的线索，复习完一个板块，试着不看清单把主线和其中考点复述一遍。
