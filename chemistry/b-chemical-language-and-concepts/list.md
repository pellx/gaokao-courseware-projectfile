## 第1章 物质及其变化

### HXB-01　必一 1.1（上） 物质的分类（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-01`
清单考点：B1　考法：选择题 ★★（常藏在第 1 题 STSE、传统文化情境里）
1. 分类方法：树状分类法与交叉分类法；同一物质按不同标准可归入不同类别
2. 纯净物与混合物：结晶水合物是纯净物，漂白粉、氨水、玻璃、合金、天然高分子是混合物
3. 氧化物的分类：酸性氧化物与碱性氧化物；金属氧化物不一定是碱性氧化物（Mn₂O₇），非金属氧化物不一定是酸性氧化物（CO、NO）；Na₂O₂ 不是碱性氧化物
4. 酸、碱的分类：几元酸看能电离出的 H⁺ 数，不看分子中的 H 原子数（H₃PO₂ 是一元酸〔课外〕）；含氧酸与无氧酸
5. 盐的分类：正盐、酸式盐、碱式盐；NaH₂PO₂ 是正盐〔课外〕
6. 同素异形体：同种元素形成的不同单质（O₂ 与 O₃，金刚石、石墨与 C₆₀）；相互转化是化学变化
7. 物质分类辨析的解题方法：先看组成（几种物质、几种元素），再看性质，逐个排除“一定”“都是”类说法

### HXB-02　必一 1.1（下） 分散系、胶体与物质的转化（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-02`
清单考点：B1　考法：选择题 ★★
1. 分散系：按分散质粒子直径分为溶液（< 1 nm）、胶体（1～100 nm）、浊液（> 100 nm），本质区别是粒子直径
2. Fe(OH)₃ 胶体的制备：向沸水中滴加饱和 FeCl₃ 溶液，煮沸至红褐色，不能用 NaOH，不能长时间加热
3. 胶体的性质与应用：丁达尔效应（鉴别胶体与溶液）；明矾、铁盐净水（胶体吸附悬浮杂质）；胶粒能透过滤纸、不能透过半透膜〔课外：电泳、聚沉、渗析〕
4. 酸、碱、盐、氧化物的通性与相互转化关系
5. 物质转化的应用：由单质到盐的转化路线、制备物质时选择反应
6. 物理变化与化学变化：焰色试验、蒸馏、分馏、升华、潮解、胶体聚沉是物理变化；干馏、裂化、风化、钝化、同素异形体转化是化学变化
7. 传统文化与科技情境题：从古文中找“变化”“分离方法”“物质成分”，先翻译再判断

### HXB-03　必一 1.2（上） 电解质的电离（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-03`
清单考点：B6（基础）　考法：选择题 ★★
1. 电解质与非电解质：都是化合物；单质和混合物既不是电解质也不是非电解质；CO₂、NH₃、SO₂ 是非电解质
2. 导电的条件：自由移动的离子（溶液、熔融）或自由电子；NaCl 固体不导电，熔融和溶液导电
3. 电离方程式：强电解质用“=”，NaHSO₄ 在水中与熔融时的电离不同，NaHCO₃ 电离出 HCO₃⁻
4. 强电解质与弱电解质初识：强酸、强碱、大多数盐完全电离；弱酸、弱碱、水部分电离〔选必1 详讲〕
5. 溶液导电能力：取决于离子浓度和离子电荷，与电解质强弱无必然关系
6. 导电性曲线：Ba(OH)₂ 溶液中滴加稀硫酸，导电能力先降到接近 0 再升高；滴加 Na₂SO₄ 则几乎不变

### HXB-04　必一 1.2（下） 离子反应与离子共存（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-04`
清单考点：B6 B7　考法：选择题 ★★★（方程式正误）、★（离子共存）
1. 离子反应的实质与发生条件：生成沉淀、气体、水（弱电解质），或发生氧化还原反应
2. 离子方程式的书写：写、拆、删、查
3. 拆分原则：强酸、强碱、可溶性盐拆；弱电解质、沉淀、气体、单质、氧化物不拆；微溶物看状态（澄清石灰水拆，石灰乳不拆）；HCO₃⁻ 不拆开写
4. 离子方程式的意义：表示一类反应；H⁺ + OH⁻ = H₂O 不能表示所有酸碱中和
5. 常见离子的检验：Cl⁻（AgNO₃ + 稀硝酸）、SO₄²⁻（先加盐酸，再加 BaCl₂）、CO₃²⁻
6. 粗盐提纯：除 Ca²⁺、Mg²⁺、SO₄²⁻ 的试剂与顺序（Na₂CO₃ 在 BaCl₂ 之后，盐酸最后加）
7. 离子共存：复分解、氧化还原、双水解〔课外〕、配位（Fe³⁺ 与 SCN⁻）四类不能共存
8. 隐含条件：无色、酸性或碱性、“由水电离的 c(H⁺)”、酸性溶液中的 NO₃⁻ 有强氧化性

### HXB-05　必一 1.3（上） 氧化还原反应的概念与电子转移（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-05`
清单考点：B4　考法：选择题 ★★★，大题贯穿
1. 特征与本质：化合价升降是特征，电子转移（得失或偏移）是本质
2. 与四种基本反应类型的关系：置换反应一定是，复分解反应一定不是，有单质参加的化合反应、有单质生成的分解反应是；有单质参加的反应不一定是（O₂ 转化为 O₃）
3. 化合价的标定：常见元素的化合价；陌生物质（NaH、H₂O₂、Fe₃O₄、Na₂S₂O₃、NaClO₂、K₂FeO₄）
4. 氧化剂、还原剂、氧化产物、还原产物：“升失氧，降得还”
5. 双线桥法：标出变价元素、得失电子数，“得”“失”总数相等
6. 单线桥法：从还原剂中失电子的元素指向氧化剂中得电子的元素，只标转移总数

### HXB-06　必一 1.3（下） 氧化剂、还原剂与氧化还原规律（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-06`
清单考点：B4　考法：双考 ★★★
1. 常见氧化剂与还原剂及其产物（KMnO₄、浓硫酸、硝酸、Cl₂、H₂O₂、Fe³⁺；Fe²⁺、SO₂、I⁻、S²⁻）
2. 价态规律：最高价只有氧化性，最低价只有还原性，中间价两者都有
3. 强弱规律：氧化剂的氧化性 > 氧化产物；由方程式判断强弱，由强弱判断反应能否发生
4. 先后规律：同一氧化剂遇到几种还原剂，先氧化还原性强的（Cl₂ 通入 FeBr₂、FeI₂ 溶液）
5. 歧化与归中：歧化（Cl₂ 与 NaOH）；归中“只靠拢、不交叉”（H₂S 与浓硫酸、KClO₃ 与浓盐酸）
6. 得失电子守恒的计算：找准变价元素，算出每个原子的变化量乘以原子个数
7. 转移电子数的易错计算：Na₂O₂ 与水或 CO₂、Cl₂ 与 NaOH、1 mol Fe 与足量 Cl₂ 或 S 反应

## 第2章 物质的量

### HXB-07　必一 2.3（上） 物质的量、摩尔质量与气体摩尔体积（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-07`
清单考点：B3　考法：大题计算的基础 ★★
1. 物质的量与阿伏加德罗常数：n = N / N<sub>A</sub>；“mol”只用于微观粒子，要指明粒子种类
2. 摩尔质量：数值等于相对分子（原子）质量，单位 g/mol
3. 气体摩尔体积：标准状况下 V<sub>m</sub> = 22.4 L/mol，只适用于气体（标况下 H₂O、SO₃、CCl₄、HF 不是气体）
4. 阿伏加德罗定律：同温同压下，气体体积之比等于物质的量之比；密度之比等于摩尔质量之比
5. 微粒数的计算：分子中原子、质子、电子数；Na₂O₂ 中阴离子是 O₂²⁻；混合物按最简式算
6. 以物质的量为中心的换算网络：m、N、V、c 都先换成 n

### HXB-08　必一 2.3（下） 物质的量浓度与溶液配制（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-08`
清单考点：B3　考法：大题 ★★
1. 物质的量浓度：c = n / V，V 是溶液体积不是溶剂体积；从溶液中取出一部分，浓度不变
2. 浓度换算：c = 1000ρw / M；溶液稀释 c₁V₁ = c₂V₂
3. 配制所需仪器：容量瓶（规格、使用前查漏，不能溶解、不能长期存放），托盘天平或量筒、烧杯、玻璃棒、胶头滴管
4. 配制步骤：计算 → 称量 → 溶解（冷却）→ 转移 → 洗涤 → 定容 → 摇匀；没有 480 mL 容量瓶，按 500 mL 计算
5. 误差分析：看 n 和 V 的变化；定容仰视偏低、俯视偏高；未冷却偏高；未洗涤偏低
6. 物质的量用于化学方程式计算：系数之比等于物质的量之比；“上下单位一致，左右相当”
7. 计算题的规范：设未知数、列比例、带单位

## 第3章 综合

### HXB-09　综合 化学用语正误判断（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-09`
清单考点：B2　考法：选择题 ★★★（北京卷第 2 题前后基本固定一道）
1. 题型：四个选项分别是电子式、结构示意图、模型、核素符号或轨道表示式，逐项挑错
2. 电子式的高频错误：Na₂O₂、NH₄Cl、HClO（O 在中间）、CO₂、N₂、CCl₄（漏写 Cl 的孤电子对）
3. 用电子式表示形成过程：离子化合物要画弯箭头，共价化合物不画；“→”不能写成“=”
4. 结构示意图：原子与离子的区别，核电荷数不变
5. 核素符号：质量数在左上，质子数在左下
6. 球棍模型与空间填充模型：原子相对大小（CO₂ 中 C 比 O 大，CH₄ 中 C 比 H 大）
7. 价层电子排布与轨道表示式、VSEPR 模型的判断（HXA-05、HXA-10 详讲）
8. 结构式、结构简式、键线式：官能团不能省（碳碳双键、醛基 –CHO 不能写成 –COH）

### HXB-10　综合 方程式与事实相符吗（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-10`
清单考点：B6　考法：选择题 ★★★（“下列方程式与所给事实不相符的是”）
1. 题型：一道题覆盖元素化合物、电化学、有机和沉淀转化四类方程式
2. 第一查：反应能不能发生、产物对不对（CO₂ 通入 CaCl₂ 溶液不反应；Fe 与稀硝酸、浓硝酸产物；Fe³⁺ 与 I⁻ 能反应）
3. 第二查：拆分是否正确（弱酸、沉淀、HCO₃⁻）
4. 第三查：原子守恒、电荷守恒、得失电子守恒
5. 量的关系：少量与过量（Ca(HCO₃)₂ 与 NaOH、NaHCO₃ 与 Ca(OH)₂、CO₂ 与 NaOH），“以少定多”的写法
6. 先后顺序：Cl₂ 与 FeBr₂、FeI₂ 不同用量
7. 电化学方程式：电极反应与电解总反应（电解饱和食盐水、铅蓄电池放电）
8. 沉淀转化与水解方程式：AgCl → AgI、Na₂CO₃ 水解分步写、Fe³⁺ 水解制胶体不写“↓”

### HXB-11　综合 陌生氧化还原方程式书写（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-11`
清单考点：B4 B5　考法：大题 ★★★（流程、原理、实验三道大题都会要求写）
1. 四步法：定产物 → 得失电子守恒配主要物质 → 电荷守恒补 H⁺ 或 OH⁻ → 原子守恒补 H₂O
2. 判断产物的常用对应：MnO₄⁻（酸性 Mn²⁺，中性 MnO₂，碱性 MnO₄²⁻）、Cr₂O₇²⁻ → Cr³⁺、H₂O₂ → H₂O 或 O₂、ClO⁻ → Cl⁻、浓硝酸 → NO₂、稀硝酸 → NO
3. 环境决定补什么：酸性溶液中不出现 OH⁻，碱性溶液中不出现 H⁺
4. 从题目信息读产物：流程图箭头、“检测到某气体”“溶液变为某颜色”
5. 歧化与归中方程式：先配产物一侧，再看反应物
6. 有机物参与的氧化还原：用 H 和 O 的变化或平均化合价配平〔课外〕
7. 化学方程式与离子方程式的转换：题目要哪个就写哪个，沉淀、气体符号不漏
8. 典型失分点总结：漏写条件、配错系数、环境写错、把“=”写成“→”

### HXB-12　综合 大题中的定量计算（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/b-chemical-language-and-concepts/projects/hxb-12`
清单考点：B3 B4　考法：大题 ★★（纯度、产率、含量、滴定）
1. 关系式法：多步反应找出起始物与终态物的物质的量关系
2. 得失电子守恒建立关系式：跨越多步、只看始态和终态
3. 原子守恒（元素守恒）：流程中某元素的质量守恒
4. 滴定计算：KMnO₄ 法、碘量法（I₂ 与 S₂O₃²⁻ 按 1:2）、K₂Cr₂O₇ 法；注意“取出 25.00 mL 共 250 mL”的倍数
5. 纯度、产率、质量分数的表达式：用字母表示的结果要化简，单位统一
6. 误差分析：滴定管未润洗、读数仰视俯视、滴定前有气泡等对结果的影响方向
7. 答题规范：写出带字母的表达式，单位换算（mL 换 L）不出错
