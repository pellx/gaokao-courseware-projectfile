## 第1章 钠和氯（必一第二章）

### HXC-01　必一 2.1（上） 钠与钠的氧化物（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-01`
清单考点：C1　考法：选择题 ★★
1. 钠的物理性质与保存：软、银白色、密度比水小比煤油大，保存在煤油中；取用后剩余的钠放回原瓶
2. 钠与 O₂：常温生成 Na₂O，加热生成 Na₂O₂（淡黄色）
3. 钠与水：浮、熔、游、响、红；本质是与 H⁺ 反应；钠与盐溶液先与水反应（钠投入 CuSO₄ 溶液得不到 Cu）
4. Na₂O 与 Na₂O₂ 的比较：颜色、阴阳离子个数比都是 1:2、Na₂O₂ 不是碱性氧化物
5. Na₂O₂ 与 H₂O、CO₂ 的反应：O₂ 的来源、供氧剂；每生成 1 mol O₂ 转移 2 mol 电子
6. Na₂O₂ 的强氧化性与漂白性〔课外：使酚酞先变红后褪色〕

### HXC-02　必一 2.1（下） 碳酸钠与碳酸氢钠、焰色试验（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-02`
清单考点：C1　考法：选择题 ★★，流程题偶考侯氏制碱
1. Na₂CO₃ 与 NaHCO₃ 的性质比较：溶解性、碱性、热稳定性
2. 与盐酸反应：快慢、逐滴加入顺序不同现象不同
3. 鉴别方法：加热、CaCl₂ 溶液、逐滴加盐酸；不能用 Ca(OH)₂ 鉴别
4. 相互转化与除杂：通 CO₂、加 NaOH、加热
5. 侯氏制碱法：先通 NH₃ 再通 CO₂，析出 NaHCO₃，循环利用 CO₂ 和母液
6. 焰色试验：操作（铂丝用盐酸洗净灼烧）、钠黄色、钾紫色透过蓝色钴玻璃；是物理变化
7. 图像题〔课外〕：Na₂CO₃ 与 NaHCO₃ 混合液中滴加盐酸的 CO₂ 体积曲线

### HXC-03　必一 2.2（上） 氯气的性质与次氯酸（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-03`
清单考点：C2　考法：双考 ★★★
1. Cl₂ 的物理性质：黄绿色、有刺激性气味、有毒、能溶于水（1:2）
2. Cl₂ 与金属、H₂ 的反应：与 Fe 生成 FeCl₃（不论用量）；H₂ 在 Cl₂ 中燃烧发出苍白色火焰
3. Cl₂ 与水：可逆反应，HClO 是弱酸；新制氯水的成分（三分子四离子）
4. 氯水的性质：多种成分分别表现性质（酸性、漂白性、氧化性、Cl⁻ 沉淀）；久置氯水变成稀盐酸
5. HClO 的性质：弱酸性（比碳酸弱）、不稳定性（见光分解）、强氧化性与漂白性
6. Cl₂ 与碱：制漂白液（NaClO）和漂白粉（有效成分 Ca(ClO)₂）；漂白粉失效的原理
7. 漂白原理的比较：HClO、Na₂O₂、O₃ 氧化漂白，SO₂ 化合漂白，活性炭吸附

### HXC-04　必一 2.2（下） 氯气的制法与含氯消毒剂（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-04`
清单考点：C2　考法：双考 ★★★
1. 实验室制法：MnO₂ 与浓盐酸加热，浓盐酸变稀后反应停止
2. 装置顺序：发生 → 饱和食盐水除 HCl → 浓硫酸干燥 → 向上排空气收集 → NaOH 溶液吸收尾气
3. 其他制法〔课外〕：KMnO₄、KClO₃、Ca(ClO)₂ 与浓盐酸常温反应
4. Cl⁻ 的检验：先加稀硝酸再加 AgNO₃，排除 CO₃²⁻ 干扰
5. 84 消毒液：有效成分 NaClO，与洁厕灵（含 HCl）混用产生 Cl₂；与 CO₂ 反应生成 HClO
6. ClO₂ 与 NaClO₂：高效消毒剂，等质量时得电子数比 Cl₂ 多〔课外〕
7. 实验探究题中的含氯物质：探究 Cl₂ 与 ClO⁻ 的氧化性、氯水颜色和 pH 变化

## 第2章 铁和金属材料（必一第三章）

### HXC-05　必一 3.1（上） 铁、铁的氧化物与氢氧化物（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-05`
清单考点：C3　考法：选择题 ★★
1. 铁单质：与 Cl₂ 生成 FeCl₃，与 S、I₂ 生成 +2 价化合物；与水蒸气高温反应生成 Fe₃O₄ 和 H₂（装置）
2. 铁与酸：与稀硫酸、盐酸生成 Fe²⁺；常温下遇浓硫酸、浓硝酸钝化（是化学变化）
3. 铁的氧化物：FeO（黑）、Fe₂O₃（红棕，铁红）、Fe₃O₄（黑，磁性）；Fe₃O₄ 与酸生成 Fe²⁺ 和 Fe³⁺
4. Fe(OH)₂ 的制备：白色沉淀 → 灰绿色 → 红褐色；防氧化措施（煮沸除氧、长滴管伸入液面下、油层隔绝）
5. Fe(OH)₃：红褐色，受热分解生成 Fe₂O₃
6. 铁的价-类二维图：0、+2、+3 价物质的位置与转化

### HXC-06　必一 3.1（下） 铁盐和亚铁盐：转化与检验（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-06`
清单考点：C3　考法：双考 ★★★（实验探究题常客）
1. Fe³⁺ 的氧化性：与 Fe、Cu（印刷电路板）、I⁻、SO₂、S²⁻ 反应
2. Fe²⁺ 的还原性：被 Cl₂、H₂O₂、酸性 KMnO₄、HNO₃ 氧化；FeSO₄ 溶液中加铁粉防氧化
3. Fe³⁺ 的检验：KSCN 溶液变红（生成配合物，不是沉淀）
4. Fe²⁺ 的检验：先加 KSCN 无现象再加氯水变红；K₃[Fe(CN)₆] 生成蓝色沉淀；有 Fe³⁺ 时不能用 KSCN 法，用酸性 KMnO₄ 要排除 Cl⁻ 干扰
5. 除杂：FeCl₃ 中的 FeCl₂（通 Cl₂）、FeCl₂ 中的 FeCl₃（加 Fe 粉）、Cu²⁺ 中的 Fe³⁺（调 pH 沉淀）
6. Fe³⁺ 的水解：配制 FeCl₃ 溶液加盐酸；FeCl₃ 溶液蒸干得 Fe(OH)₃
7. 实验探究中的 Fe³⁺ 与 SO₂、I⁻、Ag：先显色后褪色，速率与限度的竞争
8. 答题方法：观察到的颜色对应什么物质（Fe³⁺ 黄、Fe²⁺ 浅绿、Fe(SCN)₃ 红、Fe(OH)₂ 白）

### HXC-07　必一 3.2 金属材料：合金与铝（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-07`
清单考点：C8　考法：选择题 ★
1. 合金的特点：硬度一般比成分金属大，熔点一般比成分金属低；合金是混合物
2. 铁合金：生铁与钢的含碳量；不锈钢
3. 铝与氧化铝：Al 与 NaOH 溶液反应生成 Na[Al(OH)₄] 和 H₂；Al₂O₃ 是两性氧化物；铝制品表面致密氧化膜
4. 新型合金：储氢合金、钛合金、稀土元素
5. 铝的“两性”在流程中的应用：碱溶除铝、调 pH 沉淀 Al(OH)₃〔课外〕
6. 金属与酸反应的计算：等质量 Na、Mg、Al 产生 H₂ 的比较

## 第3章 硫、氮和无机非金属材料（必二第五章）

### HXC-08　必二 5.1（上） 硫与二氧化硫（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-08`
清单考点：C4　考法：双考 ★★★
1. 硫单质：黄色，难溶于水、微溶于酒精、易溶于 CS₂；与 Fe、Cu 生成低价硫化物（FeS、Cu₂S）
2. SO₂ 的酸性氧化物通性：与水、碱、碱性氧化物反应；通入 BaCl₂ 溶液无沉淀
3. SO₂ 的还原性：使酸性 KMnO₄、溴水褪色；与 Fe³⁺、H₂O₂、O₂ 反应
4. SO₂ 的氧化性：与 H₂S 反应生成 S
5. SO₂ 的漂白性：使品红褪色，加热恢复；不能漂白酸碱指示剂；SO₂ 与 Cl₂ 等量混合失去漂白性
6. SO₃：标况下不是气体；工业制硫酸 FeS₂ → SO₂ → SO₃ → H₂SO₄（98.3% 浓硫酸吸收）
7. 易错：SO₂ 使酸性 KMnO₄ 褪色是还原性不是漂白性；鉴别 SO₂ 与 CO₂ 的方法

### HXC-09　必二 5.1（下） 硫酸与含硫物质的转化（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-09`
清单考点：C4　考法：双考 ★★★
1. 浓硫酸的吸水性与脱水性：干燥剂（不能干燥 NH₃、H₂S）；使蔗糖炭化
2. 浓硫酸的强氧化性：与 Cu 加热反应，与 C 反应；常温使 Fe、Al 钝化；随反应变稀后停止
3. 浓硫酸与 Cu 反应的实验与产物检验（SO₂、CuSO₄）〔检验 C 与浓硫酸的产物时先检 H₂O〕
4. SO₄²⁻ 的检验：先加盐酸无现象，再加 BaCl₂；排除 Ag⁺、CO₃²⁻、SO₃²⁻ 干扰
5. 含硫物质的价-类二维图：−2、0、+4、+6 价之间的转化
6. SO₃²⁻ 与 S²⁻ 的还原性；Na₂SO₃ 在空气中变质
7. 硫代硫酸钠 S₂O₃²⁻：遇酸生成 S 和 SO₂；与 I₂ 的滴定反应〔课外〕
8. 实验探究题：SO₂ 与 Fe³⁺、Ag⁺、Cu²⁺ 的反应，产物的检验思路

### HXC-10　必二 5.2（上） 氮气、氮氧化物、氨与铵盐（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-10`
清单考点：C5　考法：双考 ★★★
1. 氮气与氮的固定：N₂ 性质稳定（N≡N 键能大）；自然固氮、人工固氮（合成氨）
2. NO 与 NO₂：NO 无色、与 O₂ 生成 NO₂；NO₂ 红棕色、与水生成 HNO₃ 和 NO
3. 氮氧化物溶于水的计算：4NO₂ + O₂ + 2H₂O、4NO + 3O₂ + 2H₂O 的比例
4. NH₃ 的性质：极易溶于水、喷泉实验原理；氨水显碱性；与 HCl 产生白烟；催化氧化生成 NO
5. NH₃ 的实验室制法：NH₄Cl 与 Ca(OH)₂ 加热；碱石灰干燥（不能用浓硫酸、CaCl₂）；向下排空气法
6. 铵盐的性质：受热易分解（NH₄Cl 分解再化合不是升华）；与碱共热放出 NH₃
7. NH₄⁺ 的检验：加 NaOH 溶液加热，用湿润的红色石蕊试纸检验
8. 喷泉实验的条件与变式：气体极易溶于溶液或能与之反应；HCl、CO₂ 与 NaOH 溶液

### HXC-11　必二 5.2（下） 硝酸、氮循环与环境（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-11`
清单考点：C5　考法：双考 ★★★
1. 硝酸的不稳定性：见光分解，保存在棕色瓶；浓硝酸显黄色的原因
2. 硝酸的强氧化性：与 Cu（浓生成 NO₂，稀生成 NO）；常温使 Fe、Al 钝化；Fe 过量时生成 Fe²⁺
3. 硝酸参与反应的计算：起酸性作用和氧化作用的硝酸；得失电子守恒
4. 工业制硝酸：NH₃ → NO → NO₂ → HNO₃
5. 酸雨：硫酸型与硝酸型，pH < 5.6；防治措施
6. NOₓ 的治理：选择性催化还原（NH₃ 还原 NOₓ）、汽车尾气三元催化
7. 氮循环图：从图中读价态变化、判断是否为氧化还原、找固氮环节

## 第4章 金属冶炼与海水资源（必二第八章）

### HXC-13　必二 8.1 金属冶炼与海水资源（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-13`
清单考点：C8　考法：大题 ★★（流程题最后一步常问冶炼方法）
1. 金属冶炼的本质：金属阳离子得电子被还原
2. 冶炼方法与金属活动性：电解法（K～Al）、热还原法（Zn～Cu）、热分解法（Hg、Ag）
3. 电解法：Na 电解熔融 NaCl，Mg 电解熔融 MgCl₂，Al 电解熔融 Al₂O₃（加冰晶石）；不用 AlCl₃，不用 MgO
4. 热还原法：CO、H₂、C、Al（铝热反应）作还原剂
5. 海水提溴：酸化、Cl₂ 氧化、热空气吹出、SO₂ 吸收、再用 Cl₂ 氧化（富集）
6. 海水提镁：石灰乳沉淀 Mg(OH)₂ → 盐酸溶解 → 在 HCl 气流中加热得无水 MgCl₂ → 电解
7. 海带提碘〔与实验模块共用〕：灼烧、浸泡、过滤、H₂O₂ 氧化、萃取

## 第5章 综合

### HXC-14　综合 陌生过渡金属（上）：铜与银（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-14`
清单考点：C7　考法：大题 ★★★（流程与实验探究的主角）
1. 铜的价态：Cu、Cu₂O（砖红色）、CuO（黑色）；Cu⁺ 在酸性溶液中歧化为 Cu 和 Cu²⁺
2. Cu 与氧化性酸：与浓硫酸、硝酸反应，与 H₂O₂ 和稀硫酸反应
3. Cu²⁺ 的配位：[Cu(NH₃)₄]²⁺（深蓝色）、[CuCl₄]²⁻；CuCl 白色沉淀〔课外〕
4. Ag⁺ 的沉淀：AgCl、AgBr、AgI 的颜色与溶解度顺序；沉淀转化
5. Ag⁺ 的配位：[Ag(NH₃)₂]⁺ 银氨溶液，AgCl 溶于氨水；配位与沉淀的竞争
6. Ag⁺ 的氧化性：与 Fe²⁺ 的可逆反应，Ag 与 Fe³⁺ 的反应（实验探究常客）
7. 解题方法：没学过的物质，先标化合价，再按氧化还原、沉淀、配位三种规律推

### HXC-15　综合 陌生过渡金属（下）：锰、铬、钴、镍（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-15`
清单考点：C7　考法：大题 ★★★
1. 锰的价态：+2（Mn²⁺ 近无色）、+4（MnO₂ 黑色）、+6（MnO₄²⁻ 绿色）、+7（MnO₄⁻ 紫红色）
2. MnO₄⁻ 在不同酸碱性下的还原产物；MnO₂ 的催化与氧化作用
3. 铬：Cr₂O₇²⁻（橙色）与 CrO₄²⁻（黄色）的平衡，加酸加碱的颜色变化；Cr(Ⅵ) 被还原为 Cr³⁺（绿色）
4. 钴与镍：Co²⁺、Ni²⁺ 在流程中的分离（调 pH、萃取）；Co³⁺ 的强氧化性〔课外〕
5. 流程中过渡金属的除杂：先氧化 Fe²⁺ 为 Fe³⁺，再调 pH 沉淀
6. 陌生方程式与颜色信息：从颜色变化推断价态变化
7. 解题方法：价态 → 氧化还原；配体 → 配位平衡；沉淀 → Ksp

### HXC-16　综合 价-类二维图与物质转化（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/c-elements-and-compounds/projects/hxc-16`
清单考点：C1～C8　考法：选择题 ★★（性质与用途对应、物质转化能否实现）
1. 价-类二维图的读法：横轴物质类别、纵轴化合价，同列靠氧化还原，同行靠复分解

4. “物质转化能否一步实现”：S 不能一步到 SO₃，N₂ 不能一步到 NO₂，Fe 与 Cl₂ 不能生成 FeCl₂
