定位：备考与应试。覆盖选必三全部五章和必二第七章中会考的内容；教材中基本不考的阅读栏目不设考点，见文末“未收录的内容”。

考点末尾标〔课外〕的，是教材里没有、但考试常用的内容，讲的时候要说明“课本没有，考试会用”。

## 第1章 结构与研究方法（选必三第一章）

### HXE-01　选必三 1.1（上） 有机物的分类与官能团（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-01`
清单考点：E1　考法：双考 ★★★（有机大题第一问常问官能团名称）
1. 按碳骨架分类：链状、环状；脂环与芳香族
2. 常见官能团（一）：碳碳双键、碳碳三键、碳卤键、羟基
3. 常见官能团（二）：醛基、酮羰基、羧基、酯基
4. 常见官能团（三）：醚键、氨基、酰胺基、硝基
5. 醇与酚的区别：羟基是否直接连在苯环上
6. 名称书写规范：“碳碳双键”不写“双键”，“酮羰基”与“醛基”别混
7. 识别复杂结构中的官能团（新药、天然产物）

### HXE-02　选必三 1.1、2.1 有机物的命名（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-02`
清单考点：E1　考法：双考 ★★★
1. 习惯命名与系统命名；烃基的名称
2. 烷烃的系统命名：选主链、编号、写名称
3. 烯烃、炔烃的命名：主链含不饱和键，编号使其位次最小
4. 醇的命名：主链含连羟基的碳
5. 苯的同系物的命名：邻、间、对与数字编号
6. 含多种官能团物质的命名（醛、羧酸、酯）
7. 易错辨析：“2-乙基丁烷”“3-甲基丁烷”为什么错

### HXE-03　选必三 1.1（下） 有机物的结构特点：共线共面与杂化（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-03`
清单考点：E2　考法：选择题 ★★★
1. 碳原子的成键特点：四价、单双三键、碳链与碳环
2. 碳原子的杂化方式：sp³、sp²、sp
3. σ 键与 π 键的计数
4. 三种基本构型：甲烷四面体、乙烯平面、乙炔直线、苯平面
5. 共面判断：饱和碳原子连的原子不可能全部共面
6. 共线判断：三键两端及其相连原子共线
7. 解题方法：拆成基本构型，单键可以旋转

### HXE-04　选必三 1.1 同分异构体（上）：类型与数目（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-04`
清单考点：E3 E2　考法：双考 ★★★
1. 同分异构体的概念与“四同”辨析（同位素、同素异形体、同系物、同分异构体）
2. 构造异构：碳架异构、位置异构、官能团异构
3. 顺反异构：双键两端碳上各连两个不同基团
4. 手性碳与对映异构
5. 一元取代物数目：等效氢法
6. 二元取代物数目：定一移一
7. 常见的官能团异构：醇与醚、醛与酮、羧酸与酯

### HXE-05　综合 同分异构体（下）：限定条件书写（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-05`
清单考点：E3　考法：大题 ★★★（有机大题必有一问）
1. 不饱和度的计算与应用
2. 条件翻译（一）：能发生银镜反应、能与 NaHCO₃ 反应、遇 FeCl₃ 显紫色
3. 条件翻译（二）：能水解、能与 Na 反应、1 mol 消耗 2 mol NaOH
4. 核磁共振氢谱峰数与峰面积比：用对称性控制
5. 苯环上取代基位置的安排：对位最对称
6. 书写步骤：算不饱和度 → 锁定官能团 → 拼碳骨架 → 调整对称性
7. 甲酸酯与酚酯的特殊性质

### HXE-06　选必三 1.2 研究有机物的方法：分离提纯与波谱（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-06`
清单考点：E13　考法：选择题 ★★
1. 研究有机物的一般步骤
2. 蒸馏：适用条件与装置要点
3. 萃取与分液
4. 重结晶：提纯苯甲酸
5. 确定实验式和分子式：元素分析、质谱测相对分子质量
6. 红外光谱：测化学键和官能团
7. 核磁共振氢谱：氢的种类与个数比

## 第2章 烃（选必三第二章）

### HXE-07　选必三 2.1～2.2 烷烃、烯烃与炔烃（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-07`
清单考点：E4　考法：双考 ★★
1. 烷烃的性质：取代反应、燃烧；同系物的物理性质递变
2. 烯烃的加成反应：与 H₂、X₂、HX、H₂O
3. 不对称加成与 1,3-丁二烯的 1,2-加成和 1,4-加成
4. 烯烃的氧化：使酸性 KMnO₄ 溶液褪色，臭氧氧化断键〔课外信息题常用〕
5. 加聚反应
6. 乙炔的实验室制法与性质
7. 鉴别烷烃与烯烃：溴水、酸性 KMnO₄ 溶液，除杂不能用 KMnO₄

### HXE-08　选必三 2.3 芳香烃（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/chemistry/e-organic-chemistry/projects/hxe-08`
清单考点：E4　考法：双考 ★★
1. 苯的结构：六个碳碳键完全相同，不是单双键交替
2. 苯的取代反应：溴代（FeBr₃）、硝化
3. 苯的加成反应：与 H₂ 加成
4. 溴苯、硝基苯的制备实验要点
5. 苯的同系物：侧链被酸性 KMnO₄ 氧化（与苯环相连的碳上要有氢）
6. 甲苯的取代：光照取代侧链，催化剂取代苯环
7. 苯环与侧链的相互影响

### HXE-10　选必三 3.2 醇与酚（8 个考点）🛠

4. 与新制 Cu(OH)₂ 反应：碱性条件、加热、砖红色沉淀
5. 甲醛的定量关系：1 mol HCHO 生成 4 mol Ag
6. 酮的性质：不能被银氨溶液、新制 Cu(OH)₂ 氧化
7. 醛基的检验与碳碳双键的区分

### HXE-12　选必三 3.4 羧酸、酯与酰胺（8 个考点）🛠

4. 酯的水解：酸性可逆，碱性彻底

6. 油脂：结构、皂化反应、氢化
7. 胺与酰胺：酰胺的水解
8. 甲酸及甲酸酯：能发生银镜反应
