# 生物、化学讲解视频对课标知识点的覆盖统计

统计日期：2026-11-22。对照依据：《普通高中生物学课程标准日常修订版（2017年版2025年修订）》《普通高中化学课程标准日常修订版（2017年版2025年修订）》（本目录下的 `sw.pdf`、`hx.pdf`）中必修和选择性必修的“内容要求”，以及化学的“学生必做实验”、生物“教学提示”中要求开展的实验和活动。视频一侧是各系列 `list.md` 中的全部考点（生物 104 期 732 个，化学 102 期 737 个）。

## 一、结论

- **生物**：课标 120 条内容要求，完整覆盖 119 条，部分覆盖 1 条，没有覆盖的 0 条。课标要求的 47 项实验和活动里，完整覆盖 43 项，部分 3 项，没有 1 项。**知识点层面基本全覆盖。**
- **化学**：课标 139 条内容要求中，可直接命题的知识类 121 条，完整覆盖 121 条，部分覆盖 0 条，没有覆盖 0 条；另有态度、价值、观念类（“素养类”）18 条，不设考点是正常的。18 个学生必做实验全部覆盖。**知识类要求已全部覆盖**：2026-11-22 把原先 13 条部分覆盖或没有覆盖的内容补进了 10 期现有视频（不增减期数和考点数，考得少的内容用一两句带过），见第五节。
- **但“知识点覆盖”不等于“能应对全部高考题”**。生物系列只有按课本小节分的期，没有跨章节的综合题型期（遗传大题、实验设计、光合呼吸综合等），而化学有 21 期综合/题型期、44 个〔课外〕考点（课本没有、考试常用）。生物在“题型和解题方法”这一层还有明显空间。

## 二、现在还有“高考考纲”吗

没有了。新高考省份从 2020 年前后起不再制定考试大纲，命题直接以课程标准为依据：

- 国务院办公厅《关于新时代推进普通高中育人方式改革的指导意见》（国办发〔2019〕29号）：“学业水平选择性考试与高等学校招生全国统一考试命题要以普通高中课程标准和高校人才选拔要求为依据，实施普通高中新课程的省份不再制定考试大纲。”（https://www.gov.cn/zhengce/content/2019-06/19/content_5401568.htm）
- 北京市教委《北京市普通高中学业水平考试实施办法》（京教计〔2024〕43号，现行有效）：“等级性考试内容以普通高中课程标准中的必修课程和选择性必修课程要求为依据。”（https://jw.beijing.gov.cn/xxgk/2024zcwj/2024xzgfwj/202409/t20240920_3902305.html）

所以第六、七节列出的课标“内容要求”，就是现在官方意义上的高考知识点范围。

**版本说明**：本统计以 2025 年日常修订版为准，并已与教育部 2020 修订版原件（教材〔2020〕3号附件）逐条比对，变化见第四节。

## 八、方法与局限

- 课标条目从教育部附件 PDF 原文提取；对照是逐条阅读课标和各期考点后人工判断的，不是关键词匹配。“完整”表示有专门的考点讲到这条要求的核心内容，“部分”表示只带到或只讲了其中一部分。
- 统计的是“有没有讲到”，不衡量讲得深不深、例题够不够。
- 化学清单按北京卷编排，会把北京卷基本不考的内容压缩或不收；生物清单没有标明地区，按人教版课本编排。
- 课标之外、考试常用的内容（如化学的〔课外〕考点、晶胞投影、分布系数图）不在本表统计范围内，它们是视频比课标多出来的部分。
