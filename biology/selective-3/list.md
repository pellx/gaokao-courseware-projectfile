## 第1章 发酵工程

### XB3-01　1.1 传统发酵技术的应用（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-01`
1. 发酵与传统发酵技术：利用天然存在的菌种，固体或半固体发酵，混合菌种
2. 腐乳、酱等传统发酵食品：毛霉等产生蛋白酶和脂肪酶
3. 泡菜的制作：乳酸菌、无氧条件、盐水浓度与煮沸冷却
4. 泡菜发酵中乳酸菌、乳酸和亚硝酸盐含量的变化曲线
5. 果酒的制作：酵母菌、18～30 ℃、先通气后密封、排气
6. 果醋的制作：醋酸菌、30～35 ℃、持续通氧，两条反应途径
7. 果酒与果醋制作的比较与装置分析（充气口、排气口、出料口）
8. 发酵结果的检测：酸性重铬酸钾检测酒精，pH 与气味判断醋酸

### XB3-02　1.2（上） 微生物的纯培养（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-02`
1. 培养基的概念与基本成分：水、碳源、氮源、无机盐，特殊营养物质
2. 培养基的类型：液体与固体（琼脂），按用途分
3. 无菌技术：消毒与灭菌的区别
4. 常用灭菌方法：湿热（高压蒸汽）、干热、灼烧，对象的对应
5. 微生物纯培养的步骤：配制培养基 → 灭菌 → 倒平板 → 接种 → 培养
6. 倒平板的操作与平板倒置的原因
7. 平板划线法：接种环灼烧的次数和目的、划线顺序
8. 实验：酵母菌的纯培养与菌落特征

### XB3-03　1.2（下） 微生物的选择培养和计数（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-03`
1. 选择培养基：允许特定微生物生长、抑制其他微生物
2. 实例：以尿素为唯一氮源分离分解尿素的细菌
3. 稀释涂布平板法：梯度稀释与涂布操作
4. 菌落计数：选菌落数 30～300 的平板，计算公式
5. 计数结果偏小的原因：两个或多个细胞连在一起形成一个菌落
6. 显微镜直接计数法及其与活菌计数的比较
7. 对照的设置：未接种的空白平板、牛肉膏蛋白胨培养基对照
8. 鉴定分解尿素的细菌：酚红指示剂变红

### XB3-04　1.3 发酵工程及其应用（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-04`
1. 发酵工程的概念与特点
2. 基本环节：选育菌种 → 扩大培养 → 配制培养基 → 灭菌 → 接种 → 发酵罐内发酵 → 分离提纯
3. 菌种选育的方法：自然界筛选、诱变育种、基因工程育种
4. 发酵过程的控制：温度、pH、溶解氧，及时添加营养
5. 产品的分离与提纯：菌体本身用过滤沉淀，代谢物用提取分离
6. 发酵工程在食品工业中的应用：啤酒、酱油、柠檬酸、单细胞蛋白
7. 发酵工程在医药、农牧业上的应用：抗生素、微生物肥料、微生物农药、饲料

## 第2章 细胞工程

### XB3-05　2.1（上） 植物细胞工程的基本技术（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-05`
1. 细胞工程的概念与植物细胞的全能性
2. 植物组织培养的过程：外植体 → 脱分化 → 愈伤组织 → 再分化 → 植株
3. 组织培养的条件：无菌、营养、激素（生长素与细胞分裂素的比例）、光照
4. 实验：菊花的组织培养（消毒、接种、转接、移栽）
5. 植物体细胞杂交：去壁（纤维素酶和果胶酶）获得原生质体
6. 原生质体融合的方法与融合成功的标志（再生出细胞壁）
7. 杂种植株的染色体数目与可育性
8. 植物体细胞杂交的意义：打破生殖隔离，实现远缘杂交育种

### XB3-06　2.1（下） 植物细胞工程的应用（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-06`
1. 快速繁殖（微型繁殖）：保持优良品种的遗传特性
2. 作物脱毒：取茎尖等分生区组织培养（易错：脱毒不等于抗毒）
3. 单倍体育种：花药离体培养 + 秋水仙素处理
4. 突变体的利用：愈伤组织易受诱变
5. 细胞产物的工厂化生产：植物细胞培养（如紫杉醇）
6. 各种应用的比较：是否需要培养成完整植株

### XB3-07　2.2（一） 动物细胞培养（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-3/projects/xb3-07`
1. 动物细胞工程的技术组成，动物细胞培养是基础
2. 培养条件：营养（加血清）、无菌无毒、温度 pH 渗透压、95% 空气 + 5% CO2
3. 培养过程：胰蛋白酶处理 → 原代培养 → 传代培养
4. 细胞贴壁与接触抑制
5. 干细胞的类型：胚胎干细胞、成体干细胞、诱导多能干细胞（iPS 细胞）
6. 干细胞的应用前景
7. 易错：动物细胞培养不能体现细胞全能性，培养的结果是细胞群而不是个体

3. 单克隆抗体的制备流程
4. 两次筛选：选择培养基筛出杂交瘤细胞，抗体检测筛出能产生特定抗体的细胞
5. 杂交瘤细胞的特点：既能无限增殖，又能产生特定抗体

### XB3-09　2.2（三） 动物体细胞核移植技术和克隆动物（6 个考点）🛠

3. 为什么用 MⅡ 期卵母细胞作受体
4. 克隆动物的遗传物质来源（核基因来自供体，细胞质基因来自受体）
