## 第1章 走近细胞

### BX1-01　1.1 细胞是生命活动的基本单位（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-01`
1. 细胞学说的建立过程：维萨里、比夏、胡克、列文虎克、施莱登和施旺、魏尔肖
2. 细胞学说的主要内容，以及“细胞通过分裂产生新细胞”的修正和补充
3. 细胞学说的意义：揭示动物和植物的统一性，从而阐明生物界的统一性（未涉及多样性）
4. 科学方法：完全归纳法与不完全归纳法
5. 生命活动离不开细胞：单细胞生物、多细胞生物和病毒
6. 生命系统的结构层次：细胞是最基本的生命系统，植物没有“系统”层次

### BX1-02　1.2 细胞的多样性和统一性（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-02`
1. 高倍显微镜的使用步骤：低倍镜找到 → 移到视野中央 → 换高倍镜 → 调细准焦螺旋和光圈
2. 显微镜成像特点：放大的倒像，“偏哪移哪”，放大倍数指长度或宽度

4. 原核细胞与真核细胞的根本区别：有无以核膜为界限的细胞核
5. 常见原核生物：细菌、蓝细菌（含藻蓝素和叶绿素，能光合作用）、支原体
6. 原核细胞与真核细胞的统一性：细胞膜、细胞质、核糖体、DNA
7. 易混生物辨析：酵母菌、霉菌是真核生物；带“菌”字的不一定是细菌；病毒不属于原核生物

## 第2章 组成细胞的分子

### BX1-03　2.1 细胞中的元素和化合物（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-03`
1. 生物界与非生物界的统一性（元素种类）和差异性（元素含量）
2. 大量元素与微量元素（Fe、Mn、Zn、Cu、B、Mo）
3. C 是最基本的元素；鲜重中 O 最多，干重中 C 最多
4. 细胞中的化合物：水含量最多，蛋白质是含量最多的有机化合物
5. 检测还原糖：斐林试剂现配现用、50～65 ℃水浴加热、砖红色沉淀，材料的选择
6. 检测脂肪：苏丹Ⅲ染液染成橘黄色，体积分数 50% 的酒精洗去浮色
7. 检测蛋白质：双缩脲试剂先加 A 液再加 B 液，与斐林试剂的比较

### BX1-04　2.2 细胞中的无机物（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-04`
1. 水的含量特点：不同生物、不同器官、不同发育时期的差异
2. 水是良好的溶剂：极性分子、氢键与比热容较高
3. 自由水与结合水的存在形式和功能
4. 自由水与结合水的比值与代谢、抗逆性的关系
5. 无机盐的存在形式与功能（一）：组成复杂化合物（Fe、Mg、I、P）
6. 无机盐的功能（二）：维持生命活动（血钙低会抽搐）、维持渗透压和酸碱平衡
7. 实验设计：验证某种无机盐是植物生长所必需的（完全培养液 vs 缺素培养液，再补充）

### BX1-05　2.3 细胞中的糖类和脂质（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-05`
1. 糖类的元素组成与功能：主要的能源物质
2. 单糖：葡萄糖、果糖、半乳糖、核糖、脱氧核糖
3. 二糖：蔗糖、麦芽糖、乳糖及其水解产物
4. 多糖：淀粉、糖原、纤维素、几丁质
5. 脂质的种类与功能：脂肪、磷脂、固醇（胆固醇、性激素、维生素 D）
6. 脂肪的组成：甘油 + 脂肪酸，饱和脂肪酸与不饱和脂肪酸
7. 糖类与脂肪的比较：脂肪含 H 多、含 O 少，氧化分解耗氧多、释放能量多
8. 糖类和脂质的相互转化：糖类可大量转化为脂肪，脂肪不能大量转化为糖类

### BX1-06　2.4 蛋白质是生命活动的主要承担者（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-06`
1. 蛋白质的功能：结构、催化、运输、信息传递（调节）、免疫
2. 氨基酸的结构通式与判断：至少一个氨基和一个羧基连在同一个碳原子上
3. 组成蛋白质的 21 种氨基酸：必需氨基酸与非必需氨基酸
4. 脱水缩合与肽键：水中的 H 来自氨基和羧基，O 来自羧基
5. 计算（一）：肽键数 = 脱去水分子数 = 氨基酸数 − 肽链数，蛋白质相对分子质量
6. 计算（二）：游离的氨基和羧基数目，N、O 原子数目
7. 蛋白质结构多样性的原因：氨基酸种类、数目、排列顺序，肽链盘曲折叠方式及空间结构
8. 蛋白质变性：空间结构被破坏，肽键不断裂，仍能与双缩脲试剂反应

### BX1-07　2.5 核酸是遗传信息的携带者（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/required-1/projects/bx1-07`
1. 核酸的种类与分布：DNA 主要在细胞核，RNA 主要在细胞质
2. 核苷酸的组成：一分子磷酸 + 一分子五碳糖 + 一分子含氮碱基
3. DNA 与 RNA 的比较：脱氧核糖与核糖，T 与 U
4. 不同生物所含核酸、核苷酸、碱基的种类数
5. 遗传物质：细胞生物都是 DNA，病毒是 DNA 或 RNA
6. 核酸的功能：核苷酸的排列顺序储存遗传信息
7. 生物大分子以碳链为骨架：单体与多聚体的对应
