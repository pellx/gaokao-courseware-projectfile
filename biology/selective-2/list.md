## 第1章 种群及其动态

### XB2-01　1.1 种群的数量特征（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-01`
1. 种群的概念与种群密度（最基本的数量特征）
2. 样方法：适用对象、随机取样、五点取样法与等距取样法、“计上不计下，计左不计右”
3. 标记重捕法：适用对象、N = M·n/m、标记物脱落等误差分析
4. 其他调查方法：逐个计数、黑光灯诱捕、红外触发相机、粪便与声音计数
5. 出生率和死亡率、迁入率和迁出率：直接决定种群密度
6. 年龄结构：增长型、稳定型、衰退型，预测数量变化趋势
7. 性别比例：影响出生率（性引诱剂诱杀雄虫）
8. 种群各数量特征之间的关系（概念图）

### XB2-02　1.2 种群数量的变化（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-02`
1. 建构种群增长模型的方法：数学模型（观察 → 假设 → 数学表达 → 检验修正）
2. “J”形增长：理想条件、Nt = N0·λ^t、λ 的含义
3. “S”形增长：环境阻力与环境容纳量（K 值）
4. 增长速率曲线：K/2 时增长速率最大
5. K 值与 K/2 的应用：渔业捕捞、有害生物防治
6. 种群数量的波动和下降
7. 探究：培养液中酵母菌种群数量的变化（血细胞计数板、先盖盖玻片再滴培养液、振荡摇匀、计数原则）
8. 易错：λ 曲线与增长率曲线的判读

### XB2-03　1.3 影响种群数量变化的因素（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-03`
1. 非生物因素：阳光、温度、水等，往往是综合作用
2. 生物因素：种群内部（种内竞争）与种群外部（捕食、竞争、寄生等）
3. 密度制约因素与非密度制约因素
4. 捕食者与被捕食者数量变化曲线（猞猁与雪兔，先增先减者为被捕食者）
5. 种群研究的应用：濒危动物保护
6. 种群研究的应用：有害生物防治与渔业资源合理利用

## 第2章 群落及其演替

### XB2-04　2.1 群落的结构（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-04`
1. 群落的概念与物种组成：物种丰富度，区别不同群落的重要特征
2. 优势种
3. 种间关系：原始合作、互利共生、种间竞争、捕食、寄生
4. 种间关系曲线的判读
5. 群落的空间结构：垂直结构（植物分层与光照，动物分层与栖息空间和食物）与水平结构
6. 群落的季节性
7. 生态位：研究内容、形成原因与意义
8. 探究：土壤中小动物类群丰富度的研究（取样器取样法、记名计算法与目测估计法、诱虫器）

### XB2-05　2.2 群落的主要类型（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-05`
1. 群落类型的划分依据：外貌和物种组成
2. 荒漠生物群落：生物的耐旱特点
3. 草原生物群落：耐寒旱生草本植物，动物善于挖洞或奔跑
4. 森林生物群落：分层明显，树栖、攀缘动物多
5. 湿地生物群落与海洋生物群落
6. 群落中的生物适应环境：结构与功能相适应

### XB2-06　2.3 群落的演替（7 个考点）🛠

2. 初生演替：裸岩上的演替阶段（地衣 → 苔藓 → 草本 → 灌木 → 乔木）
3. 次生演替：弃耕农田上的演替
4. 初生演替与次生演替的比较（起点、时间、影响因素）
5. 演替的趋势与结果：能否演替到森林取决于气候等条件
6. 人类活动对群落演替的影响：改变演替的速度和方向
7. 退耕还林、还草、还湖

## 第3章 生态系统及其稳定性

### XB2-07　3.1 生态系统的结构（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-07`
1. 生态系统的概念与范围（生物圈是最大的生态系统）
2. 组成成分：非生物的物质和能量、生产者、消费者、分解者
3. 成分判断的易错：细菌、动物、植物不都对应同一成分
4. 各组成成分之间的关系
5. 食物链：起点为生产者、营养级、不含分解者
6. 食物网：同一生物可占不同营养级，种间关系可能既有捕食又有竞争
7. 食物网中生物数量变化的分析

### XB2-08　3.2（上） 生态系统的能量流动（上）：过程和特点（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-08`
1. 能量流动的概念：输入、传递、转化和散失
2. 能量流经第一营养级
3. 能量流经第二营养级：摄入量 = 同化量 + 粪便量
4. 同化量的去向：呼吸作用散失、用于生长发育和繁殖（流向下一营养级、流向分解者、未利用）
5. 赛达伯格湖的能量流动定量分析
6. 能量流动的特点：单向流动、逐级递减，相邻营养级传递效率约 10%～20%
7. 生态金字塔：能量金字塔、数量金字塔、生物量金字塔

### XB2-09　3.2（下） 生态系统的能量流动（下）：相关计算与实践意义（6 个考点）🛠
工程：`~/gaokao-courseware-projectfile/biology/selective-2/projects/xb2-09`
1. 传递效率的计算：相邻两个营养级同化量之比
2. 已知最高营养级增重，求至少 / 最多消耗生产者（最短链 × 20%，最长链 × 10%）
3. 食物网中按比例分配的能量计算
4. 能量流动模型图中各字母的关系
5. 研究意义一、二：合理配置以增大流入的总能量（间作套种），科学设计人工生态系统以提高能量利用率（秸秆、粪便多级利用）
6. 研究意义三：合理调整能量流动关系，使能量持续高效地流向对人类最有益的部分（除草灭虫、合理载畜量；易错：不能提高传递效率）

### XB2-10　3.3 生态系统的物质循环（7 个考点）🛠

2. 碳循环：在生物群落与非生物环境之间以 CO2 形式，在群落内部以含碳有机物形式
3. 碳循环图解的判断（双向箭头连接生产者与大气中的 CO2 库）
4. 温室效应与碳中和
5. 生物富集：概念、营养级越高浓度越高、具有全球性
6. 能量流动与物质循环的关系
7. 探究：土壤微生物的分解作用（实验组土壤 60 ℃ 处理，对照与变量）
