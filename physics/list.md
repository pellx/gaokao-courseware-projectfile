**分篇依据**
1. **力学（WLA）**：运动的描述 → 相互作用 → 牛顿运动定律 → 曲线运动与万有引力 → 能量与动量 → 机械振动。
   - 必修一、必修二和选择性必修一的动量、机械振动都以“力和运动”为核心，合成一篇。
   - 功和能、动量排在一起：动能定理与动量定理、机械能守恒与动量守恒前后对照。
   - 机械振动要用到回复力和机械能，放在力学最后。
2. **电学基础（WLB）**：静电场 → 恒定电流 → 磁场 → 带电粒子在电场和磁场中的运动 → 电磁感应 → 交变电流与传感器。
   - 必修三的静电场、电路、磁场初步，与选择性必修二的安培力、洛伦兹力、电磁感应、交变电流合成一篇。
   - 必修三 13.1～13.3 并入磁场和电磁感应的相应期。
   - “带电粒子在电场中的运动”与“在磁场中的运动”、质谱仪和回旋加速器排在一起，便于对照两种场对带电粒子的作用。
3. **波动与光（WLC）**：机械波 → 光的折射与全反射 → 光的干涉、衍射和偏振 → 电磁振荡与电磁波。
   - 机械波、光和电磁波都是波，合成一篇。
   - 光的干涉、衍射紧跟机械波的干涉、衍射。
   - 最后讲电磁振荡和电磁波，落到“光是一种电磁波”。电磁振荡要用到电学篇的电容器和自感。
4. **热学（WLD）**：分子动理论 → 气体 → 固体和液体 → 热力学定律与能源。必修三 12.4“能源与可持续发展”并入热力学第二定律一期。
5. **近代物理（WLE）**：相对论时空观 → 能量量子化 → 光电效应与波粒二象性 → 原子结构 → 原子核。必修二 7.5（相对论）和必修三 13.5（能量量子化）并入本篇。
6. **实验（WLF）**：一个实验一期，共 21 期，前面加一期“实验基础：误差和有效数字”。按类型分组：测量基础 → 力学实验 → 电学实验 → 光学实验 → 热学实验。
   - 前面各篇的知识期不讲实验，实验的原理、步骤、数据处理和误差都只在本篇讲。
   - 每期标题下写了要先学的知识期。

**学习顺序**
- 按篇的顺序学，就能保证先修在前。
- 可以调整的地方：
  - 热学（WLD）只用到力学，可以提前到力学之后。
  - 实验篇的各期可以在对应的知识期学完后穿插着学，先修期写在每期标题下。

## 篇A（WLA）力学：运动的描述、相互作用与牛顿运动定律、曲线运动与万有引力、能量与动量、机械振动

**A1 运动的描述**（WLA-01～WLA-05）

### WLA-01　必一 1.1、1.2 质点、参考系、时间与位移（8 个考点）⬜
先修：—（系列起点）
1. 物理学的研究方法：实验与科学推理相结合；突出主要因素、忽略次要因素，建立理想化的物理模型
2. 质点：用来代替物体的有质量的点，是理想化模型；能否看成质点取决于物体的大小和形状对所研究的问题影响能否忽略
3. 参考系：描述运动时选来作为参考的物体；选不同的参考系，对同一运动的描述可能不同；通常选地面
4. 坐标系：为了定量描述物体的位置及其变化，在参考系上建立坐标系；直线运动用一维坐标轴
5. 时刻与时间间隔：在时间轴上分别对应点和线段；“第 3 s 末”是时刻，“第 3 s 内”“前 3 s”是时间间隔
6. 位移与路程：位移是由初位置指向末位置的有向线段，是矢量；路程是轨迹的长度，是标量；只有单向直线运动中位移大小才等于路程
7. 矢量与标量：矢量既有大小又有方向，标量只有大小；直线运动中矢量的正负表示方向，不表示大小
8. 直线运动的位置和位移：位移 Δx = x2 − x1；位移—时间图像（x-t 图像）表示位置随时间的变化，不是运动轨迹（→ WLA-05）

### WLA-02　必一 1.3、1.4 速度与加速度（8 个考点）⬜
先修：WLA-01
1. 速度 v = Δx/Δt：用位移与时间之比定义（比值定义法）；单位 m/s；速度是矢量，方向就是物体运动的方向
2. 平均速度与瞬时速度：平均速度对应一段时间或一段位移；Δt 非常小时的平均速度可以看作瞬时速度（极限思想）
3. 速率：瞬时速度的大小叫速率；平均速率 = 路程/时间，一般不等于平均速度的大小
4. 速度—时间图像（v-t 图像）：直观表示速度随时间的变化；匀速直线运动的 v-t 图像是平行于时间轴的直线
5. 加速度 a = Δv/Δt：描述速度变化的快慢，即速度的变化率；单位 m/s²；是矢量
6. 加速度的方向：与速度变化量 Δv 的方向相同；直线运动中 a 与 v 同向时加速，反向时减速
7. 从 v-t 图像看加速度：图线的斜率表示加速度；图线是曲线时，某点切线的斜率表示该时刻的加速度（→ WLA-05）
8. 概念辨析：速度、速度变化量、加速度三者没有必然联系；速度很大时加速度可以为 0，速度为 0 时加速度可以不为 0

### WLA-03　必一 2.2、2.3 匀变速直线运动的规律（8 个考点）⬜
先修：WLA-02
1. 匀变速直线运动：沿着一条直线且加速度不变的运动；v-t 图像是一条倾斜的直线；分为匀加速和匀减速
2. 速度与时间的关系 v = v0 + at：由加速度的定义式变形得到
3. 位移与时间的关系 x = v0t + ½at²：由 v-t 图线与时间轴所围的面积得出（把过程无限细分再累加的微元思想）
4. 速度与位移的关系 v² − v0² = 2ax：由前两式消去时间 t 得到
5. 公式的矢量性：v0、v、a、x 都是矢量，使用前先规定正方向（通常取 v0 的方向），结果的正负表示方向
6. 平均速度：匀变速直线运动中，一段时间内的平均速度等于 (v0 + v)/2，也等于这段时间中间时刻的瞬时速度
7. 连续相等时间 T 内的位移之差是恒量：Δx = aT²，是判断物体是否做匀变速直线运动的依据
8. 初速度为 0 的匀加速直线运动：v 与 t 成正比，x 与 t² 成正比

### WLA-04　必一 2.4 自由落体运动与竖直上抛运动（9 个考点）⬜
先修：WLA-03
1. 亚里士多德的观点：重的物体下落得快；伽利略用逻辑推理（轻、重两物体绑在一起下落）指出其中的矛盾
2. 自由落体运动：物体只在重力作用下从静止开始下落的运动；空气阻力可以忽略时，物体的下落可近似看作自由落体运动
3. 运动性质：自由落体运动是初速度为 0 的匀加速直线运动（可用频闪照相或打点计时器研究）；同一地点轻重物体下落一样快
4. 自由落体加速度 g：方向竖直向下；同一地点一切物体的 g 相同；不同地点一般不同，随纬度升高而增大；一般取 9.8 m/s²
5. 自由落体运动的规律：v = gt，h = ½gt²，v² = 2gh；匀变速直线运动的规律和推论都适用
6. 伽利略的研究过程：猜想 v 与 t 成正比 → 数学推理得 x 与 t² 成正比 → 用斜面“冲淡”重力验证 → 合理外推到竖直下落
7. 伽利略的科学方法：把实验和逻辑推理（包括数学推演）和谐地结合起来，开创了近代物理学的研究方法；近代实验科学由此兴起，研究自然从思辨转向实验和测量
8. 竖直上抛运动（教材正文未单列，按匀变速直线运动的规律理解）：只受重力，全程加速度为 g；取向上为正，v = v0 − gt，h = v0t − ½gt²
9. 竖直上抛的对称性：上升和下降经过同一位置时速度大小相等、方向相反，上升与下降时间相等

### WLA-05　必一 第1、2章 运动图像（8 个考点）⬜
先修：WLA-02、WLA-03
1. 图像中的物理量：坐标轴表示的物理量和单位，以及图线的斜率、面积、截距、交点，各有确定的物理意义
2. x-t 图像的斜率：表示速度；静止时图线平行于时间轴，匀速直线运动时是倾斜直线，变速运动时是曲线
3. x-t 图像的截距与交点：纵截距表示初始位置；两条图线的交点表示两物体在同一时刻位于同一位置
4. v-t 图像的斜率：表示加速度；匀速直线运动是平行于时间轴的直线，匀变速直线运动是倾斜直线
5. v-t 图像的面积：图线与时间轴所围的面积表示位移，时间轴上方为正、下方为负；两条图线的交点表示速度相同
6. a-t 图像：图线与时间轴所围的面积表示速度的变化量 Δv；匀变速直线运动的 a-t 图像是平行于时间轴的直线
7. 运动方向的变化：v-t 图线穿过时间轴时速度反向；x-t 图线的斜率由正变负（或相反）时速度反向
8. 概念辨析：x-t、v-t 图像只能描述直线运动，图线不是运动轨迹；图线是曲线表示变速，不表示物体做曲线运动

**A2 相互作用**（WLA-06～WLA-10）

### WLA-06　必一 3.1 重力与弹力（8 个考点）⬜
先修：WLA-01
1. 力：物体与物体之间的相互作用；单位牛顿（N）；力的三要素是大小、方向和作用点；可用力的图示或力的示意图表示
2. 重力：由于地球的吸引而使物体受到的力，G = mg，方向竖直向下
3. 重心：物体各部分受到的重力的等效作用点；位置与物体的形状和质量分布有关，可以不在物体上；薄板的重心可用悬挂法确定
4. 弹性形变与弹力：发生形变的物体由于要恢复原状，对与它接触的物体产生的力；产生条件是直接接触并发生弹性形变
5. 微小形变的观察：桌面、玻璃瓶等的形变很小，可借助光的反射或细管中液面的变化把形变放大显示
6. 弹力的方向：压力和支持力垂直于接触面，指向被压或被支持的物体；绳的拉力沿着绳指向绳收缩的方向
7. 胡克定律 F = kx：在弹性限度内，弹力与形变量成正比；x 是形变量而不是弹簧长度；劲度系数 k 由弹簧本身决定，单位 N/m
8. 概念辨析：弹力是施力物体发生形变产生的，书对桌面的压力是书的形变引起的，桌面对书的支持力是桌面的形变引起的

### WLA-07　必一 3.2 摩擦力（7 个考点）⬜
先修：WLA-06
1. 摩擦力：两个相互接触的物体发生相对运动或具有相对运动趋势时，在接触面上产生阻碍相对运动或相对运动趋势的力
2. 产生条件：接触面粗糙、相互挤压（有弹力）、有相对运动或相对运动趋势；有摩擦力一定有弹力，有弹力不一定有摩擦力
3. 滑动摩擦力的方向：沿着接触面，与物体相对于接触物的运动方向相反
4. 滑动摩擦力的大小 Ff = μFN：FN 是压力，不一定等于重力；动摩擦因数 μ 与接触面的材料和粗糙程度有关，没有单位
5. 静摩擦力：相对静止但有相对运动趋势时产生；方向沿接触面，与相对运动趋势的方向相反
6. 静摩擦力的大小：随外力变化，0 < F ≤ Fmax，不能用 μFN 计算；最大静摩擦力略大于滑动摩擦力，粗略计算时可认为相等
7. 概念辨析：摩擦力阻碍的是“相对”运动，方向可以与物体的运动方向相同，可以是动力；运动的物体可以受静摩擦力

### WLA-08　必一 3.3 牛顿第三定律与受力分析（8 个考点）⬜
先修：WLA-07
1. 作用力和反作用力：力的作用是相互的，两个物体之间的这一对力叫作用力和反作用力
2. 牛顿第三定律：两个物体之间的作用力和反作用力总是大小相等、方向相反，作用在同一条直线上
3. 实验依据：两个弹簧测力计（或力传感器）对拉，示数总是相等，且同时变化
4. 作用力与反作用力的特点：同时产生、同时变化、同时消失，性质相同，分别作用在两个物体上，效果不能抵消
5. 普遍性：牛顿第三定律与物体的运动状态无关，物体静止、匀速或加速时都成立
6. 概念辨析：一对相互作用力作用在两个物体上，一对平衡力作用在同一物体上；平衡力的性质不一定相同
7. 受力分析：先分析重力，再在研究对象与其他物体接触处分析弹力和摩擦力，最后分析其他力，画出受力示意图
8. 受力分析的原则：只分析研究对象受到的力；每个力都能找到施力物体；不另画“合力”“下滑力”等按效果命名的力

### WLA-09　必一 3.4 力的合成和分解（8 个考点）⬜
先修：WLA-08
1. 合力与分力：一个力单独作用的效果与几个力共同作用的效果相同，这个力叫那几个力的合力，是等效替代关系
2. 共点力：作用在物体的同一点，或作用线（延长线）交于一点的几个力
3. 平行四边形定则：以表示两个分力的线段为邻边作平行四边形，对角线表示合力
4. 合力的大小范围：|F1 − F2| ≤ F ≤ F1 + F2；两分力夹角越大合力越小；合力可以大于、等于或小于分力
5. 力的分解：力的分解是力的合成的逆运算，同样遵从平行四边形定则；不加限制时一个力可分解为无数对分力
6. 按实际需要分解：常按力的作用效果分解，如斜面上物体的重力分解为沿斜面和垂直斜面的两个分力
7. 正交分解：把力沿两个相互垂直的方向分解，F 在两个方向的分力为 F cosθ 和 F sinθ
8. 矢量和标量：矢量相加遵从平行四边形定则（三角形定则：两矢量首尾相接，从起点指向终点），标量相加遵从算术法则

### WLA-10　必一 3.5 共点力的平衡（7 个考点）⬜
先修：WLA-09
1. 平衡状态：物体受到几个力作用时，保持静止或匀速直线运动的状态，此时加速度为 0
2. 平衡条件：在共点力作用下物体平衡的条件是合力为 0
3. 平衡条件的分量形式：把各力正交分解，x 方向合力为 0，y 方向合力也为 0
4. 二力平衡与三力平衡：二力平衡时两力等大反向；三力平衡时任意两个力的合力与第三个力等大反向
5. 三力平衡的矢量关系：三个力的矢量首尾依次相接，组成封闭的三角形
6. 多力平衡：任意一个力与其余各力的合力等大反向；几个物体组成的系统保持平衡时，系统所受外力的合力也为 0
7. 概念辨析：速度为 0 不等于处于平衡状态，竖直上抛的物体到达最高点时速度为 0，但合力不为 0

**A3 牛顿运动定律**（WLA-11～WLA-13）

### WLA-11　必一 4.1 牛顿第一定律（8 个考点）⬜
先修：WLA-08
1. 亚里士多德的观点：必须有力作用在物体上，物体才能运动，没有力的作用物体就要静止
2. 伽利略的理想斜面实验：在可靠事实的基础上合理外推，得出若没有摩擦，运动的物体将以恒定速度一直运动下去
3. 笛卡儿的补充：如果运动中的物体不受力的作用，它将继续以同一速度沿同一直线运动，既不停下来也不偏离原来的方向
4. 牛顿第一定律：一切物体总保持匀速直线运动状态或静止状态，除非作用在它上面的力迫使它改变这种状态
5. 定律的地位：描述的是不受力的理想情况，不能用实验直接验证；它是在实验基础上经过推理概括得出的
6. 力和运动的关系：力不是维持物体运动的原因，而是改变物体运动状态的原因
7. 惯性：物体保持原来匀速直线运动状态或静止状态的性质，牛顿第一定律又叫惯性定律；质量是惯性大小的唯一量度
8. 概念辨析：惯性是物体的固有属性，不是力，与物体的速度、是否受力无关，不能说“受到惯性作用”

### WLA-12　必一 4.3、4.4 牛顿第二定律与力学单位制（8 个考点）⬜
先修：WLA-09、WLA-11
1. 牛顿第二定律：物体加速度的大小跟它受到的作用力成正比、跟它的质量成反比，加速度的方向跟作用力的方向相同
2. 表达式 F = ma：F 是物体所受的合力；取 1 N = 1 kg·m/s² 时比例系数 k = 1
3. 矢量性：加速度的方向总与合力的方向相同；可写成分量形式 Fx = max、Fy = may
4. 瞬时性：加速度与合力同时产生、同时变化、同时消失
5. 概念辨析：a = Δv/Δt 是加速度的定义式，a = F/m 表明加速度由合力和质量决定
6. 单位制：基本量的单位叫基本单位，由基本量根据物理关系推导出来的量的单位叫导出单位，二者组成单位制
7. 国际单位制：有七个基本单位；力学中的基本量是长度、质量、时间，基本单位是 m、kg、s；N、J、m/s 等是导出单位
8. 单位制的作用：计算时各量统一用国际单位，结果也是国际单位；可以根据单位检查物理关系式是否可能正确

### WLA-13　必一 4.5、4.6 牛顿运动定律的应用与超重、失重（8 个考点）⬜
先修：WLA-03、WLA-12
1. 力和运动的联系：加速度是联系物体受力情况和运动情况的桥梁
2. 两类基本问题：由受力情况确定运动情况，由运动情况确定受力情况；都要用到牛顿第二定律和运动学规律
3. 实重与视重：物体对支持物的压力或对悬挂物的拉力（测力计示数）叫视重；超重、失重时物体的重力并没有变化
4. 超重：物体对支持物的压力（或对悬挂物的拉力）大于物体所受重力的现象；加速度方向向上，加速上升或减速下降
5. 失重：物体对支持物的压力（或对悬挂物的拉力）小于物体所受重力的现象；加速度方向向下，加速下降或减速上升
6. 完全失重：物体向下的加速度等于 g 时，对支持物完全没有压力；绕地球运行的航天器中的物体处于完全失重状态，与重力有关的现象消失
7. 生活中的超重和失重：站在力传感器上下蹲时先失重后超重，站起时先超重后失重；电梯起动、制动时也会出现
8. 概念辨析：超重还是失重只由加速度的方向决定，与速度的方向无关

**A4 曲线运动与万有引力**（WLA-14～WLA-20）

### WLA-14　必二 5.1、5.2 曲线运动与运动的合成与分解（8 个考点）⬜
先修：WLA-02、WLA-09
1. 曲线运动的速度方向：质点在某一点的速度方向沿曲线在这一点的切线方向；速度方向时刻改变，曲线运动一定是变速运动
2. 物体做曲线运动的条件：所受合力（加速度）的方向与它的速度方向不在同一条直线上
3. 合力与轨迹的关系：轨迹夹在速度方向与合力方向之间，合力指向轨迹弯曲的内侧（凹侧）
4. 合力对速率的影响：合力与速度夹角为锐角时速率增大，为钝角时速率减小，始终垂直时速率不变
5. 合运动与分运动：物体实际发生的运动是合运动；分运动同时进行、各自独立，互不影响
6. 运动的合成与分解：位移、速度、加速度都是矢量，它们的合成与分解都遵从平行四边形定则
7. 教材实例（蜡块的运动）：蜡块沿玻璃管匀速上升，玻璃管同时水平匀速移动，蜡块的合运动是匀速直线运动，轨迹为 y = (vy/vx)x
8. 概念辨析：合运动是直线还是曲线，看合初速度与合加速度是否共线；两个匀速直线运动的合运动仍是匀速直线运动，变速运动不一定是曲线运动

### WLA-15　必二 5.4 抛体运动的规律（9 个考点）⬜
先修：WLA-04、WLA-14
1. 抛体运动：以一定速度抛出、忽略空气阻力、只受重力作用的运动；加速度恒为 g，是匀变速曲线运动
2. 平抛运动：初速度沿水平方向的抛体运动；可分解为水平方向的匀速直线运动和竖直方向的自由落体运动
3. 平抛运动的速度：vx = v0，vy = gt，合速度 v = √(v0² + vy²)，与水平方向的夹角 θ 满足 tanθ = gt/v0
4. 平抛运动的位移：x = v0t，y = ½gt²，位移与水平方向的夹角 α 满足 tanα = gt/2v0
5. 平抛运动的轨迹：消去 t 得 y = gx²/2v0²，轨迹是一条抛物线
6. 飞行时间与水平射程：t = √(2h/g) 只由下落高度决定；水平射程 x = v0√(2h/g) 由初速度和高度共同决定
7. 速度的变化：加速度恒为 g，任意相等时间内速度的变化量 Δv = gΔt 相同，方向竖直向下
8. 一般的抛体运动（斜抛）：初速度与水平方向成 θ 角，水平方向做匀速直线运动 vx = v0cosθ，竖直方向做初速度为 v0sinθ、加速度为 g 的匀变速运动
9. 概念辨析：斜抛运动到最高点时竖直分速度为 0，但速度不为 0（等于 v0cosθ），加速度仍为 g

### WLA-16　必二 6.1、6.3 圆周运动与向心加速度（9 个考点）⬜
先修：WLA-14
1. 匀速圆周运动：线速度大小处处相等的圆周运动；线速度方向时刻改变，是变速运动，而且加速度方向也在变，是变加速运动
2. 线速度 v = Δs/Δt：Δs 是 Δt 内通过的弧长；线速度方向沿圆周在该点的切线方向
3. 角速度 ω = Δθ/Δt：Δθ 是半径转过的角度，用弧度制；单位是弧度每秒，符号 rad/s
4. 周期与转速：周期 T 是转一周所用的时间；转速 n 是单位时间转过的圈数，单位 r/s 或 r/min
5. 各量的关系：v = ωr，ω = 2π/T，v = 2πr/T；转速以 r/s 为单位时 ω = 2πn
6. 传动中的规律：同一转动物体上各点角速度相同；皮带、链条、齿轮传动不打滑时，轮缘上各点线速度大小相等
7. 向心加速度：做匀速圆周运动的物体加速度指向圆心；它只改变速度的方向，不改变速度的大小
8. 向心加速度的大小：an = v²/r = ω²r = ωv；【教材拓展】也可以由速度变化量 Δv 的矢量关系推导出来
9. 概念辨析：an 与 r 是正比还是反比要看前提，线速度一定时 an 与 r 成反比，角速度一定时 an 与 r 成正比

### WLA-17　必二 6.2、6.4 向心力与生活中的圆周运动（8 个考点）⬜
先修：WLA-13、WLA-16
1. 向心力：做匀速圆周运动的物体所受的指向圆心的合力，Fn = mv²/r = mω²r；向心力是按效果命名的力
2. 向心力的来源：可以是重力、弹力、摩擦力中的某一个力，也可以是几个力的合力或某个力的分力；受力分析时不另画向心力
3. 变速圆周运动：合力不指向圆心，可分解为指向圆心的分力 Fn（改变速度方向）和沿切线的分力 Ft（改变速度大小）
4. 一般的曲线运动：可以把曲线分成许多很短的小段，每一小段看作一小段圆弧，用圆周运动的方法分析
5. 火车转弯：弯道处外轨略高于内轨，以规定速度行驶时由重力和支持力的合力提供向心力，v0 = √(gr tanθ)；速度过大挤压外轨，过小挤压内轨
6. 汽车过拱形桥与凹形路面：拱形桥最高点 mg − FN = mv²/r，压力小于重力，v = √(gr) 时压力为 0；凹形路面最低点压力大于重力
7. 航天器中的失重现象：绕地球做匀速圆周运动的航天器中，地球引力全部用来提供向心力，航天员对座椅的压力为 0，处于完全失重状态
8. 离心运动：合力突然消失或不足以提供所需的向心力时，物体沿切线飞出或逐渐远离圆心；应用有洗衣机脱水筒，危害要防止（如转弯限速）；并不存在“离心力”

### WLA-18　必二 7.1、7.2 行星的运动与万有引力定律（9 个考点）⬜
先修：WLA-17
1. 两种学说：地心说认为地球是宇宙的中心，日心说（哥白尼）认为太阳是中心；开普勒在第谷观测数据的基础上总结出行星运动规律
2. 开普勒第一定律：所有行星绕太阳运动的轨道都是椭圆，太阳处在椭圆的一个焦点上
3. 开普勒第二定律：对任意一个行星来说，它与太阳的连线在相等的时间内扫过的面积相等；因此行星在近日点速率大，远日点速率小
4. 开普勒第三定律：所有行星轨道的半长轴的三次方跟公转周期的二次方的比都相等，a³/T² = k；k 只与中心天体有关
5. 行星运动的近似处理：多数行星轨道接近圆，可看作以太阳为圆心的匀速圆周运动，a 取轨道半径
6. 太阳与行星间的引力：由向心力公式和开普勒第三定律得 F ∝ m/r²，再由牛顿第三定律得 F ∝ Mm/r²
7. 月—地检验：月球绕地球的向心加速度约为地面重力加速度的 1/60²，说明地面物体所受引力与天体间的引力遵从相同的规律
8. 万有引力定律：F = Gm1m2/r²，r 是两质点间的距离；质量分布均匀的球体，r 取两球心间的距离
9. 引力常量与定律的意义：卡文迪什用扭秤实验测出 G ≈ 6.67×10⁻¹¹ N·m²/kg²；万有引力定律第一次揭示了天上和地上的物体遵从同一规律

### WLA-19　必二 7.3 万有引力理论的成就（9 个考点）⬜
先修：WLA-18
1. 万有引力与重力：若不考虑地球自转，地面上物体所受重力等于地球对它的引力，mg = GMm/R²
2. 地球自转的影响：万有引力的一部分提供物体随地球自转的向心力，重力略小于万有引力，两极处二者相等，赤道处差别最大，但都很小
3. 重力加速度随高度变化：离地面高 h 处 g′ = GM/(R + h)²，高度越大 g′ 越小
4. “称量”地球的质量：由 mg = GMm/R² 得 M = gR²/G；卡文迪什测出 G 后，地球质量才得以算出
5. 计算太阳的质量：行星绕太阳做圆周运动，万有引力提供向心力，GMm/r² = m·4π²r/T²，得 M = 4π²r³/GT²
6. 天体的密度：由求出的中心天体质量和它的体积，可以得到天体的平均密度 ρ = M/(4πR³/3)
7. 发现未知天体：海王星是先根据万有引力定律计算出轨道、再观测发现的，被称为“笔尖下发现的行星”
8. 预言彗星回归：哈雷用牛顿的引力理论计算彗星轨道，预言了它的回归，后来得到证实
9. 概念辨析：根据环绕天体的运动求出的是中心天体的质量，不能求出环绕天体自身的质量

### WLA-20　必二 7.4 宇宙航行（8 个考点）⬜
先修：WLA-19
1. 牛顿的设想：在高山上水平抛出物体，速度越大落地点越远，速度足够大时物体将不再落回地面，成为人造地球卫星
2. 卫星的运行规律：万有引力提供向心力，v = √(GM/r)、ω = √(GM/r³)、T = 2π√(r³/GM)；轨道越高，v、ω、an 越小，T 越大，与卫星质量无关
3. 第一宇宙速度：v1 = √(GM/R) = √(gR) ≈ 7.9 km/s，是物体在地面附近绕地球做匀速圆周运动的速度
4. 发射速度与环绕速度：7.9 km/s 是最小的发射速度，也是卫星绕地球做圆周运动的最大环绕速度
5. 第二、第三宇宙速度：11.2 km/s 时挣脱地球引力的束缚，16.7 km/s 时挣脱太阳引力的束缚；发射速度介于 7.9 km/s 与 11.2 km/s 之间时轨道是椭圆
6. 地球同步卫星：周期与地球自转周期相同；轨道平面与赤道平面重合、相对地面静止的叫静止卫星，离地高度约 3.6×10⁴ km
7. 载人航天与太空探索：1957 年苏联发射第一颗人造卫星，1961 年加加林进入太空，1969 年阿波罗 11 号登月；我国有东方红一号、神舟载人飞船、嫦娥探月、天问一号、北斗系统和中国空间站
8. 概念辨析：赤道上随地球自转的物体不是由万有引力全部提供向心力，不是卫星，它与静止卫星角速度相同，速度远小于近地卫星

**A5 能量与动量**（WLA-21～WLA-28）

### WLA-21　必二 8.1 功与功率（8 个考点）⬜
先修：WLA-09、WLA-12
1. 做功的两个要素：作用在物体上的力，物体在力的方向上发生的位移
2. 功的公式 W = Fl cosα：α 是力与位移的夹角；功是标量，是过程量，单位焦耳，1 J = 1 N·m
3. 正功和负功：0 ≤ α < 90° 时做正功，90° < α ≤ 180° 时做负功（也说物体克服这个力做功），α = 90° 时不做功；正负不表示方向
4. 总功：几个力对物体做的总功，等于各个力分别对物体做功的代数和，也等于这几个力的合力对物体做的功
5. 功率 P = W/t：表示做功快慢的物理量，单位瓦特（W）；额定功率是动力机械长时间正常工作的最大功率，实际功率可以小于额定功率；常见机械的功率差别很大，人体约百瓦量级，汽车约几十千瓦，高铁列车可达上万千瓦
6. 功率与速度 P = Fv：F 与 v 同向；v 是平均速度时 P 是平均功率，v 是瞬时速度时 P 是瞬时功率
7. 功率一定时 F 与 v 成反比：汽车发动机功率一定时，上坡需要较大牵引力，司机换低速挡减小速度
8. 概念辨析：摩擦力不一定做负功，静摩擦力和滑动摩擦力都可以做正功、做负功或不做功

### WLA-22　必二 8.2 重力势能与弹性势能（8 个考点）⬜
先修：WLA-21
1. 重力做功的特点：只跟物体运动的起点和终点的位置（高度差）有关，跟运动路径无关，WG = mgh1 − mgh2
2. 重力势能 Ep = mgh：h 是物体相对参考平面的高度；是标量，单位焦耳
3. 重力做功与重力势能变化的关系：WG = Ep1 − Ep2；重力做正功，重力势能减少；重力做负功，重力势能增加
4. 重力势能的相对性：数值与参考平面的选取有关，在参考平面下方时为负值；但重力势能的变化量与参考平面的选取无关
5. 重力势能的系统性：重力势能是地球与物体所组成的系统共有的
6. 弹性势能：发生弹性形变的物体的各部分之间，由于有弹力的相互作用而具有的势能
7. 弹性势能的大小：弹簧的弹性势能与形变量和劲度系数有关，形变量越大、劲度系数越大，弹性势能越大
8. 弹力做功与弹性势能变化：弹力做正功，弹性势能减少；弹力做负功，弹性势能增加；【教材拓展】弹力做的功可由 F-x 图线下的面积求得

### WLA-23　必二 8.3 动能和动能定理（8 个考点）⬜
先修：WLA-03、WLA-21
1. 动能表达式的得出：恒力 F 使物体在光滑水平面上由 v1 加速到 v2，由 W = Fl、牛顿第二定律和运动学公式得 W = ½mv2² − ½mv1²
2. 动能 Ek = ½mv²：物体由于运动而具有的能量；是标量，没有负值，单位焦耳
3. 动能是状态量：对应某一时刻的速度；速度方向改变而大小不变时动能不变（如匀速圆周运动）
4. 动能定理：力在一个过程中对物体做的功，等于物体在这个过程中动能的变化，W = Ek2 − Ek1
5. 动能定理中的 W：是合力做的功，即各个力做功的代数和
6. 适用范围：由恒力、直线运动推得，对变力做功和曲线运动同样适用
7. 物理意义：合力做正功，动能增加；合力做负功，动能减少；合力做的功是动能变化的量度
8. 概念辨析：动能定理是标量式，不能在某个方向上分别列式；速度和位移一般都相对地面

### WLA-24　必二 8.4 机械能守恒定律与能量守恒（9 个考点）⬜
先修：WLA-22、WLA-23
1. 追寻守恒量：伽利略的斜面实验中，小球总能回到与出发点几乎同样的高度，说明有某个量是守恒的
2. 机械能：动能、重力势能和弹性势能统称为机械能；通过重力或弹力做功，动能与势能可以相互转化
3. 机械能守恒定律：在只有重力或弹力做功的物体系统内，动能与势能可以互相转化，而总的机械能保持不变
4. 定律的推导：只有重力做功时，由动能定理 WG = Ek2 − Ek1 和 WG = Ep1 − Ep2 得 Ek1 + Ep1 = Ek2 + Ep2
5. 概念辨析：“只有重力或弹力做功”不等于“只受重力或弹力”，其他力不做功或做功代数和为 0 时机械能也守恒
6. 功是能量转化的量度：合力做功对应动能的变化，重力做功对应重力势能的变化，弹力做功对应弹性势能的变化
7. 机械能的变化：除重力和弹力以外的其他力做的功等于机械能的变化，做正功机械能增加，做负功机械能减少
8. 能量的转化：有摩擦等阻力做功时，机械能转化为内能等其他形式的能，机械能减少，但总能量守恒（→ WLD-06）
9. 能量守恒定律：能量既不会凭空产生，也不会凭空消失，只能从一种形式转化为另一种形式，或从一个物体转移到别的物体，总量保持不变（→ WLD-06）

### WLA-25　选必1 1.1、1.2 动量、冲量与动量定理（9 个考点）⬜
先修：WLA-12、WLA-23
1. 动量概念的提出：在碰撞实验中寻找“不变量”，发现两物体碰撞前后质量与速度的乘积之和保持不变，于是把 mv 定义为动量
2. 动量 p = mv：单位 kg·m/s；矢量，方向与速度的方向相同；是状态量
3. 动量的变化量 Δp = p′ − p：矢量运算，同一直线上规定正方向后化为代数运算；Δp 的方向与速度变化量的方向相同
4. 概念辨析 动量与动能：动量是矢量，动能是标量，Ek = p²/2m；动量变化时动能不一定变化，动能变化时动量一定变化
5. 冲量 I = FΔt：单位 N·s；矢量，恒力的冲量方向与力的方向相同；是过程量，表示力对时间的累积效应，与物体是否运动无关
6. 变力的冲量：F-t 图线与时间轴所围的面积表示冲量；也可以由动量定理通过动量的变化量求出
7. 动量定理：由牛顿第二定律和运动学公式推出 FΔt = mv′ − mv；物体在一个过程中所受合力的冲量等于它在这个过程始末的动量变化量
8. 动量定理的意义：F = Δp/Δt，合力等于动量的变化率；它是矢量式，可以在某一方向上使用；对变力同样成立，F 为平均作用力
9. 用动量定理解释现象：动量变化量一定时，作用时间越长作用力越小（安全气囊、跳远的沙坑、包装用的泡沫塑料）；作用时间越短作用力越大

### WLA-26　选必1 1.3 动量守恒定律（8 个考点）⬜
先修：WLA-08、WLA-25
1. 系统、内力和外力：相互作用的几个物体组成系统；系统中物体间的相互作用力叫内力，系统以外的物体施加的力叫外力
2. 定律的推导：两物体相互作用时，由牛顿第三定律和动量定理得 m1v1 + m2v2 = m1v1′ + m2v2′；内力只在系统内转移动量，不改变总动量
3. 动量守恒定律：如果一个系统不受外力，或者所受外力的矢量和为 0，这个系统的总动量保持不变
4. 近似守恒与分方向守恒：内力远大于外力时（如碰撞、爆炸）系统动量近似守恒；某一方向上外力的矢量和为 0 时，该方向上的动量守恒
5. 表达式的含义：矢量式，各速度相对同一参考系（通常是地面）；“守恒”指过程中任意两个时刻系统的总动量都相等
6. 概念辨析 动量守恒与机械能守恒：前者的条件是外力的矢量和为 0，后者的条件是只有重力或弹力做功；一个守恒时另一个不一定守恒
7. 与牛顿运动定律的关系：在牛顿运动定律适用的范围内可以由它推出；动量守恒定律只涉及过程的始末状态，不必考虑相互作用力的细节
8. 动量守恒定律的普适性：牛顿运动定律只适用于宏观、低速的情形，动量守恒定律在高速（接近光速）和微观领域依然成立，是自然界普遍适用的基本规律之一

### WLA-27　选必1 1.5 弹性碰撞和非弹性碰撞（8 个考点）⬜
先修：WLA-24、WLA-26
1. 碰撞的特点：作用时间极短，内力远大于外力，系统动量守恒；碰撞过程中物体的位移可以忽略
2. 按能量分类：碰撞前后系统动能不变的是弹性碰撞；动能有损失的是非弹性碰撞，损失的动能转化为内能等
3. 完全非弹性碰撞：碰后两物体结合在一起以共同速度运动，m1v1 + m2v2 = (m1 + m2)v，系统动能的损失最大
4. 弹性正碰（v2 = 0）的结果：由动量守恒和动能守恒得 v1′ = (m1 − m2)v1/(m1 + m2)，v2′ = 2m1v1/(m1 + m2)
5. 对结果的讨论：m1 = m2 时两球交换速度；m1 > m2 时两球都向前运动；m1 < m2 时入射球反弹；m1 远小于 m2 时入射球几乎以原速率弹回
6. 碰撞的特点：作用时间极短，内力远大于外力，系统动量守恒；碰撞过程中系统的总动能不会增加
7. 对心碰撞与非对心碰撞：碰前速度沿两球球心连线的是正碰，否则是斜碰；斜碰后速度不在同一直线上，动量守恒仍按矢量成立
8. 散射：微观粒子相互接近时不一定发生接触，这种“碰撞”叫散射；核反应堆中用慢化剂使中子减速利用的也是碰撞规律（→ WLE-09）

### WLA-28　选必1 1.6 反冲现象与火箭（8 个考点）⬜
先修：WLA-26
1. 反冲现象：一个物体在内力作用下分成两部分，一部分向某一方向运动，另一部分必然向相反方向运动
2. 反冲遵循动量守恒：内力远大于外力，系统动量守恒；原来静止时 0 = m1v1 + m2v2，两部分速度方向相反
3. 反冲中的能量：化学能、弹性势能等其他形式的能转化为机械能，系统的总动能增加
4. 爆炸：内力远大于外力，动量近似守恒；化学能转化为动能，总动能增加；与反冲的本质相同
5. 反冲的应用与防止：农田的喷灌装置自动旋转、章鱼和乌贼喷水前进是利用反冲；射击时枪身后坐，要把枪托抵在肩部以减小反冲的影响
6. 火箭的原理：燃料燃烧产生的高温高压燃气以很大的速度向后喷出，火箭获得向前的反冲速度；在没有空气的太空中同样可以加速
7. 影响火箭速度的因素：喷气速度和质量比（火箭开始飞行时的质量与燃料燃尽时的质量之比）；喷气速度越大、质量比越大，火箭获得的速度越大
8. 火箭的发展：我国古代已发明利用火药燃气反冲的火箭；现代运载火箭多采用多级结构，并用于发射卫星和载人飞船

**A6 机械振动**（WLA-29～WLA-32）

### WLA-29　选必1 2.1、2.2 简谐运动及其描述（9 个考点）⬜
先修：WLA-05、WLA-16
1. 机械振动：物体在平衡位置附近的往复运动；平衡位置是振动物体原来静止时的位置
2. 弹簧振子：小球和弹簧组成的系统，是理想化模型（小球看成质点，忽略弹簧质量和摩擦）
3. 振子的位移—时间图像：用频闪照相或让振子带笔在匀速移动的纸带上描迹得到；位移从平衡位置指向振子所在的位置
4. 简谐运动：质点的位移与时间的关系遵从正弦函数的规律，x-t 图像是正弦曲线；它是最简单、最基本的振动
5. 振幅、周期和频率：振幅 A 是离开平衡位置的最大距离，表示振动的强弱；完成一次全振动的时间为周期 T，f = 1/T；一个周期内路程为 4A
6. 周期与振幅无关：简谐运动的周期（频率）由振动系统本身决定，与振幅无关
7. 表达式 x = A sin(ωt + φ)：ω = 2π/T = 2πf 叫圆频率；(ωt + φ) 叫相位，φ 是初相
8. 相位差：两个同频率简谐运动的相位差 Δφ = φ2 − φ1，表示振动步调的差异；Δφ = 0 时步调一致，Δφ = π 时步调相反
9. 从 x-t 图像获得信息：振幅、周期、任一时刻的位移；图线上某点切线的斜率表示该时刻的速度

### WLA-30　选必1 2.3 简谐运动的回复力和能量（8 个考点）⬜
先修：WLA-12、WLA-29
1. 回复力：使振动物体回到平衡位置的力，方向总是指向平衡位置；按效果命名，可以由一个力、几个力的合力或某个力的分力提供
2. 简谐运动的动力学特征：F = −kx；物体所受的力与它偏离平衡位置的位移大小成正比且总指向平衡位置，物体就做简谐运动；k 不一定是劲度系数
3. 加速度 a = −kx/m：大小与位移成正比，方向与位移相反；简谐运动是加速度不断变化的变加速运动
4. 竖直弹簧振子：平衡位置在弹力与重力相等处，回复力是弹力与重力的合力，以平衡位置为原点时仍满足 F = −kx
5. 各量随位置的变化：远离平衡位置时位移、回复力、加速度增大，速度减小；在平衡位置速度最大、加速度为 0，在最大位移处速度为 0、加速度最大
6. 能量的转化：振动中动能和势能相互转化；在平衡位置动能最大，在最大位移处势能最大
7. 机械能守恒：不计阻力时简谐运动的机械能守恒；振动的能量与振幅有关，振幅越大，能量越大
8. 概念辨析 速度与位移的方向：加速度总与位移反向，速度与位移可以同向也可以反向，取决于振子正在远离还是靠近平衡位置

### WLA-31　选必1 2.4 单摆（8 个考点）⬜
先修：WLA-17、WLA-30
1. 单摆模型：细线的质量和伸缩可以忽略，小球的直径比线长小得多；是理想化模型
2. 单摆的回复力：重力沿圆弧切线方向的分力 F = −mg sinθ；摆线拉力与重力沿摆线方向分力的合力提供向心力
3. 小角度近似：摆角很小时 sinθ ≈ x/l，回复力 F = −(mg/l)x，单摆的运动可看作简谐运动
4. 概念辨析 回复力与合力：摆球经过最低点时回复力为 0，但合力不为 0（提供向心力），最低点不是平衡状态
5. 科学史：伽利略发现了单摆运动的等时性；惠更斯确定了单摆的周期公式，并利用等时性发明了摆钟
6. 周期公式 T = 2π√(l/g)：摆长 l 是悬点到摆球球心的距离；周期只由摆长和当地的重力加速度决定，与振幅（小摆角时）和摆球质量无关
7. 摆钟：利用单摆的等时性计时；改变摆长可以调整摆钟走时的快慢
8. 单摆的能量：摆动中重力势能和动能相互转化，不计阻力时机械能守恒；摆球在最低点速度最大

### WLA-32　选必1 2.6 受迫振动与共振（8 个考点）⬜
先修：WLA-30
1. 固有振动与固有频率：振动系统不受外力作用时的振动叫固有振动，其频率叫固有频率，由系统本身决定
2. 阻尼振动：系统受到阻力，机械能逐渐转化为内能等，振幅逐渐减小的振动
3. 驱动力与受迫振动：作用于振动系统的周期性外力叫驱动力，系统在驱动力作用下的振动叫受迫振动
4. 受迫振动的频率：稳定后等于驱动力的频率，与系统的固有频率无关
5. 共振：驱动力的频率等于系统的固有频率时，受迫振动的振幅最大，这种现象叫共振
6. 共振曲线：横轴为驱动力频率，纵轴为振幅；驱动力频率越接近固有频率振幅越大，峰值处 f驱 = f固
7. 共振的应用：需要利用共振时，使驱动力的频率接近或等于固有频率，如共振筛、乐器的共鸣箱
8. 共振的防止：需要防止共振时，使驱动力的频率远离固有频率，如部队过桥便步走、火车过桥减速、机器转速避开机座的固有频率

## 篇B（WLB）电学基础：静电场、恒定电流、磁场、带电粒子在电场和磁场中的运动、电磁感应、交变电流与传感器

**B1 静电场**（WLB-01～WLB-06）

### WLB-01　必三 9.1、9.2 电荷与库仑定律（8 个考点）⬜
先修：WLA-09、WLA-10
1. 两种电荷：自然界只有正、负两种电荷，同种电荷相互排斥，异种电荷相互吸引；电荷量的单位是库仑（C）
2. 起电的本质：原子由带正电的原子核和核外带负电的电子组成，不同物质束缚电子的能力不同，金属中有自由电子；摩擦起电、感应起电和接触带电都是电子的转移，并没有创造电荷
3. 静电感应：带电体靠近导体时，导体中的自由电子发生移动，使导体靠近带电体的一端带异种电荷，远离的一端带同种电荷
4. 电荷守恒定律：电荷既不会创生也不会消灭，只能从一个物体转移到另一个物体，或从物体的一部分转移到另一部分，总量保持不变
5. 元电荷 e = 1.60×10⁻¹⁹ C：最小的电荷量，所有带电体的电荷量都是 e 的整数倍；元电荷不是电子也不是质子；电荷量与质量之比叫比荷
6. 点电荷：带电体的形状、大小及电荷分布对相互作用的影响可以忽略时的理想化模型，与质点类似
7. 库仑定律 F = kq₁q₂/r²：适用于真空中两个静止的点电荷，k = 9.0×10⁹ N·m²/C²，力的方向在两电荷的连线上；库仑用扭秤实验得出，研究中采用了控制变量和与万有引力类比的方法，用完全相同的金属球接触平分电荷来改变电荷量
8. 静电力的叠加：两个以上点电荷对某一电荷的作用力，等于各点电荷单独作用时所受静电力的矢量和

### WLB-02　必三 9.3 电场与电场强度（8 个考点）⬜
先修：WLB-01
1. 电场：电荷周围存在的一种特殊物质，电荷之间的相互作用通过电场发生；场与实物一样是物质存在的形式
2. 试探电荷与场源电荷：试探电荷的电荷量和尺寸要充分小，放入后不影响原电场；激发电场的电荷叫场源电荷
3. 电场强度 E = F/q：比值定义，单位 N/C；由电场本身决定，与试探电荷无关；方向与正电荷在该点所受静电力的方向相同
4. 点电荷的电场 E = kQ/r²：由场源电荷 Q 和距离 r 决定；正电荷的电场方向背离电荷，负电荷的电场方向指向电荷
5. 电场强度的叠加：某点的电场强度等于各个点电荷单独在该点产生的电场强度的矢量和，按平行四边形定则合成
6. 电场线：为形象描述电场而假想的线，起始于正电荷或无限远，终止于无限远或负电荷；不相交；疏密表示强弱，切线方向表示电场强度方向
7. 匀强电场：各点电场强度的大小和方向都相同，电场线是间隔相等的平行直线；相距很近、带等量异种电荷的平行金属板间（边缘除外）是匀强电场
8. 概念辨析：电场线不是带电粒子的运动轨迹；只有电场线是直线、粒子只受静电力且初速度为 0 或沿电场线时，轨迹才与电场线重合

### WLB-03　必三 9.4 静电的防止与利用（8 个考点）⬜
先修：WLB-02
1. 静电平衡：导体放入电场后自由电子重新分布，当导体内的自由电子不再发生定向移动时，导体达到静电平衡状态
2. 静电平衡导体内部的电场强度处处为 0：感应电荷的电场与外电场在导体内部叠加，合电场强度为 0
3. 静电平衡导体上的电荷分布：导体内部没有净电荷，电荷只分布在导体的外表面；表面越尖锐的位置电荷密度越大，周围电场强度越大
4. 尖端放电：导体尖端附近的强电场使空气电离，与尖端电荷异号的离子被吸引而中和尖端的电荷；避雷针利用尖端放电，高压设备的导体表面做得光滑以减少放电
5. 静电屏蔽：静电平衡时导体壳内的空腔不受外部电场的影响，金属网也有屏蔽作用；如高压作业人员穿含金属丝的工作服、高压输电线上方的接地导线
6. 静电吸附：利用静电使微粒被吸附到电极或物体上，应用于静电除尘、静电喷漆、静电复印
7. 静电的危害与防止：静电积累可能引起火花放电，造成火灾或损坏器件；防止的办法是及时导走静电，如油罐车接地、加油前触摸静电释放器、保持空气湿润
8. 概念辨析：“导体内部电场强度为 0”指合电场强度为 0，外电场和感应电荷的电场仍然都存在

### WLB-04　必三 10.1 电势能和电势（8 个考点）⬜
先修：WLA-22、WLB-02
1. 静电力做功的特点：在静电场中移动电荷时，静电力做的功与路径无关，只与电荷的起点和终点位置有关（与重力做功类比）
2. 电势能：电荷在电场中具有的势能；静电力做的功等于电势能的减少量，W_AB = E_pA − E_pB
3. 静电力做功与电势能变化：静电力做正功，电势能减少；静电力做负功，电势能增加
4. 电势能的相对性：电势能的数值与零势能位置的选取有关，通常取无限远处或大地表面的电势能为 0；电荷在某点的电势能等于把它从该点移到零势能位置时静电力做的功
5. 电势 φ = E_p/q：单位伏特（V），标量，有正负；由电场本身决定，与试探电荷无关；电势的数值与零电势点的选取有关
6. 沿着电场线方向电势逐渐降低
7. 电势能与电势的关系 E_p = qφ：正电荷在电势高处电势能大，负电荷在电势高处电势能小
8. 概念辨析：电场强度与电势没有必然联系，电场强度大的地方电势不一定高，电场强度为 0 的地方电势不一定为 0

### WLB-05　必三 10.2、10.3 电势差及其与电场强度的关系（8 个考点）⬜
先修：WLB-04
1. 电势差 U_AB = φ_A − φ_B：也叫电压，单位 V，有正负，U_AB = −U_BA；与零电势点的选取无关
2. 静电力做功与电势差 W_AB = qU_AB：对任何电场都成立；电子伏（eV）是能量单位，1 eV = 1.60×10⁻¹⁹ J
3. 等势面：电场中电势相同的各点构成的面；在同一等势面上移动电荷，静电力不做功
4. 等势面与电场线的关系：等势面与电场线垂直，电场线由电势高的等势面指向电势低的等势面；相邻等势面电势差相等时，等势面越密电场强度越大
5. 常见的等势面：点电荷的等势面是以它为球心的一簇球面，匀强电场的等势面是垂直于电场线的一簇平面；静电平衡的导体是等势体，表面是等势面
6. 匀强电场中 U_AB = Ed：d 是 A、B 两点沿电场方向的距离
7. E = U/d 的物理意义：匀强电场中电场强度在数值上等于沿电场方向单位距离上降低的电势；电场强度的方向就是电势降低最快的方向；单位 V/m 与 N/C 相同
8. 非匀强电场中的定性理解：电场强度越大的区域，沿电场方向相同距离上的电势差越大，等差等势面越密

### WLB-06　必三 10.4 电容器的电容（7 个考点）⬜
先修：WLB-05
1. 电容器：两个彼此绝缘又相距很近的导体组成；平行板电容器是最简单的电容器
2. 充电与放电：充电时两极板带上等量异种电荷，电源的能量储存在电容器中；放电时两极板的电荷中和，电场能转化为其他形式的能；电容器的电荷量指一个极板所带电荷量的绝对值
3. 电容 C = Q/U：比值定义，表示电容器容纳电荷的本领；由电容器本身决定，与 Q、U 无关；也可写成 C = ΔQ/ΔU
4. 电容的单位：法拉（F），1 F = 10⁶ μF = 10¹² pF
5. 平行板电容器的电容 C = εᵣS/4πkd：与正对面积成正比，与极板间距离成反比，极板间插入电介质后电容增大；εᵣ 是电介质的相对介电常数
6. 常用电容器：分为固定电容器和可变电容器，电解电容器有正负极之分；电容器的应用如照相机闪光灯、电容式传感器
7. 击穿电压与额定电压：加在电容器两极板上的电压超过击穿电压时电介质被击穿；电容器外壳上标的是额定电压，低于击穿电压

**B2 恒定电流**（WLB-07～WLB-10）

### WLB-07　必三 11.1、11.2 电源和电流、导体的电阻（8 个考点）⬜
先修：WLB-05
1. 电源：能把电子从正极搬运到负极的装置，作用是保持导体两端的电势差，使电路中有持续的电流
2. 恒定电场与恒定电流：导线内的电场由电源、导线等电路元件所积累的电荷共同形成，电荷分布稳定，电场也稳定；大小、方向都不随时间变化的电流叫恒定电流
3. 电流 I = q/t：单位安培（A），1 A = 1 C/s；规定正电荷定向移动的方向为电流的方向；电流是标量
4. 电流的微观表达式【教材拓展】：I = nqSv，n 是单位体积内的自由电荷数，v 是自由电荷定向移动的平均速率，金属中这一速率很小
5. 电阻 R = U/I：反映导体对电流的阻碍作用，单位欧姆（Ω）；欧姆定律 I = U/R 适用于金属和电解质溶液导电
6. 电阻定律 R = ρl/S：同种材料的导体，电阻与长度成正比，与横截面积成反比；用控制变量法探究得出
7. 电阻率 ρ：反映材料的导电性能，由材料和温度决定，与导体的形状无关；金属的电阻率随温度升高而增大，有些合金的电阻率几乎不受温度影响，可制作标准电阻；某些材料低温下电阻突然减为 0 的现象叫超导
8. 伏安特性曲线：导体的 I-U 图像；电流与电压成正比、图线是过原点的直线的元件叫线性元件，小灯泡、二极管等的图线不是直线，叫非线性元件；常见电路元器件有电阻器、电容器、电感器、二极管、开关等，各有不同作用

### WLB-08　必三 11.4 串联电路和并联电路（8 个考点）⬜
先修：WLB-07
1. 串联电路的电流和电压：电流处处相等，总电压等于各部分电路两端电压之和
2. 并联电路的电流和电压：各支路两端电压相等，总电流等于各支路电流之和
3. 串联电路的电阻：总电阻等于各部分电阻之和，R = R₁ + R₂ + …；各电阻两端的电压与电阻成正比
4. 并联电路的电阻：总电阻的倒数等于各支路电阻的倒数之和，1/R = 1/R₁ + 1/R₂ + …；各支路的电流与电阻成反比
5. 概念辨析：串联的总电阻大于其中任何一个电阻，并联的总电阻小于其中任何一个电阻
6. 表头：小量程的电流表 G，三个参数是内阻 R_g、满偏电流 I_g 和满偏电压 U_g = I_gR_g；从电路的角度看，表头就是一个能显示自身电流的电阻
7. 改装成电压表：表头串联一个分压电阻，R = U/I_g − R_g；量程越大，电压表的内阻越大
8. 改装成电流表：表头并联一个分流电阻，R = I_gR_g/(I − I_g)；量程越大，电流表的内阻越小

### WLB-09　必三 12.1 电路中的能量转化（8 个考点）⬜
先修：WLB-08
1. 电功 W = UIt：电流做功的实质是导体中的恒定电场对自由电荷的静电力做功，电能转化为其他形式的能；单位焦耳，生活中常用千瓦时，1 kW·h = 3.6×10⁶ J
2. 电功率 P = W/t = UI：表示电流做功的快慢，单位瓦特（W）
3. 焦耳定律 Q = I²Rt：电流通过导体产生的热量；热功率 P热 = I²R；由英国物理学家焦耳通过实验得出
4. 纯电阻电路：电能全部转化为内能，W = Q，P = UI = I²R = U²/R
5. 非纯电阻电路：含电动机、电解槽等，电能只有一部分转化为内能，UI > I²R，欧姆定律不适用
6. 电动机的能量转化：输入功率 P入 = UI，热功率 P热 = I²r，输出的机械功率 P出 = UI − I²r，效率 η = P出/P入
7. 额定功率与实际功率：用电器铭牌上标的是额定电压和额定功率，实际功率随实际电压而改变
8. 家庭电路、安全用电和节约用电：家庭电路中各用电器并联，同时使用的用电器总功率越大，干路电流越大；短路或过载会使导线过热，需选用合适规格的导线并安装保险装置；随手关灯、选用节能电器以节约用电

### WLB-10　必三 12.2 闭合电路的欧姆定律（8 个考点）⬜
先修：WLB-09
1. 闭合电路的组成：外电路由用电器和导线组成，内电路是电源内部；电源内部也有电阻，叫内阻 r
2. 非静电力：在电源内部，非静电力把正电荷从负极搬运到正极，把其他形式的能转化为电势能（如化学电池中化学能转化为电势能）
3. 电动势 E = W/q：W 是非静电力移送电荷 q 所做的功；电动势表征电源把其他形式的能转化为电势能的本领，单位 V，由电源本身决定，与外电路无关
4. 闭合电路的欧姆定律 I = E/(R + r)：闭合电路的电流跟电源的电动势成正比，跟内、外电路的电阻之和成反比；适用于外电路为纯电阻的电路
5. 电动势与内外电压：E = U外 + U内，即 U = E − Ir，内电压是电流通过内阻时的电势降落
6. 路端电压与负载的关系：外电阻增大时，电流减小，路端电压增大；断路时路端电压等于电动势；短路时 I = E/r，电流很大，绝不允许把电源两极直接用导线相连
7. 闭合电路中的能量与功率：EIt = UIt + I²rt；电源的总功率 P总 = EI，输出功率 P出 = UI，内阻的热功率 P内 = I²r；电源的效率 η = U/E
8. 电源的 U-I 图像：U = E − Ir 的图线是一条直线，纵轴截距等于电动势，斜率的绝对值等于内阻

**B3 磁场**（WLB-11～WLB-13）

### WLB-11　必三 13.1、13.2 磁场、磁感应强度与磁通量（8 个考点）⬜
先修：WLB-02
1. 磁现象与我国古代成就：磁体有 N、S 两极，同名磁极相斥、异名相吸；我国古代发明司南、指南针，北宋沈括在《梦溪笔谈》中记载了磁偏角；现代应用有电磁铁、磁记录、磁悬浮列车等
2. 电流的磁效应与磁场：奥斯特发现电流周围存在磁场，揭示电与磁的联系；磁体与磁体、磁体与电流、电流与电流间的作用都通过磁场发生
3. 磁感线：为形象描述磁场而假想的曲线；切线方向为该点磁场方向（小磁针 N 极受力方向），疏密表示强弱；是闭合曲线，外部 N→S、内部 S→N
4. 安培定则与常见磁场：直线电流的磁感线是同心圆，拇指指电流、四指指环绕方向；环形电流和通电螺线管四指指电流，拇指指内部磁场方向；螺线管内部近似匀强磁场
5. 安培分子电流假说与地磁场：分子电流假说说明磁体的磁场与电流的磁场本质相同；地磁南极在地理北极附近，地磁场两极与地理两极不重合
6. 磁感应强度：导线与磁场垂直时 B = F/Il，比值定义，由磁场本身决定，与 I、l 无关；矢量，方向即磁场方向；单位特斯拉（T）；多个磁场叠加按平行四边形定则
7. 匀强磁场：各处磁感应强度大小相等、方向相同的磁场，磁感线是间隔相等的平行直线；距离很近的两个异名磁极之间、通电螺线管内部近似为匀强磁场
8. 磁通量：匀强磁场中 Φ = BS（S 与 B 垂直），不垂直时取垂直于磁场方向的投影面积；标量，单位韦伯（Wb），1 Wb = 1 T·m²；B 可理解为磁通密度

### WLB-12　选必2 1.1 安培力（8 个考点）⬜
先修：WLB-10、WLB-11
1. 安培力：通电导线在磁场中受到的力；方向用左手定则判断，磁感线垂直穿入掌心，四指指电流方向，拇指所指为安培力方向
2. 方向特点：安培力既垂直于磁场方向，又垂直于电流方向，即垂直于 B 与 I 所决定的平面；B 与 I 不一定垂直
3. 安培力的大小：I 与 B 垂直时 F = IlB；I 与 B 平行时 F = 0；夹角为 θ 时 F = IlB sinθ（把 B 分解为垂直和平行于导线的分量）
4. 平行通电直导线间的作用：同向电流相互吸引，反向电流相互排斥；可用一条导线产生的磁场对另一条导线的安培力来解释
5. 磁电式电流表的构造：蹄形磁体、极靴、软铁圆柱、线圈、螺旋弹簧和指针；极靴与圆柱间的磁场沿半径方向，线圈平面总与磁感线平行
6. 磁电式电流表的原理与特点：线圈受安培力矩转动，螺旋弹簧扭转阻碍转动；偏角随电流增大而增大，偏转方向反映电流方向；灵敏度高，但允许通过的电流很弱
7. 电动机与能量转化：电动机利用通电线圈在磁场中受安培力而转动的原理工作；安培力做正功，把电能转化为机械能
8. 概念辨析：B 的方向是小磁针 N 极受力方向，安培力方向与 B 垂直而不沿 B；导线与磁场平行时不受安培力，不能说明该处 B 为 0

### WLB-13　选必2 1.2 洛伦兹力（7 个考点）⬜
先修：WLB-12
1. 洛伦兹力：运动电荷在磁场中受到的力；安培力是导线中大量定向移动电荷所受洛伦兹力的宏观表现
2. 洛伦兹力的方向：用左手定则，四指指向正电荷运动方向（负电荷运动的反方向）；洛伦兹力既垂直于速度，又垂直于磁场
3. 洛伦兹力的大小：由 F安 = IlB 与 I = nqSv 推导得 F = qvB（v 与 B 垂直）；v 与 B 平行时 F = 0；夹角为 θ 时 F = qvB sinθ
4. 洛伦兹力不做功：洛伦兹力始终与速度垂直，只改变速度方向，不改变速度大小，因此不改变粒子的动能
5. 与静电力的比较：静电力作用于电场中的一切电荷，与是否运动无关，可以做功；洛伦兹力只作用于运动且速度不与磁场平行的电荷，不做功
6. 电子束的磁偏转：显像管中电子枪发射的电子束经偏转线圈的磁场偏转，偏转磁场的强弱和方向不断变化，使电子束扫描整个荧光屏
7. 概念辨析：洛伦兹力方向随速度方向变化，是变力；正、负电荷以相同速度运动时所受洛伦兹力方向相反

**B4 带电粒子在电场和磁场中的运动**（WLB-14～WLB-16）

### WLB-14　必三 10.5 带电粒子在电场中的运动（8 个考点）⬜
先修：WLA-15、WLA-23、WLB-05
1. 重力的处理：电子、质子、α 粒子、离子等微观粒子所受重力远小于静电力，一般不计重力；带电小球、液滴、尘埃等一般要考虑重力
2. 带电粒子的加速：由动能定理 qU = ½mv² − ½mv₀²，对匀强电场和非匀强电场都适用；从静止加速时 v = √(2qU/m)
3. 带电粒子的偏转：粒子以初速度 v₀ 垂直于电场方向进入匀强电场，运动与平抛运动类似
4. 偏转的分解：沿初速度方向做匀速直线运动，t = l/v₀；沿电场方向做初速度为 0 的匀加速直线运动，a = qU/md
5. 偏移量与偏转角：y = qUl²/2mdv₀²，tanθ = qUl/mdv₀²
6. 示波管的构造【教材拓展】：由电子枪、偏转电极（YY′、XX′）和荧光屏组成，管内抽成真空；电子枪发射并加速电子
7. 示波管的原理【教材拓展】：YY′ 加待测的信号电压，XX′ 加扫描电压，两者周期相同时荧光屏上显示信号电压一个周期内的波形
8. 能量转化：带电粒子在电场中运动时，静电力做的功等于电势能的减少量，也等于（只有静电力做功时）动能的增加量

### WLB-15　选必2 1.3 带电粒子在匀强磁场中的运动（7 个考点）⬜
先修：WLA-17、WLB-13
1. 运动性质：不计重力的带电粒子，速度与磁场平行时做匀速直线运动，速度与磁场垂直时在垂直于磁场的平面内做匀速圆周运动
2. 向心力来源：洛伦兹力始终与速度垂直、大小不变，提供向心力，qvB = mv²/r
3. 轨道半径：r = mv/qB，同一磁场中粒子的速度越大、比荷越小，半径越大
4. 运动周期：T = 2πr/v = 2πm/qB，只由粒子的比荷和磁感应强度决定，与速度大小和轨道半径无关
5. 洛伦兹力演示仪：电子枪发射电子束，励磁线圈产生与电子束垂直的匀强磁场，电子径迹为圆；增大加速电压半径变大，增大励磁电流半径变小
6. 运动的物理图景：粒子运动过程中动能不变；电性相反的粒子在同一磁场中绕行方向相反
7. 速度与磁场斜交：速度可分解为平行与垂直于磁场的分量，粒子沿磁场方向匀速运动的同时做圆周运动，轨迹为螺旋线

### WLB-16　选必2 1.4 质谱仪与回旋加速器（7 个考点）⬜
先修：WLB-14、WLB-15
1. 质谱仪的构造与原理：粒子经电场加速 qU = ½mv²，再垂直进入匀强磁场做半个圆周运动打到照相底片上，r = (1/B)√(2mU/q)
2. 质谱仪的用途：底片上的位置反映粒子的比荷，可测定带电粒子的质量、分析同位素；最初由阿斯顿设计
3. 速度选择器：电场与磁场相互垂直，qE = qvB 时粒子沿直线通过，v = E/B，与粒子的电性、电荷量和质量无关
4. 回旋加速器的构造：两个 D 形盒置于匀强磁场中，两盒间的窄缝处加交变电压；粒子在缝隙中被电场加速，在盒内受磁场作用做半个圆周运动
5. 回旋加速器的同步条件：粒子回旋周期 T = 2πm/qB 与速度无关，交变电压的周期等于粒子回旋周期，粒子每次经过缝隙都被加速
6. 最大动能：粒子半径等于 D 形盒半径 R 时引出，Ekm = q²B²R²/2m，由 B 和 R 决定，与加速电压无关
7. 回旋加速器的局限：粒子能量很高时，受相对论效应影响，回旋周期发生变化，粒子的能量受到限制（→ WLE-01）

**B5 电磁感应**（WLB-17～WLB-19）

### WLB-17　必三 13.3，选必2 2.1 电磁感应现象与楞次定律（9 个考点）⬜
先修：WLB-11
1. 划时代的发现：奥斯特发现“电生磁”后，法拉第经多年探索于 1831 年发现“磁生电”，即电磁感应现象，产生的电流叫感应电流
2. 产生感应电流的条件：穿过闭合导体回路的磁通量发生变化；回路不闭合时只产生感应电动势，没有感应电流
3. 磁通量变化的方式：磁感应强度变化；导体切割磁感线使回路面积变化；回路平面与磁场的夹角变化
4. 教材实验：导体棒切割磁感线、磁体插入或拔出线圈、改变原线圈电流（通断开关、移动滑片）时，电流表指针偏转，说明有感应电流
5. 电磁感应的应用与影响：发电机、变压器等都利用电磁感应，使大规模生产和利用电能成为可能，推动了人类进入电气时代
6. 楞次定律：感应电流的磁场总要阻碍引起感应电流的磁通量的变化
7. “阻碍”的含义：阻碍的是磁通量的变化而非磁通量本身，表现为“增反减同”“来拒去留”；阻碍不是阻止，变化只是被延缓
8. 楞次定律与能量守恒：感应电流的效果总阻碍引起它的原因，外界须做功才能获得电能，楞次定律是能量守恒在电磁感应中的体现
9. 右手定则：导体切割磁感线时，磁感线穿入掌心，拇指指导体运动方向，四指所指为感应电流方向；是楞次定律在切割情形中的具体表现

### WLB-18　选必2 2.2 法拉第电磁感应定律（8 个考点）⬜
先修：WLB-10、WLB-17
1. 感应电动势：电磁感应现象中产生的电动势；产生感应电动势的那部分导体相当于电源，有无感应电流还取决于电路是否闭合
2. 法拉第电磁感应定律：感应电动势的大小跟穿过这一电路的磁通量的变化率成正比，E = nΔΦ/Δt，单位为伏特（V）
3. Φ、ΔΦ 与 ΔΦ/Δt：感应电动势由磁通量变化的快慢决定，与磁通量的大小、变化量的大小没有必然联系
4. 导线切割磁感线：B、l、v 两两垂直时 E = Blv，由定律推导得出；v 与 B 夹角为 θ 时 E = Blv sinθ
5. 平均值与瞬时值：E = nΔΦ/Δt 一般表示 Δt 内的平均感应电动势；E = Blv 中 v 为瞬时速度时表示瞬时感应电动势
6. 动生电动势：导体运动产生的感应电动势；其非静电力与导体中自由电荷随导体运动所受的洛伦兹力有关
7. 动生电动势中的能量转化：导体切割磁感线时受到阻碍运动的安培力，外力克服安培力做功，机械能转化为电能，这正是发电机的能量转化
8. 反电动势：电动机线圈转动时也切割磁感线，产生与电源电动势方向相反的反电动势，电动机正是在克服反电动势的过程中把电能转化为机械能

### WLB-19　选必2 2.3、2.4 涡流、电磁阻尼与电磁驱动，互感和自感（9 个考点）⬜
先修：WLB-18
1. 感生电场与感生电动势：麦克斯韦认为变化的磁场在周围空间激发感生电场，导体中自由电荷在它作用下定向移动形成感应电流；电子感应加速器利用感生电场加速电子
2. 涡流及其应用：块状金属中因磁通量变化产生的旋涡状感应电流；真空冶炼炉、电磁炉、金属探测器（探雷器、安检门）利用涡流
3. 涡流的防止：变压器和电动机的铁芯用相互绝缘的硅钢片叠成，以减小涡流造成的能量损失和发热
4. 电磁阻尼：导体相对磁场运动时，感应电流所受安培力总阻碍导体的相对运动；磁电式仪表把线圈绕在铝框上，使指针很快停下
5. 电磁驱动：磁场相对导体转动时，导体中的感应电流受安培力而跟着转动，转速总小于磁场转速；交流感应电动机利用电磁驱动
6. 互感：一个线圈中电流变化，在另一个线圈中产生感应电动势；变压器利用互感，互感也可能干扰电路，需要防止
7. 自感：线圈自身电流变化时产生自感电动势，总阻碍电流的变化；通电时与线圈串联的灯泡逐渐变亮，断电时线圈中的电流逐渐减小；应用与危害：日光灯镇流器利用自感，断开含大线圈的电路时会产生电火花，精密电阻用双线绕法消除自感
8. 自感系数：自感电动势 E = LΔI/Δt；L 与线圈的大小、形状、匝数及有无铁芯有关，单位亨利（H）
9. 磁场的能量：断电时灯泡能继续发光，说明线圈中的磁场储存了能量；电流建立的过程中电源做功储存为磁场能

**B6 交变电流与传感器**（WLB-20～WLB-22）

### WLB-20　选必2 3.1、3.2 交变电流及其描述（9 个考点）⬜
先修：WLA-16、WLB-09、WLB-18
1. 交变电流：大小和方向随时间做周期性变化的电流，简称交流；方向不随时间变化的电流叫直流
2. 交变电流的产生：线圈在匀强磁场中绕垂直于磁场的轴匀速转动；线圈平面与磁场垂直的位置叫中性面，此时 Φ 最大、感应电动势为 0
3. 中性面的特点：线圈每经过一次中性面电流方向改变一次，转一周改变两次；线圈平面与磁场平行时 Φ 为 0，感应电动势最大
4. 正弦式交变电流的公式与图像：从中性面开始计时 e = Em sinωt，Em = NBSω；i、u 也按正弦规律变化，图像为正弦曲线
5. 交流发电机：由产生感应电动势的电枢和产生磁场的磁体组成，分旋转电枢式和旋转磁极式；把机械能转化为电能
6. 周期和频率：T = 2π/ω = 1/f；我国电网交流的频率为 50 Hz，周期为 0.02 s
7. 峰值和有效值：有效值按电流的热效应定义，相同电阻在一个周期内产生相同热量的恒定电流值；正弦式交流 I = Im/√2，U = Um/√2
8. 有效值的使用：用电器铭牌上的额定值、交流电表的示数都是有效值；电容器的耐压值要高于交流电压的峰值
9. 电感器和电容器对交流的作用【教材拓展】：电感器“通直流、阻交流”，自感系数越大、频率越高，感抗越大；电容器“隔直流、通交流”，电容越大、频率越高，容抗越小

### WLB-21　选必2 3.3、3.4 变压器与电能的输送（9 个考点）⬜
先修：WLB-19、WLB-20
1. 变压器的构造：由闭合铁芯和绕在铁芯上的原线圈、副线圈组成；原线圈接电源，副线圈接负载
2. 变压器的原理：互感现象，原线圈中交变电流产生交变磁通量，在副线圈中产生感应电动势；对恒定电流不能变压，也不改变交流频率
3. 理想变压器：没有能量损失，P入 = P出；电压与匝数关系 U1/U2 = n1/n2，n2 > n1 为升压、n2 < n1 为降压
4. 电流与匝数关系：只有一个副线圈时 I1/I2 = n2/n1，由功率关系得出；匝数多的线圈电流小，导线可较细
5. 实际变压器的能量损失：线圈有电阻会发热，铁芯中有涡流，还有漏磁；大型变压器效率很高
6. 输电的基本要求与损失：可靠、保质、经济；输电线上功率损失 P损 = I²r，电压损失 ΔU = Ir，r 为输电线电阻
7. 高压输电：输送功率一定时 I = P/U，提高输电电压可减小电流，从而大大减小损失；减小导线电阻的作用有限
8. 远距离输电的基本环节：发电厂 → 升压变压器 → 高压输电线 → 降压变压器 → 用户；输电电压并非越高越好，还要考虑绝缘等技术与成本
9. 电网供电与直流输电：电网可合理调度电力、保证供电质量；我国已建成特高压输电工程，远距离输电中也采用直流输电

### WLB-22　选必2 5.1、5.2 传感器（8 个考点）⬜
先修：WLB-10、WLB-13
1. 传感器：能感受被测量并按一定规律转换成便于利用的信号（通常是电压、电流等电学量或电路的通断）的器件或装置
2. 非电学量转换成电学量：把力、温度、光、磁场等非电学量转换为电学量后，便于测量、传输、处理和控制
3. 传感器的组成：一般由敏感元件和转换元件组成，敏感元件直接感受被测量，转换元件把它输出的信号转换成电信号
4. 光敏电阻：多用硫化镉等半导体材料制成，光照越强电阻越小；把光照强弱转换为电阻大小，用于光控开关、光电计数
5. 热敏电阻与金属热电阻：金属电阻率随温度升高而增大；半导体热敏电阻阻值随温度变化明显、灵敏度高，金属热电阻化学稳定性好、测温范围大
6. 电阻应变片：金属导体被拉伸时电阻变大、被压缩时电阻变小；把形变转换为电阻变化，用于电子秤等力传感器
7. 霍尔元件【教材拓展】：通电半导体薄片置于垂直磁场中，在与电流和磁场都垂直的方向出现霍尔电压，大小与 B 成正比，可把磁感应强度转换为电压（→ WLB-13）
8. 传感器的应用：广泛用于家用电器、智能手机、汽车、工业自动化和医疗

## 篇C（WLC）波动与光：机械波、光的折射与全反射、光的波动性、电磁振荡与电磁波

**C1 机械波**（WLC-01～WLC-02）

### WLC-01　选必1 3.1、3.2 机械波的形成与描述（9 个考点）⬜
先修：WLA-29
1. 波的形成：波源振动带动相邻质点振动，相邻质点依次带动下去，振动由近及远传播；各质点开始振动的方向与波源开始振动的方向相同
2. 机械波：机械振动在介质中的传播；产生机械波需要波源和介质
3. 波传递的是什么：传播的是振动这种运动形式，同时传递能量和信息；介质中的质点只在各自平衡位置附近振动，不随波迁移
4. 横波和纵波：质点振动方向与传播方向垂直的是横波，有波峰和波谷；在同一直线上的是纵波，有密部和疏部；声波是纵波，地震波既有横波也有纵波
5. 波的图像：横轴表示各质点的平衡位置，纵轴表示某一时刻各质点偏离平衡位置的位移；简谐波的图像是正弦曲线
6. 波长、周期和波速：波长 λ 是在振动中相位总相同的两个相邻质点间的距离；一个周期内波传播一个波长，v = λ/T = λf
7. 各量由什么决定：频率由波源决定，波速由介质决定，波长由两者共同决定；波从一种介质进入另一种介质时频率不变
8. 质点振动方向与波的传播方向：沿传播方向，后面的质点重复前面质点的振动，所以由波形和传播方向可以确定各质点的振动方向，反之亦然
9. 概念辨析 振动图像与波的图像：振动图像描述一个质点的位移随时间的变化，横轴是时间，可读出周期；波的图像描述某一时刻各质点的位移，横轴是位置，可读出波长

### WLC-02　选必1 3.3～3.5 波的反射、折射、衍射、干涉与多普勒效应（10 个考点）⬜
先修：WLC-01
1. 波的反射：波遇到障碍物会返回原介质继续传播，反射角等于入射角；反射波的频率、波速和波长不变；回声是声波的反射
2. 波的折射：波从一种介质进入另一种介质时传播方向发生改变；频率不变，波速和波长改变
3. 波的衍射：波可以绕过障碍物继续传播；一切波都能发生衍射，“闻其声而不见其人”是声波的衍射
4. 发生明显衍射的条件：缝、孔的宽度或障碍物的尺寸跟波长相差不多，或者比波长更小；条件不满足时衍射依然存在，只是不明显
5. 波的叠加：几列波相遇后仍保持各自的运动特征继续传播；在重叠区域，质点的位移等于几列波单独传播时引起的位移的矢量和
6. 波的干涉：频率相同、相位差恒定、振动方向相同的两列波叠加，振动加强区和减弱区相互间隔且位置稳定；干涉和衍射都是波特有的现象
7. 加强点和减弱点（两波源振动步调相同）：到两波源的路程差为波长的整数倍时加强，振幅为 A1 + A2；为半波长的奇数倍时减弱，振幅为 |A1 − A2|
8. 概念辨析 加强点的位移：加强点仍在做振动，位移随时间变化，某些时刻为 0；“加强”指的是振幅最大，而不是位移始终最大
9. 多普勒效应：波源与观察者相互靠近时，观察者接收到的频率变大；相互远离时变小；波源本身的频率并没有改变；由奥地利物理学家多普勒首先发现
10. 多普勒效应的应用：交通中测量车辆速度，医学上用“彩超”测血流速度，天文学上由星体光谱线的移动测定星体相对地球的运动速度

**C2 光的折射与全反射**（WLC-03～WLC-04）

### WLC-03　选必1 4.1 光的折射（9 个考点）⬜
先修：WLC-02
1. 光的反射和折射：光射到两种介质的分界面时，一部分光返回原介质发生反射，一部分光进入另一种介质发生折射
2. 折射定律：折射光线与入射光线、法线在同一平面内，折射光线与入射光线分别位于法线两侧；入射角的正弦与折射角的正弦成正比，sinθ1/sinθ2 = n12
3. 折射率：光从真空射入某种介质时，入射角的正弦与折射角的正弦之比 n = sinθ1/sinθ2，反映介质的光学性质
4. n = c/v：光在介质中的速度 v = c/n；光在真空中的速度最大，任何介质的折射率都大于 1
5. 光路可逆：在折射现象中光路是可逆的；光从介质射入空气时，折射角大于入射角
6. 光进入介质后的变化：频率不变，速度变小，波长变短，λ = λ0/n
7. 不同色光的折射率：同一种介质对不同色光的折射率不同，对紫光最大、对红光最小，紫光在介质中的速度较小；白光经三棱镜分解为彩色光带
8. 两面平行的玻璃砖与三棱镜：光通过平行玻璃砖后出射光线与入射光线平行但发生侧移；光通过三棱镜后向底边偏折
9. 生活中的折射现象：从水面上方看水中的物体，位置比实际的浅；插入水中的筷子看起来向上弯折

### WLC-04　选必1 4.2 全反射（8 个考点）⬜
先修：WLC-03
1. 光疏介质与光密介质：两种介质相比，折射率较小的叫光疏介质，较大的叫光密介质；这是相对的概念，与介质的密度不是一回事
2. 全反射现象：光从光密介质射向光疏介质，入射角增大时折射角随之增大，折射光越来越弱、反射光越来越强，入射角达到某一角度时折射光完全消失
3. 临界角：折射角为 90° 时对应的入射角；光从介质射入空气（真空）时 sinC = 1/n，折射率越大，临界角越小
4. 发生全反射的条件：光从光密介质射入光疏介质；入射角等于或大于临界角
5. 全反射棱镜：截面为等腰直角三角形的玻璃棱镜，可使光的传播方向改变 90° 或 180°；全反射时几乎没有能量损失，比平面镜反射效果好
6. 光导纤维的工作原理：光纤由内芯和外套两层组成，内芯的折射率比外套的大，光在内芯与外套的界面上不断发生全反射，从一端传到另一端
7. 光纤的应用：光纤通信传输容量大、衰减小、抗干扰能力强；医学上用光导纤维制成内窥镜，观察人体内部器官
8. 生活中的全反射：水中或玻璃中的气泡看起来特别明亮，是光射到气泡表面时发生了全反射

**C3 光的干涉、衍射和偏振**（WLC-05～WLC-06）

### WLC-05　选必1 4.3 光的干涉（8 个考点）⬜
先修：WLC-02、WLC-03
1. 杨氏双缝干涉实验：1801 年托马斯·杨成功观察到光的干涉现象，证明光是一种波
2. 相干光源：频率相同、相位差恒定、振动方向相同；实验中让同一束光通过双缝，得到两个相干光源
3. 亮条纹和暗条纹的条件：屏上某点到两缝的路程差等于波长的整数倍时出现亮条纹，等于半波长的奇数倍时出现暗条纹
4. 条纹间距 Δx = lλ/d：l 为双缝到屏的距离，d 为双缝间距
5. 干涉图样的特点：单色光的干涉条纹是等间距的明暗相间条纹；白光的干涉条纹是彩色的，中央为白色亮条纹
6. 光的颜色与波长：光的颜色由频率决定；红光波长最长、紫光最短，波长越长，干涉条纹间距越大
7. 薄膜干涉：薄膜前、后两个表面的反射光叠加形成干涉；竖直放置的肥皂膜上薄下厚，形成水平的条纹，白光照射时呈彩色
8. 薄膜干涉的应用：检查光学元件表面是否平整；在镜头等光学元件表面镀膜，增加透射光或反射光

### WLC-06　选必1 4.5、4.6 光的衍射、偏振与激光（10 个考点）⬜
先修：WLC-05
1. 光的衍射：光通过很窄的缝或很小的孔时，绕过缝或孔的边缘传播到相当宽的地方；障碍物或孔的尺寸与光的波长相差不多或比波长小时，衍射十分明显
2. 单缝衍射图样：中央亮条纹最宽最亮，两侧条纹变窄变暗；缝越窄、波长越长，中央亮条纹越宽；白光的衍射条纹是彩色的
3. 圆孔衍射和圆盘衍射：圆孔衍射图样是明暗相间的圆环；不透光圆盘的阴影中心出现亮斑（泊松亮斑），它的出现有力支持了光的波动说
4. 衍射光栅：由许多等宽、等间距的狭缝组成，衍射条纹又窄又亮，可用于分析光谱
5. 概念辨析 干涉与衍射图样：双缝干涉条纹等间距、亮度基本相同；单缝衍射条纹中央宽而亮，两侧窄而暗，间距不等
6. 衍射的意义：衍射现象说明“光沿直线传播”只是近似规律；光的干涉和衍射说明光具有波动性
7. 光的偏振：自然光在垂直于传播方向的平面内沿一切方向振动；通过偏振片后只剩下沿透振方向振动的光，成为偏振光；两偏振片透振方向垂直时光不能通过
8. 光是横波：只有横波才能发生偏振，光的偏振现象说明光是横波；自然光在水面、玻璃表面反射和折射时，反射光和折射光都是偏振光
9. 偏振的应用：照相机镜头前加偏振滤光片减弱反射光、立体电影、液晶显示
10. 激光的特性和应用：激光是人工产生的相干光；相干性好，可用于光纤通信、全息照相；平行度好，可用于精确测距、读取光盘；亮度高，可用于切割、焊接，医学上用作“光刀”

**C4 电磁振荡与电磁波**（WLC-07～WLC-08）

### WLC-07　选必2 4.1 电磁振荡（8 个考点）⬜
先修：WLB-06、WLB-19
1. 振荡电流与振荡电路：大小和方向都做周期性迅速变化的电流叫振荡电流；由线圈 L 和电容器 C 组成的 LC 电路是最简单的振荡电路
2. 放电过程：电容器放电，电荷量减少、电流增大，电场能转化为磁场能；放电完毕时电荷量为 0，电流和磁场能最大
3. 充电过程：线圈的自感作用使电流继续流动并逐渐减小，给电容器反向充电，磁场能转化为电场能；充电完毕时电流为 0
4. 电磁振荡：电路中的电荷、电流以及与之相联系的电场和磁场周期性相互转化的现象
5. 同步变化的物理量：电荷量、板间电压、电场强度、电场能同步变化；电流、线圈中的磁感应强度、磁场能同步变化；一组最大时另一组为 0
6. 周期和频率：T = 2π√(LC)，f = 1/(2π√(LC))，叫固有周期和固有频率；改变 L 或 C 可以改变振荡频率
7. 阻尼振荡与无阻尼振荡：电路有电阻发热、又向外辐射电磁波，振幅逐渐减小；适时补充能量可得到振幅不变的等幅振荡
8. 振荡图像：从电容器充满电开始放电时计时，q 随时间按余弦规律变化，i 按正弦规律变化

### WLC-08　必三 13.4，选必2 4.2～4.4 电磁场与电磁波（10 个考点）⬜
先修：WLC-01、WLC-07
1. 麦克斯韦电磁场理论：变化的磁场产生电场，变化的电场产生磁场；周期性变化的电场和磁场相互联系，形成不可分割的电磁场
2. 电磁波的预言与证实：麦克斯韦预言电磁波并指出光是电磁波；赫兹用实验证实了电磁波的存在，测得其速度等于光速；电磁场理论把电、磁、光统一起来，体现了场的统一性与多样性
3. 电磁波的特点：横波，电场、磁场与传播方向两两垂直；传播不需要介质；真空中速度 c = 3.0×10⁸ m/s，c = λf；能发生反射、折射、干涉、衍射
4. 电磁波的能量：电磁场是一种物质，电磁波具有能量，能传递能量和信息，例如微波炉加热食物、阳光使地面升温
5. 无线电波的发射：振荡频率要足够高，电路要开放；把信号加到频率很高的载波上叫调制，分调幅（AM）和调频（FM）
6. 无线电波的接收：接收电路固有频率与电磁波频率相同时产生电谐振，使电路产生电谐振的过程叫调谐；从接收到的振荡电流中还原出信号叫解调
7. 电磁波谱：按波长由长到短为无线电波、红外线、可见光、紫外线、X 射线、γ 射线
8. 各波段的特征与应用：无线电波用于通信和广播，微波用于雷达和微波炉；红外线热作用强，用于遥感和测温；紫外线能杀菌消毒、使荧光物质发光
9. X 射线与 γ 射线：X 射线穿透力强，用于医学透视和安检；γ 射线能量很高、穿透力更强，用于治疗肿瘤和工业探伤
10. 电磁波的应用及其影响：广播电视、移动通信、卫星导航、雷达等改变了人类的生活；过量电磁辐射危害健康，电磁波也会形成电磁污染

## 篇D（WLD）热学：分子动理论、气体、固体和液体、热力学定律与能源

**D1 分子动理论**（WLD-01～WLD-02）

### WLD-01　选必3 1.1 分子动理论的基本内容（8 个考点）⬜
先修：WLA-12
1. 物体由大量分子组成：分子直径的数量级一般为 10⁻¹⁰ m
2. 阿伏加德罗常数：NA = 6.02×10²³ mol⁻¹，是联系摩尔质量、摩尔体积等宏观量与分子质量、分子体积等微观量的桥梁
3. 微观量的关系：分子质量 m0 = M/NA；固体、液体的 Vmol/NA 近似为一个分子的体积，气体的 Vmol/NA 是每个分子平均占有的空间
4. 扩散现象：不同物质能够彼此进入对方，是分子无规则运动的直接结果，温度越高扩散越快
5. 布朗运动：悬浮微粒的无规则运动，是液体分子撞击不平衡造成的，间接反映了液体分子的无规则运动；微粒越小、温度越高越明显
6. 分子的热运动：分子永不停息的无规则运动叫热运动，温度越高热运动越剧烈
7. 分子间的作用力：分子间同时存在引力和斥力；r = r0 时合力为 0，r < r0 时表现为斥力，r > r0 时表现为引力，距离很大时可以忽略
8. 概念辨析：显微镜下看到的是悬浮微粒而不是分子；布朗运动图中的折线是每隔一定时间微粒位置的连线，不是运动轨迹

### WLD-02　选必3 1.3、1.4 分子运动速率分布与内能（9 个考点）⬜
先修：WLA-22、WLA-23、WLD-01
1. 气体分子运动的特点：分子间距离大，除碰撞外作用力很弱；分子频繁碰撞，向各个方向运动的分子数目几乎相等
2. 统计规律：单个分子的运动是偶然的、无规则的，大量分子的整体表现遵从统计规律
3. 分子运动速率分布：呈“中间多、两头少”；温度升高时速率大的分子所占比例增大，分布曲线的峰值向速率大的方向移动
4. 气体压强的微观解释：大量分子频繁碰撞器壁产生持续均匀的压力；压强与分子的平均动能和分子的数密度有关
5. 分子动能与温度：温度是分子热运动平均动能的标志；温度是大量分子的统计概念，对单个分子没有意义
6. 分子势能：由分子间的相对位置决定；分子力做正功分子势能减小，做负功增大；r = r0 时分子势能最小
7. 内能：物体中所有分子的热运动动能与分子势能的总和，一切物体都具有内能
8. 内能的决定因素：与物质的量、温度、体积有关；与物体整体的机械运动速度和所处高度无关
9. 概念辨析：温度高的物体内能不一定大；0 ℃ 的冰熔化成 0 ℃ 的水，分子平均动能不变，吸热后内能增大

**D2 气体**（WLD-03～WLD-04）

### WLD-03　选必3 2.1、2.2 温度和温标、气体的等温变化（7 个考点）⬜
先修：WLA-10、WLD-02
1. 状态参量：研究气体时用压强 p、体积 V、温度 T 描述系统的状态
2. 平衡态：没有外界影响时，系统的状态参量不再随时间变化的状态
3. 热平衡与热平衡定律：两个系统接触后状态参量不再变化即达到热平衡；与第三个系统分别热平衡的两个系统彼此也热平衡
4. 温度：热平衡的系统具有相同的温度，温度是决定系统是否达到热平衡的物理量；温度计依据热平衡测温
5. 温标与热力学温度：摄氏温标和热力学温标；T = t + 273.15 K，单位开尔文（K），温度变化 1 K 与 1 ℃ 相等
6. 玻意耳定律：一定质量的某种气体，温度不变时压强与体积成反比，pV = C，即 p1V1 = p2V2
7. 等温线：p-V 图像中的等温线是双曲线的一支，离原点越远温度越高；p-1/V 图像是过原点的直线

### WLD-04　选必3 2.3 气体的等压变化和等容变化（8 个考点）⬜
先修：WLD-03
1. 盖—吕萨克定律：一定质量的某种气体，压强不变时体积与热力学温度成正比，V/T = C
2. 查理定律：一定质量的某种气体，体积不变时压强与热力学温度成正比，p/T = C
3. 等压线与等容线：V-T 图像中的等压线、p-T 图像中的等容线都是过原点的直线；以摄氏温度为横轴时延长线交于 −273.15 ℃
4. 理想气体：在任何温度、任何压强下都遵从气体实验定律的气体，是理想模型；实际气体在温度不太低、压强不太大时可视为理想气体
5. 理想气体的微观模型：分子本身大小可忽略，分子间除碰撞外无相互作用，无分子势能；一定质量理想气体的内能只与温度有关
6. 理想气体的状态方程【教材拓展】：一定质量的某种理想气体，pV/T = C，三个状态参量同时变化时适用
7. 气体实验定律的微观解释：等温时体积减小，数密度增大，压强增大；等容时温度升高，平均动能增大，压强增大
8. 等压变化的微观解释：温度升高使分子平均动能增大，要保持压强不变，体积必须增大使分子的数密度减小

**D3 固体和液体**（WLD-05）

### WLD-05　选必3 2.4、2.5 固体和液体（9 个考点）⬜
先修：WLD-02
1. 晶体和非晶体：晶体有确定的熔点，非晶体没有；石英、云母、食盐、金属是晶体，玻璃、蜂蜡、松香、沥青是非晶体
2. 单晶体和多晶体：单晶体有规则的几何形状，某些物理性质各向异性；多晶体由许多杂乱排列的晶粒组成，各向同性
3. 晶体的微观结构：组成晶体的微粒在空间按一定规则整齐排列；同种微粒按不同规则排列可形成不同晶体，如金刚石和石墨
4. 晶体与非晶体的转化：在一定条件下，晶体和非晶体可以相互转化
5. 材料科学：半导体、超导体、纳米材料、液晶、石墨烯等碳材料的研制，都基于对物质微观结构的认识，深刻影响生产生活和社会进步
6. 液体的表面张力：表面层分子较稀疏，分子力表现为引力，使液面有收缩趋势，方向与液面相切；如露珠呈球形、水黾停在水面
7. 浸润和不浸润：水浸润玻璃，水银不浸润玻璃；是否浸润取决于液体和固体两种物质的性质
8. 毛细现象：浸润液体在细管中上升，不浸润液体在细管中下降，管越细越明显；如毛巾吸水、土壤中水分上升
9. 液晶：既有液体的流动性，又像某些晶体那样具有光学性质的各向异性，应用于液晶显示

**D4 热力学定律与能源**（WLD-06～WLD-07）

### WLD-06　选必3 3.1～3.3 热力学第一定律与能量守恒定律（9 个考点）⬜
先修：WLA-24、WLD-04
1. 焦耳的实验：在绝热过程中，系统从一个状态变到另一个状态，外界做功的多少只由始末状态决定，与做功方式无关
2. 功与内能：绝热过程中内能的增加量等于外界对系统做的功，ΔU = W
3. 热与内能：单纯传热时，内能的增加量等于系统从外界吸收的热量，ΔU = Q
4. 做功和传热：改变内能的两种方式，效果等价；做功是其他形式的能与内能的转化，传热是内能的转移
5. 热力学第一定律：系统内能的增加量等于外界向它传递的热量与外界对它做的功之和，ΔU = Q + W
6. 符号约定：外界对系统做功 W > 0，系统吸热 Q > 0，内能增加 ΔU > 0；反之取负；对理想气体，体积减小时外界对气体做功
7. 能量守恒定律：能量不会凭空产生或消失，只能从一种形式转化为另一种形式或在物体间转移，总量保持不变
8. 能量守恒定律的发现：经历了迈尔、焦耳、亥姆霍兹等许多人的长期探索，是自然界最普遍、最重要的规律之一
9. 第一类永动机：不消耗能量却能不断对外做功的机器，违背能量守恒定律，不可能制成

### WLD-07　选必3 3.4，必三 12.4 热力学第二定律与能源（9 个考点）⬜
先修：WLD-06
1. 宏观过程的方向性：传热、摩擦生热、气体向真空膨胀、扩散等与热现象有关的宏观自然过程都具有方向性，是不可逆的
2. 克劳修斯表述：热量不能自发地从低温物体传到高温物体；电冰箱消耗电能才能把热量从低温处移到高温处
3. 开尔文表述：不可能从单一热库吸收热量使之完全变成功而不产生其他影响；热机效率不可能达到 100%
4. 第二类永动机：从单一热库吸热全部用来做功的机器不违背能量守恒，但违背热力学第二定律，不可能制成
5. 熵【教材拓展】：熵是系统无序程度的量度；孤立系统的自发过程总是朝熵增加的方向进行
6. 能量耗散：各种形式的能最终转化为内能流散到环境中，难以重新利用；能量总量不变但品质降低，所以要节约能源
7. 能源的分类：煤、石油、天然气等化石能源是不可再生能源；水能、风能、太阳能等是可再生能源
8. 能源的利用方式：水力发电、风力发电、太阳能光伏发电和光热利用、核电站利用核能（→ WLE-09）
9. 能源与环境：化石能源的大量使用造成大气污染、温室效应等危害；要开发新能源、提高能源利用效率，走可持续发展之路

## 篇E（WLE）近代物理：相对论时空观、能量量子化与波粒二象性、原子结构、原子核

**E1 相对论时空观**（WLE-01）

### WLE-01　必二 7.5 相对论时空观与牛顿力学的局限性（8 个考点）⬜
先修：WLA-20
1. 牛顿力学时空观：时间和空间独立于物体及其运动而存在，是绝对的；速度按经典方式叠加
2. 光速不变的实验事实：迈克耳孙—莫雷实验等表明，在不同参考系中测得的光速相同，与经典速度叠加不符
3. 爱因斯坦的两个假设：在不同的惯性参考系中物理规律的形式都相同；真空中的光速在不同惯性参考系中大小都相同
4. 同时的相对性：在一个参考系中同时发生的两个事件，在另一个相对运动的参考系中不一定同时
5. 时间延缓效应：相对观察者运动的物体上发生的过程，观察者测得的时间变长；高速 μ 子寿命变长是其实验证据
6. 长度收缩效应：相对观察者运动的物体，沿运动方向的长度变短；相对论表明时间和空间与物质的运动有关
7. 牛顿力学的成就与局限：适用于宏观、低速运动；高速用相对论，微观用量子力学，牛顿力学是它们在一定条件下的特殊情形
8. 宇宙起源和演化：观测发现宇宙在膨胀（哈勃），宇宙微波背景辐射等证据支持大爆炸宇宙学说；人类对宇宙的认识仍在不断深入（了解）

**E2 能量量子化与波粒二象性**（WLE-02～WLE-04）

### WLE-02　必三 13.5，选必3 4.1 黑体辐射与能量量子化（9 个考点）⬜
先修：WLC-08
1. 热辐射：一切物体都在辐射电磁波，辐射情况与温度有关；温度升高时，波长较短的成分越来越强
2. 黑体：能够完全吸收入射的各种波长的电磁波而不反射的物体，是理想模型；黑体辐射只与温度有关
3. 黑体辐射的实验规律：温度升高时，各种波长的辐射强度都增加，辐射强度的极大值向波长较短的方向移动
4. 经典理论的困难：维恩公式在长波区偏离实验，瑞利公式在短波区与实验严重不符
5. 普朗克的能量子假设：振动着的带电微粒的能量只能是最小能量值 ε 的整数倍，ε = hν，h = 6.626×10⁻³⁴ J·s
6. 能量量子化：微观世界中能量是不连续的、分立的，量子化是微观世界的基本特征
7. 光是电磁波，光子：光是电磁波（→ WLC-08）；爱因斯坦认为光由一个个不可分割的能量子组成，叫光子，能量 ε = hν = hc/λ
8. 能级：原子的能量是量子化的，这些能量值叫能级；原子从高能级跃迁到低能级时放出光子，能量等于两能级之差
9. 原子发光的特点：由于能级分立，原子发射的光谱是一些分立的亮线（→ WLE-06）

### WLE-03　选必3 4.2 光电效应（9 个考点）⬜
先修：WLB-14、WLE-02
1. 光电效应：照射到金属表面的光能使金属中的电子从表面逸出，逸出的电子叫光电子
2. 研究装置：光电管阴极 K 受光照射发射光电子，在阳极 A 与阴极 K 间加正向或反向电压，测量光电流
3. 截止频率：入射光的频率低于截止频率 νc 时，无论光多强都不能发生光电效应；νc 由金属决定
4. 饱和电流：入射光频率一定时，光越强，饱和电流越大，单位时间内逸出的光电子越多
5. 遏止电压：使光电流减小到 0 的反向电压 Uc，eUc 等于光电子的最大初动能；Uc 只与入射光频率有关，与光强无关
6. 瞬时性与经典理论的困难：光照到金属上几乎立即产生光电流；经典电磁理论无法解释截止频率、遏止电压与光强无关和瞬时性
7. 爱因斯坦光电效应方程：Ek = hν − W0；一个电子吸收一个光子，能量一部分克服逸出功 W0，其余成为最大初动能；W0 = hνc
8. 方程对规律的解释：hν < W0 时不能逸出；最大初动能随频率增大而增大；光越强光子数越多，光电子越多
9. 实验验证：密立根测量遏止电压与频率的关系，Uc-ν 图线斜率为 h/e，证实了光电效应方程并测出普朗克常量

### WLE-04　选必3 4.2、4.5 光的波粒二象性与物质波（8 个考点）⬜
先修：WLA-25、WLC-06、WLE-03
1. 康普顿效应：X 射线被石墨散射后，散射线中除与入射波长相同的成分外，还有波长更长的成分
2. 光子的动量：康普顿认为光子不仅有能量，还有动量 p = h/λ；光子与电子碰撞后动量变小，波长变长
3. 光的粒子性：光电效应表明光子具有能量，康普顿效应表明光子还具有动量，都说明光具有粒子性
4. 光的波粒二象性：干涉、衍射、偏振表明光具有波动性，光电效应、康普顿效应表明光具有粒子性，光既有波动性又有粒子性
5. 德布罗意假设：实物粒子也具有波动性，ν = ε/h，λ = h/p，这种波叫物质波（德布罗意波）
6. 物质波的实验验证：电子束穿过晶体得到衍射图样，证实了电子的波动性；后来发现质子、中子等也有波动性
7. 宏观物体的波动性：宏观物体的动量很大，德布罗意波长极小，观察不到波动性
8. 量子力学的建立：描述微观粒子运动规律的理论，推动了原子物理、固体物理等的发展，带来激光、半导体等技术

**E3 原子结构**（WLE-05～WLE-06）

### WLE-05　选必3 4.3 原子的核式结构模型（9 个考点）⬜
先修：WLB-01、WLB-15
1. 阴极射线与电子的发现：汤姆孙根据阴极射线在电场和磁场中的偏转，断定它是带负电的粒子流并测出比荷，这种粒子叫电子
2. 电子发现的意义：电子是原子的组成部分，说明原子是可以再分的
3. 电子电荷量的测定：密立根油滴实验测出电子电荷量，发现电荷是量子化的，带电体的电荷量都是 e 的整数倍
4. 汤姆孙的原子模型：正电荷均匀分布在整个原子球体内，电子镶嵌其中
5. α 粒子散射实验的现象：绝大多数 α 粒子穿过金箔后基本沿原方向前进，少数发生大角度偏转，极少数偏转角大于 90°
6. 卢瑟福的核式结构模型：原子中心有一个很小的核，全部正电荷和几乎全部质量集中在核里，电子在核外绕核运动
7. 对实验现象的解释：原子内部绝大部分是空的；只有极少数 α 粒子离核很近，受很强的库仑斥力而大角度偏转
8. 原子核的电荷与尺度：原子核的电荷数等于原子序数；原子半径数量级为 10⁻¹⁰ m，原子核半径数量级为 10⁻¹⁵ m
9. 核式结构模型的困难：按经典电磁理论，绕核运动的电子要辐射电磁波，原子将不稳定，光谱应是连续的，与事实不符

### WLE-06　选必3 4.4 氢原子光谱与玻尔模型（9 个考点）⬜
先修：WLE-02、WLE-05
1. 光谱：线状谱是一条条分立的亮线，连续谱是连在一起的光带；各种原子都有自己的特征谱线，可用于光谱分析
2. 氢原子光谱的实验规律：巴耳末公式 1/λ = R∞(1/2² − 1/n²)，n = 3，4，5，…；氢原子光谱是分立的线状谱
3. 经典理论的困难：经典理论无法解释原子的稳定性和原子光谱的分立特征
4. 玻尔的轨道量子化与定态假设：电子的轨道是量子化的；原子只能处于一系列不连续的能量状态，定态中不辐射能量
5. 玻尔的频率条件：原子从高能级 En 跃迁到低能级 Em 时辐射光子，hν = En − Em；吸收光子则向高能级跃迁
6. 氢原子的能级：En = E1/n²，E1 = −13.6 eV，rn = n²r1；n = 1 为基态，其余为激发态，n→∞ 时能量为 0
7. 电离：使处于某能级的氢原子电离所需的最小能量等于该能级能量的绝对值
8. 概念辨析：原子吸收光子发生跃迁时，光子能量必须恰好等于两能级之差；而使原子电离时，光子能量大于等于电离能即可
9. 玻尔理论的成功与局限：成功解释了氢原子光谱；但保留了经典轨道概念，不能解释较复杂原子的光谱；量子力学用电子云描述电子

**E4 原子核**（WLE-07～WLE-09）

### WLE-07　选必3 5.1、5.2 原子核的组成与放射性衰变（10 个考点）⬜
先修：WLB-15、WLE-05
1. 天然放射现象：贝克勒尔发现铀能自发地发出射线；它说明原子核内部有复杂的结构
2. 三种射线：α 射线是氦核流，电离作用强、穿透能力弱；β 射线是电子流，穿透能力较强；γ 射线是电磁波，穿透能力最强
3. 质子和中子的发现：卢瑟福用 α 粒子轰击氮核发现质子并预言中子；查德威克用 α 粒子轰击铍发现中子
4. 原子核的组成：原子核由质子和中子组成，统称核子；电荷数 Z 等于质子数，质量数 A 等于核子数；质子数相同、中子数不同的互称同位素
5. α 衰变：原子核放出一个 α 粒子，质量数减少 4，电荷数减少 2
6. β 衰变：原子核放出一个电子，质量数不变，电荷数增加 1；实质是核内一个中子转化为一个质子和一个电子
7. γ 射线的产生：衰变后的新核处于高能级，向低能级跃迁时放出 γ 光子，不改变质量数和电荷数
8. 半衰期：放射性元素的原子核有半数发生衰变所需的时间；由核内部因素决定，与化学状态和外部条件无关，是大量原子核的统计规律；经过时间 t，剩余的原子核数 N = N₀(1/2)^(t/T)（T 为半衰期）
9. 核反应与核反应方程：原子核在其他粒子轰击下产生新核的过程；核反应方程遵循质量数守恒和电荷数守恒，用箭头连接
10. 放射性同位素的应用与防护：用作射线源（探伤、测厚、放疗、育种）和示踪原子；过量射线危害人体，要做好防护、防止污染

### WLE-08　选必3 5.3 核力与结合能（9 个考点）⬜
先修：WLE-01、WLE-07
1. 四种基本相互作用：引力相互作用、电磁相互作用、强相互作用、弱相互作用
2. 核力：核子间的相互作用，是强相互作用的表现，是短程力，作用范围约 10⁻¹⁵ m，使核子克服库仑斥力紧密结合
3. 弱相互作用：引起原子核 β 衰变的原因，作用范围比强相互作用更短
4. 结合能：把原子核分开成核子需要的能量，也是核子结合成原子核时放出的能量
5. 比结合能：结合能与核子数之比，也叫平均结合能；比结合能越大，原子核越稳定
6. 比结合能曲线：中等质量的原子核比结合能最大；重核裂变、轻核聚变后比结合能都增大，都释放能量
7. 质量亏损：原子核的质量小于组成它的核子的质量之和
8. 质能方程：E = mc²，核反应释放的能量 ΔE = Δmc²；1 u 的质量相当于 931.5 MeV 的能量
9. 概念辨析：质量亏损不是核子数减少，核反应前后质量数守恒；结合能不是原子核“具有”的能量

### WLE-09　选必3 5.4、5.5 核裂变、核聚变与“基本”粒子（10 个考点）⬜
先修：WLA-27、WLE-08
1. 重核裂变：铀 235 俘获中子后分裂成两个中等质量的核，放出几个中子并释放能量
2. 链式反应：裂变产生的中子使裂变一代接一代进行；能发生链式反应的最小体积叫临界体积，相应质量叫临界质量
3. 核反应堆：铀棒作燃料；慢化剂（石墨、重水或普通水）通过碰撞使快中子减速；镉棒吸收中子以控制反应速度
4. 核电站：核能转化为内能，再经汽轮机、发电机转化为电能；要防止放射性泄漏，妥善处理核废料
5. 轻核聚变：两个轻核结合成质量较大的核并释放能量，如氘核与氚核聚变成氦核并放出一个中子
6. 聚变的条件：要使原子核接近到核力作用范围，必须克服库仑斥力，需要极高的温度，所以叫热核反应；太阳内部进行着热核反应
7. 受控热核反应：聚变燃料丰富、更安全清洁，难点在于控制；约束方式有磁约束（托卡马克）和惯性约束
8. 粒子的发现与分类：人们发现了数以百计的粒子，许多粒子有反粒子；按相互作用可分为强子、轻子、规范玻色子和希格斯玻色子
9. 夸克模型：强子由夸克组成，夸克带的电荷量为元电荷的 ±1/3 或 ±2/3；加速器和粒子探测器是研究粒子的重要工具
10. 人类对物质结构的探索历程：从分子、原子到电子、原子核、质子和中子，再到夸克，人类对物质结构的认识不断深入

## 篇F（WLF）实验：21 个学生必做实验，一个实验一期：测量基础、力学、电学、光学、热学实验

**F1 测量基础**（WLF-01～WLF-02）

### WLF-01　必一 学生实验 实验基础：误差和有效数字（8 个考点）⬜
先修：WLA-02
1. 做好物理实验的基本要求：明确实验目的、理解实验原理、制订实验计划、安全规范操作、如实记录原始数据，数据要注明单位
2. 误差：测量值与真实值之间的差异；误差不可避免，只能尽量减小；误差不是错误，读错、记错、操作失误造成的是错误，应当避免
3. 偶然误差：由各种偶然因素造成，测量值时而偏大、时而偏小，偏大和偏小的机会比较接近；多次测量取平均值可以减小偶然误差
4. 系统误差：由仪器本身不精确、实验原理不完善或实验方法粗略造成，多次重复测量时结果总是偏大或总是偏小；多次测量取平均值不能减小，要通过校准仪器、改进原理和方法来减小
5. 绝对误差与相对误差：绝对误差是测量值与真实值之差的绝对值，相对误差 = 绝对误差/测量值；绝对误差相同时，被测量越大相对误差越小，因此可测多圈的总长度、多个周期的总时间再求平均（累积法）
6. 有效数字：测量结果中能够反映被测量大小的带有一位不可靠数字的近似数字；从左边第一个不为零的数字算起，用来定位的 0 不是有效数字，末尾的 0 是有效数字（19.0 mm 与 19 mm 精度不同）；很大或很小的数用科学记数法表示，如 3.60×10³ m
7. 读数估读的一般规则：读数时一般要估读到仪器分度值的下一位，这一位就是不可靠数字；游标卡尺、秒表、电阻箱等按其读数方式不估读（→ WLF-02）
8. 数据处理的常用方法：列表法要写明物理量、单位和测量次数，便于发现规律；图像法要选好坐标轴和标度，描点后用直线或平滑曲线连接，使尽量多的点落在线上，其余点均匀分布在两侧，明显偏离的点舍去；图像为曲线时可改换坐标使图线成为直线，再由斜率、截距得出物理量

### WLF-02　必三 11.3 长度的测量及其测量工具的选用（8 个考点）⬜
先修：WLF-01
1. 测量工具的选用：根据被测长度的大小和所需的精度选择工具；较长的长度用刻度尺，内径、外径、深度等用游标卡尺，金属丝直径、薄板厚度等很小的长度用螺旋测微器
2. 刻度尺：分度值一般为 1 mm，读数估读到分度值的下一位，以 mm 为单位时读到 0.1 mm；测量时刻度尺要紧贴被测物体，视线与尺面垂直
3. 游标卡尺的结构：由主尺和可沿主尺滑动的游标尺组成；外测量爪测外径和厚度，内测量爪测内径，深度尺测深度，紧固螺钉用来固定游标尺
4. 游标卡尺的原理与精度：游标尺上 n 个分度的总长比主尺上 n 个分度的总长短 1 mm，每个分度比主尺的 1 mm 短 1/n mm；10 分度、20 分度、50 分度的游标卡尺精度分别为 0.1 mm、0.05 mm、0.02 mm
5. 游标卡尺的读数：读数 = 主尺上游标零刻线左侧的整毫米数 + 游标尺上与主尺刻线对齐的那条刻线的序号 × 精度；游标卡尺不估读
6. 螺旋测微器的原理：测微螺杆的螺距为 0.5 mm，可动刻度一周分为 50 等份，可动刻度每转过一个等份，测微螺杆前进或后退 0.01 mm，精度为 0.01 mm
7. 螺旋测微器的读数：读数 = 固定刻度读数（注意半毫米刻线是否露出）+ 可动刻度对齐的格数（估读一位）× 0.01 mm；以 mm 为单位时读数有三位小数，又称千分尺
8. 螺旋测微器的使用：测微螺杆快靠近被测物体时改用微调旋钮，听到“喀喀”声时停止转动，再拨动止动旋钮使测微螺杆固定后读数，避免压力过大损坏仪器或影响读数

**F2 力学实验**（WLF-03～WLF-11）

### WLF-03　必一 1.3、2.1 测量做直线运动物体的瞬时速度（8 个考点）⬜
先修：WLA-02、WLA-03、WLA-05、WLF-01
1. 实验目的：用打点计时器测量纸带的平均速度和瞬时速度，并通过 v-t 图像探究小车速度随时间变化的规律
2. 打点计时器：电磁打点计时器使用低压交变电源，电火花计时器使用 220 V 交变电源；电源频率为 50 Hz 时都每隔 0.02 s 打一个点，纸带上的点迹同时记录了时间和位移
3. 器材及作用：一端带滑轮的长木板放置小车并引导运动，槽码通过细绳牵引小车，纸带穿过限位孔记录小车的运动，刻度尺测量点迹间的距离
4. 关键步骤与注意事项：细绳与木板平行；小车从靠近打点计时器的位置释放；先接通电源、后释放小车；打完点及时断开电源；换纸带重复实验，选点迹清晰的纸带
5. 计数点的选取：舍去开头过于密集的点，从清晰的点开始取计数点；每 5 个点取一个计数点时，相邻计数点间的时间间隔 T = 0.1 s
6. 瞬时速度的测量原理：用包含该点的一小段时间内的平均速度代替该点的瞬时速度，时间越短越接近瞬时速度；常取该点前后相邻两段，vn = (xn + xn+1)/2T；光电门测速 v = d/Δt 也是同样的道理，遮光条越窄越接近瞬时速度
7. 数据处理：把各计数点的速度列表，在 v-t 坐标系中描点，用直线拟合，使尽量多的点在直线上，其余点均匀分布在两侧；直线的斜率表示加速度，纵轴截距表示计时起点的速度；图像法能减小偶然误差
8. 实验结论与误差：小车的 v-t 图像是一条倾斜的直线，速度随时间均匀增加，小车做匀加速直线运动；误差主要来自长度测量、用平均速度代替瞬时速度以及描点作图

### WLF-04　必一 3.1 探究弹簧弹力与形变量的关系（7 个考点）⬜
先修：WLA-06、WLF-01、WLF-02
1. 实验目的：探究弹簧弹力的大小与弹簧伸长量之间的定量关系，测量弹簧的劲度系数
2. 实验原理：弹簧下端悬挂钩码，钩码静止时弹簧弹力的大小等于钩码所受的重力；用刻度尺测出弹簧的原长 l0 和挂钩码后的长度 l，伸长量 x = l − l0
3. 器材及作用：铁架台悬挂弹簧，钩码提供已知大小的拉力，刻度尺竖直固定在弹簧旁测量弹簧长度
4. 关键步骤与注意事项：弹簧竖直悬挂，刻度尺竖直并靠近弹簧；待钩码静止后再读数，读数时视线与指针所对刻度相平；逐个增挂钩码记录多组数据；所挂钩码不能使弹簧超过弹性限度
5. 数据处理：以弹力 F 为纵轴、伸长量 x 为横轴描点，用直线拟合，得到过原点的直线，斜率等于劲度系数 k；若横轴改用弹簧长度 l，图线与横轴的交点表示原长 l0，斜率仍为 k
6. 易错提醒：x 是弹簧的形变量而不是弹簧的长度；图线上端发生弯曲，说明拉力已超过弹簧的弹性限度，这部分数据不满足线性关系
7. 实验结论与误差：在弹性限度内，弹簧弹力与形变量成正比，即 F = kx；误差主要来自弹簧长度的测量和描点作图，多测几组数据、用图像法处理可减小偶然误差；弹簧自身重力会使图线不过原点，但不影响斜率

### WLF-05　必一 3.4 探究两个互成角度的力的合成规律（8 个考点）⬜
先修：WLA-09、WLF-01
1. 实验目的：探究两个互成角度的力与它们的合力之间满足什么关系

7. 概念辨析：按平行四边形作出的 F 是合力的理论值，用一个测力计拉出的 F′ 是合力的实际测量值，F′ 一定沿橡皮条的方向
8. 实验结论与误差：在误差允许的范围内，F 与 F′ 大小相等、方向相同，两个互成角度的力的合成遵从平行四边形定则；误差主要来自测力计的读数、记录力的方向和作图

### WLF-06　必一 4.2 探究加速度与物体受力、物体质量的关系（9 个考点）⬜
先修：WLA-12、WLF-03
1. 实验目的与方法：探究加速度与力、质量的定量关系；采用控制变量法，保持小车质量不变研究加速度与力的关系，保持拉力不变研究加速度与质量的关系

### WLF-07　必二 5.3 探究平抛运动的特点（8 个考点）⬜
先修：WLA-14、WLA-15、WLF-01
1. 实验目的与思路：探究平抛运动在水平方向和竖直方向的运动特点；把平抛运动分解为水平方向和竖直方向两个分运动，分别研究
2. 记录运动的方法：用频闪照相或录制视频的方法，记录小球每隔相等时间所到达的位置，分析它在两个方向上的位移随时间变化的规律
3. 竖直分运动的探究：用小锤击打弹性金属片，A 球沿水平方向抛出，同时 B 球被释放自由下落；改变装置高度和击打力度多次实验，两球总是同时落地，说明平抛运动在竖直方向的分运动是自由落体运动
4. 器材及作用（描轨迹）：斜槽使小球获得水平初速度，背板上的白纸和复写纸记录小球落点，可上下调节的挡板确定小球经过的位置，铅垂线确定竖直方向

6. 水平分运动的探究：描出平抛运动的轨迹，依据竖直分运动是自由落体运动，在轨迹上找出时间间隔相等的点（竖直位移之比为 1∶4∶9…的点），看相邻点之间的水平位移是否相等
7. 误差来源：斜槽末端不水平、小球释放位置不同、坐标原点或竖直方向确定不准、描点不准确以及空气阻力
8. 实验结论：平抛运动可以分解为水平方向的匀速直线运动和竖直方向的自由落体运动

### WLF-08　必二 6.2 探究向心力大小与半径、角速度、质量的关系（8 个考点）⬜
先修：WLA-16、WLA-17、WLF-01
1. 实验目的与方法：探究向心力大小与小球质量 m、转动半径 r、角速度 ω 的关系；采用控制变量法，每次只改变一个量，保持另外两个量不变
2. 向心力演示器的原理：转动手柄使长槽和短槽随变速塔轮转动，槽内小球做匀速圆周运动；横臂上的挡板对小球的弹力提供向心力，小球对挡板的反作用力通过横臂杠杆使弹簧测力套筒下降，标尺露出的等分格数显示两球所受向心力的比值
3. 改变角速度：皮带套在两个半径不同的塔轮上，两塔轮边缘的线速度大小相等，由 v = ωr 知角速度与塔轮半径成反比，可得到不同的角速度之比
4. 改变半径与质量：把小球放在长槽或短槽上不同的挡板处改变转动半径；换用质量不同的小球改变质量
5. 关键步骤与注意事项：实验前检查皮带位置和小球位置是否符合要控制的条件；摇动手柄时转速要平稳、逐渐加快，待标尺示数稳定后读数；转速不宜过快，以免小球飞出
6. 数据处理：分别记录各组 m、r、ω 之比和标尺显示的向心力之比；F-ω 图像是曲线，改作 F-ω² 图像得到过原点的直线
7. 误差说明：标尺的等分格数只能粗略显示向心力的比值，读数存在偶然误差；摇速不稳定会使示数波动
8. 实验结论：向心力的大小与质量成正比、与半径成正比、与角速度的二次方成正比，即 Fn = mω²r

### WLF-09　必二 8.5 验证机械能守恒定律（8 个考点）⬜
先修：WLA-24、WLF-03
1. 实验目的：验证只有重力做功时，物体的动能与重力势能相互转化而总的机械能保持不变
2. 实验原理：物体下落高度 Δh 时，比较重力势能的减少量 mgΔh 与动能的增加量 ½mv2² − ½mv1² 是否相等；等式两边都含质量 m，可以不测质量
3. 参考案例 1 的器材及作用：打点计时器竖直固定在铁架台上，纸带记录重物下落的时间和位置；重物选质量大、体积小（密度大）的，以减小空气阻力的影响；刻度尺测下落高度
4. 关键步骤与注意事项：两个限位孔在同一条竖直线上，减小纸带与限位孔的摩擦；手提纸带上端，让重物靠近打点计时器；先接通电源，后松开纸带；选点迹清晰的纸带
5. 易错提醒：瞬时速度要由纸带求出，用该点前后相邻两段的平均速度，vn = (hn+1 − hn−1)/2T（→ WLF-03）；不能用 v = gt 或 v = √(2gh) 计算，那样等于已经默认机械能守恒
6. 数据处理：在纸带上任取两点，验证 gΔh 与 ½v2² − ½v1² 是否相等；以起始点为参考时验证 gh = ½v²；也可作 ½v²-h 图像，若是过原点、斜率接近 g 的直线，即验证了机械能守恒
7. 参考案例 2：让滑块沿倾斜的气垫导轨下滑，用光电门和数字计时器测遮光时间，由遮光条宽度求瞬时速度，再测出下降的高度，同样比较重力势能的减少量与动能的增加量
8. 误差来源与实验结论：空气阻力和纸带受到的摩擦使动能的增加量略小于重力势能的减少量，属于系统误差；在误差允许的范围内，重力势能的减少量等于动能的增加量，机械能守恒

### WLF-10　选必1 1.4 验证动量守恒定律（8 个考点）⬜
先修：WLA-26、WLA-27、WLF-03、WLF-07
1. 实验目的与思路：让两个质量不同的物体在同一直线上碰撞，测出它们的质量和碰撞前后的速度，检验 m1v1 + m2v2 = m1v1′ + m2v2′ 是否成立
2. 参考案例 1 的器材及作用：气垫导轨使滑块几乎不受摩擦，碰撞时系统所受外力的矢量和近似为 0；光电门和数字计时器记录遮光时间 Δt，由 v = d/Δt 求速度；天平测滑块质量
3. 案例 1 的操作要点：气垫导轨调成水平（滑块通过两个光电门的时间相等）；速度是矢量，计算时先规定正方向，与正方向相反的速度取负值
4. 案例 1 可研究的碰撞情形：滑块装弹性碰撞架，碰后分开；装撞针和橡皮泥（或尼龙搭扣），碰后连成一体；两滑块间压缩轻弹簧后由静止弹开，向相反方向运动
5. 参考案例 2 的原理：入射小球从斜槽上滚下，与静止在斜槽末端的被碰小球碰撞，两球都做平抛运动；下落高度相同则飞行时间相同，水平距离与速度成正比，可用水平距离代替速度（→ WLF-07）
6. 案例 2 的器材与要求：天平测两球质量，刻度尺测水平距离，铅垂线确定斜槽末端在地面上的投影 O；斜槽末端水平；入射小球质量大于被碰小球以防反弹，两球大小相同以保证对心碰撞；入射小球每次从同一位置由静止释放，斜槽不必光滑
7. 案例 2 的数据处理：多次实验，用尽量小的圆把落点圈起来，圆心作为平均落点；验证 m1·OP 与 m1·OM + m2·ON 是否相等（P 为入射小球单独滚下时的落点，M、N 为碰后入射小球、被碰小球的落点）
8. 实验结论：在误差允许的范围内，两物体碰撞前的总动量等于碰撞后的总动量；误差主要来自摩擦、导轨不水平或斜槽末端不水平、速度和落点位置的测量

### WLF-11　选必1 2.5 用单摆测量重力加速度的大小（8 个考点）⬜
先修：WLA-31、WLF-01、WLF-02
1. 实验原理：摆角较小时单摆做简谐运动，由周期公式 T = 2π√(l/g) 得 g = 4π²l/T²，只要测出摆长 l 和周期 T 即可求出当地的重力加速度
2. 器材的选择：摆线选细而不易伸长的线，长度约 1 m；摆球选质量大、体积小的球，减小空气阻力的影响；线的上端用铁夹夹紧固定，不缠绕在横杆上，防止摆动时摆长改变
3. 摆长的测量：摆长是悬点到摆球球心的距离，等于摆线长度加小球半径；线长用刻度尺测量，小球直径用游标卡尺测量（→ WLF-02）
4. 周期的测量：摆角要小；从小球经过最低点（平衡位置）时开始计时，这里速度大、位置容易判断，计时误差小；用停表测 30～50 次全振动的总时间，再求出周期，这是累积法（→ WLF-01）
5. 易错提醒：按下停表时计数为“0”，之后小球每次同方向经过最低点计一次全振动；摆球应在同一竖直平面内摆动，不能做成圆锥摆
6. 数据处理：平均值法，改变摆长做多次实验，分别算出 g 再取平均值；图像法，作 T²-l 图像，得到过原点的直线，斜率 k = 4π²/g，所以 g = 4π²/k
7. 误差来源：摆长测量不准（如漏加小球半径）、全振动次数数错、计时开始或结束时停表按早按晚、摆角过大、悬点松动；摆长漏加半径时 T²-l 图线平移、不过原点，但斜率不变，由斜率求出的 g 不受影响
8. 实验结论：测出的 g 值与当地重力加速度的公认值在误差允许范围内相符，同时验证了单摆周期与摆长的定量关系

### WLF-12　必三 10.4 观察电容器的充、放电现象（7 个考点）⬜
先修：WLB-06、WLB-07
1. 实验目的：观察电容器充电和放电过程中电流和电压的变化，认识电容器储存电荷的作用
2. 实验电路与器材作用：直流电源提供电压；单刀双掷开关接电源一侧时电容器充电，接另一侧时电容器通过电阻放电；电阻限制电流；电流表（或电流传感器）显示电流的大小和方向，电压表显示电容器两端电压
3. 充电过程：电流从电源正极流向电容器的正极板，电流由大逐渐减小到 0；电容器两端电压逐渐升高，最后等于电源电压；两极板带上等量异种电荷，电源的能量转化为电容器中储存的电场能
4. 放电过程：电流方向与充电时相反，电流由大逐渐减小到 0；电容器两端电压逐渐减小到 0；两极板上的电荷中和，电场能转化为其他形式的能
5. 用电流传感器记录 I-t 图像：传感器与计算机相连，能把电流随时间变化的情况在屏幕上画出；充、放电电流方向相反，两条图线分别在时间轴的两侧
6. 数据处理：I-t 图线与时间轴所围的面积表示电容器充入或放出的电荷量 Q；可以数图线下的方格估算面积（大于半格算一格，小于半格舍去），再由 C = Q/U 估算电容
7. 实验结论：充、放电过程中电流都是逐渐减小到 0 的；改变电阻 R 只改变充、放电的快慢，不改变电荷量；改变电源电压或换用不同的电容器，电荷量 Q = CU 随之改变

### WLF-13　必三 11.3 测量金属丝的电阻率（8 个考点）⬜
先修：WLB-07、WLB-08、WLF-01、WLF-02
1. 实验原理：由电阻定律 R = ρl/S 和 S = πd²/4 得 ρ = πd²R/4l，需要测出金属丝的电阻 R、接入电路的有效长度 l 和直径 d
2. 长度与直径的测量：有效长度用毫米刻度尺测量，测 3 次取平均值；直径用螺旋测微器在金属丝的不同位置测量 3 次取平均值（读数方法 → WLF-02）
3. 器材及作用：电压表、电流表测金属丝两端的电压和通过的电流；滑动变阻器调节电路中的电流和电压，以便测多组数据；电源、开关、导线组成电路
4. 测量电路：金属丝电阻较小，远小于电压表内阻，采用电流表外接法；电流表外接时电压表分流，电流测量值大于通过金属丝的电流，电阻测量值偏小
5. 控制电路：滑动变阻器可采用限流式或分压式接法；闭合开关前，滑片放在使金属丝两端电压最小的位置，保护电表和金属丝
6. 关键步骤与注意事项：先测直径，再接入电路后测有效长度（两端接线柱之间的长度）；通过金属丝的电流不宜过大、通电时间不宜过长，以免金属丝温度明显升高使电阻率变化
7. 数据处理：改变滑片位置，读取多组 U、I；可以分别算出 R 再取平均值，也可以作 U-I 图像，由直线的斜率求 R，再代入 ρ = πd²R/4l 求电阻率
8. 误差来源：电流表外接带来的系统误差使电阻率测量值偏小；直径在公式中以平方出现，它的测量误差对结果影响最大；长度、电表读数存在偶然误差，可多次测量取平均值或用图像法减小

### WLF-14　必三 11.5 用多用电表测量电学中的物理量（9 个考点）⬜
先修：WLB-07、WLB-08、WLB-10
1. 实验目的：练习使用多用电表测量电压、电流和电阻，用多用电表测量二极管的正、反向电阻
2. 多用电表的结构：表盘上有电阻、直流电流和电压等刻度线；选择开关周围标有测量功能和量程；还有指针定位螺丝、欧姆调零旋钮和红、黑表笔，红表笔插“+”插孔，黑表笔插“−”插孔
3. 【教材拓展】欧姆表的原理：表头、电池和可变电阻串联，测电阻时 I = E/(R内 + Rx)；电流与 Rx 不成线性关系，所以电阻刻度不均匀，左密右疏，电阻的零刻度在最右端，“∞”在最左端
4. 欧姆调零与中值电阻：红、黑表笔短接，调节欧姆调零旋钮使指针指在电阻的零刻度（满偏）；指针指在刻度盘中央时，被测电阻等于欧姆表的内阻
5. 易错提醒：无论测什么量，电流都从红表笔流入、黑表笔流出；用欧姆挡时，黑表笔连接的是表内电池的正极
6. 测电压和电流：使用前检查指针是否指在左端零刻度，否则调指针定位螺丝（机械调零）；测电压时与被测元件并联，测电流时串联接入电路，红表笔接电势高的一端；按所选量程在相应刻度线上读数
7. 测电阻的步骤：选择欧姆挡的倍率，使指针尽量指在刻度盘中央附近；欧姆调零；把被测电阻与电源和其他元件断开后测量；读数乘以倍率；每次换倍率后都要重新欧姆调零
8. 测二极管的正、反向电阻：二极管具有单向导电性；黑表笔接二极管正极、红表笔接负极时测得正向电阻，阻值较小；反接时测得反向电阻，阻值很大
9. 使用后的处理：拔出表笔，把选择开关旋到“OFF”位置或交流电压最高挡；长期不用时取出表内电池

### WLF-15　必三 12.3 测量电源的电动势和内阻（8 个考点）⬜
先修：WLB-08、WLB-10、WLF-01
1. 实验原理：由闭合电路的欧姆定律 E = U + Ir，改变外电路电阻，测出两组 U、I 即可列方程求出 E 和 r；实际测量多组数据以减小误差
2. 器材及作用：电压表测路端电压，电流表测通过电源的电流，滑动变阻器改变外电路电阻；被测电源常用干电池，开关、导线组成电路
3. 关键步骤与注意事项：选内阻较大的旧干电池，路端电压的变化才明显；闭合开关前滑片放在使接入电阻最大的位置；电流不宜过大，读数要快，读完及时断开开关，以免电池的电动势和内阻明显变化
4. 数据处理：以 U 为纵轴、I 为横轴描点，作一条直线使尽量多的点落在线上或均匀分布在两侧；纵轴截距等于电动势 E，斜率的绝对值等于内阻 r
5. 坐标的选取：路端电压变化范围较小时，纵轴可以不从 0 开始以充分利用坐标纸；这时图线与横轴的交点不再是短路电流，但斜率的绝对值仍等于内阻
6. 误差来源：电压表直接并联在电源两端测路端电压时，电压表分流使电流表示数小于通过电源的电流，E 和 r 的测量值都偏小；读数和作图带来偶然误差
7. 其他方案：用电流表和电阻箱，E = I(R + r)；用电压表和电阻箱，E = U + Ur/R；改变电阻箱阻值测多组数据，同样可以求出 E 和 r，也可把关系式变形为线性关系后作图处理
8. 实验结论：路端电压随电流的增大而线性减小，U-I 图线是一条倾斜的直线，由它可求出电源的电动势和内阻

### WLF-16　选必2 2.1 探究影响感应电流方向的因素（9 个考点）⬜
先修：WLB-11、WLB-17
1. 实验目的：探究感应电流的方向与哪些因素有关，找出判断感应电流方向的一般规律
2. 实验思路：感应电流的方向不能直接看出，由电流表指针的偏转方向判断电流在线圈中的流向，再结合线圈的绕向用安培定则确定感应电流的磁场方向，把它与原磁场方向、磁通量的变化联系起来
3. 器材及作用：条形磁体提供原磁场；绕向已知的线圈（螺线管）作为闭合回路的一部分；零刻度在中央的灵敏电流表显示感应电流的方向；导线连接成闭合回路
4. 实验前的准备：先查明电流从哪个接线柱流入时指针向哪一侧偏转，再弄清线圈导线的绕向；否则无法由指针偏转推出线圈中的电流方向
5. 实验步骤：分别把条形磁体的 N 极插入线圈、N 极从线圈中抽出、S 极插入线圈、S 极从线圈中抽出，观察每种情况下指针的偏转方向
6. 记录方法：用表格记录四种情况下的原磁场方向、穿过线圈的磁通量是增大还是减小、感应电流的方向，以及由此推出的感应电流的磁场方向
7. 实验结论：穿过线圈的磁通量增大时，感应电流的磁场与原磁场方向相反；磁通量减小时，感应电流的磁场与原磁场方向相同，即“增反减同”
8. 归纳为楞次定律：感应电流的磁场总要阻碍引起感应电流的磁通量的变化；从相对运动看，磁体靠近线圈时受到排斥、远离时受到吸引（→ WLB-17）
9. 易错提醒：感应电流的方向由原磁场方向和磁通量的增减共同决定，只看其中一个因素无法确定；磁体在线圈中静止时磁通量不变，指针不偏转

### WLF-17　选必2 3.3 探究变压器原、副线圈电压与匝数的关系（9 个考点）⬜
先修：WLB-19、WLB-21、WLF-14
1. 实验目的：探究变压器原、副线圈两端的电压与原、副线圈匝数的关系
2. 实验原理：原线圈中的交变电流在铁芯中产生交变的磁通量，穿过副线圈，使副线圈中产生感应电动势，这是互感现象（→ WLB-21）
3. 器材及作用：可拆变压器的铁芯可以拆装，线圈上有多个接线柱，可选用不同的匝数；学生电源提供低压交流电；多用电表的交流电压挡测量原、副线圈两端的电压（→ WLF-14）
4. 实验方法：控制变量法；先保持原线圈的电压和匝数不变，改变副线圈的匝数，测副线圈电压；再保持副线圈的匝数不变，改变原线圈的匝数，测副线圈电压
5. 安全与操作要求：只用低压交流电源，所用电压不超过 12 V；通电时不用手接触裸露的导线和接线柱；测电压时先用最大量程挡试测，再换用适当的挡位；连接好电路并检查无误后才能接通电源
6. 数据处理：记录每次的匝数 n1、n2 和电压 U1、U2，分别算出电压之比 U1/U2 与匝数之比 n1/n2，比较二者是否相等
7. 误差来源：实际变压器有能量损失，线圈有电阻会发热，铁芯中有涡流，还有一部分磁感线漏到铁芯外，所以实测的副线圈电压略小于按匝数比算出的值，这种偏差总是偏向一侧（→ WLF-01）
8. 实验结论：在误差允许的范围内，原、副线圈的电压之比等于两个线圈的匝数之比，即 U1/U2 = n1/n2；没有能量损失的变压器叫理想变压器
9. 易错提醒：原线圈接直流电源时，铁芯中的磁通量不变，副线圈两端没有电压；铁芯没有装好、不闭合时漏磁很多，副线圈电压明显偏小

2. 实验原理：传感器感受被测量（磁场、光照等），把它转换为电学量或电路的通断，再通过电路控制执行装置动作，从而实现自动控制（→ WLB-22）

### WLF-19　选必1 4.1 测量玻璃的折射率（9 个考点）⬜
先修：WLC-03、WLF-01
1. 实验目的：测量玻璃的折射率，加深对折射定律的理解
2. 实验原理：用两面平行的玻璃砖，找出入射光线和对应的出射光线，从而画出玻璃砖内的折射光线，测出入射角 θ1 和折射角 θ2，由 n = sinθ1/sinθ2 求折射率（→ WLC-03）
3. 器材及作用：两面平行的玻璃砖是待测介质；白纸铺在木板上，用图钉固定，用来画光路；大头针确定光线的位置；刻度尺、铅笔画线，量角器测角度
4. 确定光路：在白纸上画出一条直线作为界面 aa′，过入射点画法线和入射光线；把玻璃砖放好，画出另一界面 bb′；在入射光线上插两个大头针 A、B，在另一侧透过玻璃砖观察，插大头针 C 挡住 A、B 的像，再插大头针 D 挡住 C 和 A、B 的像；C、D 确定出射光线，连接入射点和出射点即得玻璃砖内的折射光线
5. 注意事项：大头针要竖直插，同侧两个大头针的间距适当大一些；入射角不宜太小也不宜太大；不用手触摸玻璃砖的光学面，不把玻璃砖当尺子画界线；实验过程中玻璃砖与白纸的相对位置不能改变；选用宽度较大的玻璃砖
6. 数据处理：改变入射角，测出多组 θ1、θ2，分别算出折射率再取平均值；也可以作 sinθ1-sinθ2 图像，它是过原点的直线，斜率就是折射率
7. 不用量角器的方法：以入射点为圆心画圆，与入射光线、折射光线各交于一点，过两个交点分别向法线作垂线，两条垂线段的长度之比等于 sinθ1 与 sinθ2 之比，即为折射率
8. 误差来源：入射光线和出射光线确定得不准，界线画得不准，角度测量不准；所画两条界线的间距大于玻璃砖的实际宽度时，折射角测量值偏大，折射率偏小，间距画小时折射率偏大；大头针间距大些、多测几组数据可减小误差
9. 实验结论：对同一块玻璃，入射角改变时 sinθ1/sinθ2 保持不变，这个比值就是玻璃的折射率；玻璃砖两面不平行时出射光线不再与入射光线平行，但仍能用同样方法测出折射率

### WLF-20　选必1 4.4 用双缝干涉实验测量光的波长（9 个考点）⬜
先修：WLC-05、WLF-02
1. 实验目的：观察双缝干涉图样，测量单色光的波长
2. 实验原理：双缝干涉中相邻两条亮条纹（或暗条纹）的间距 Δx = lλ/d，所以 λ = dΔx/l；d 为双缝间距（已知），l 为双缝到屏的距离，Δx 由测量头测出（→ WLC-05）
3. 装置与各元件的作用：沿遮光筒依次为光源、滤光片、单缝、双缝、遮光筒、毛玻璃屏、测量头；滤光片得到单色光，单缝相当于一个线光源，双缝得到两个相干光源，遮光筒挡住外界杂光
4. 调节要求：使光源、滤光片、单缝、双缝的中心都在遮光筒的轴线上；单缝与双缝互相平行，屏上才能出现清晰的干涉条纹
5. 测量头：由分划板、目镜、手轮等组成；转动手轮时分划板左右移动，读数规则与螺旋测微器相同（→ WLF-02）
6. 测条纹间距：转动手轮，使分划板的中心刻线与某条亮条纹的中心对齐，记下读数；再转到另一条亮条纹的中心，记下读数；两次读数之差为 n 条亮条纹之间的距离 a，Δx = a/(n − 1)；双缝到屏的距离 l 用刻度尺测量
7. 观察现象：换用不同颜色的滤光片，条纹间距不同，红光的条纹间距比绿光、紫光的大；去掉滤光片，屏上出现彩色条纹，中央为白色亮条纹
8. 误差来源及减小方法：主要来自 Δx 和 l 的测量；测多条亮条纹之间的总距离再求 Δx，比只测相邻两条更准确；分划板中心刻线要与条纹平行并对准条纹中心；多次测量取平均值
9. 易错提醒：n 条亮条纹之间只有 n − 1 个间距，不能用 a/n 计算条纹间距

**F5 热学实验**（WLF-21～WLF-22）

### WLF-21　选必3 1.2 用油膜法估测油酸分子的大小（9 个考点）⬜
先修：WLD-01、WLF-01
1. 实验目的：用油膜法估测油酸分子的直径，体会由宏观量的测量得到微观量的方法
2. 实验原理：把油酸分子看成球形并认为它们一个挨一个紧密排列；油酸在水面上形成单分子油膜，油膜的厚度就是分子的直径，测出一滴油酸的体积 V 和它形成的油膜面积 S，则 d = V/S
3. 器材及作用：油酸酒精溶液是实验用的油；浅盘盛水；爽身粉撒在水面上显示油膜的轮廓；注射器（或滴管）和量筒（或烧杯）测一滴溶液的体积；带坐标方格的玻璃板（或透明塑料板）和彩笔描画油膜轮廓、计算面积
4. 用油酸酒精溶液的原因：纯油酸一滴的量也很难在水面上形成单分子油膜，用酒精稀释后才能充分展开；酒精溶于水并很快挥发，水面上留下纯油酸形成的油膜
5. 测一滴溶液中纯油酸的体积：用注射器吸取一定体积的溶液，一滴一滴地滴入量筒（或烧杯），数出滴数，算出一滴溶液的体积，再乘以溶液中油酸的体积分数（浓度）
6. 测油膜的面积：在浅盘的水面上均匀地撒一层爽身粉，滴入一滴溶液，待油膜形状稳定后把玻璃板放在浅盘上描下轮廓；数出轮廓内的方格数，不足半格的舍去，多于半格的算一格，乘以每格的面积
7. 计算与结果：由 d = V/S 算出分子直径，注意统一单位；分子直径的数量级为 10⁻¹⁰ m，本实验只是估测，重在数量级
8. 误差来源：爽身粉撒得太厚，油膜不能充分展开，面积偏小、直径偏大；油膜形状未稳定就描轮廓，面积不准；数滴数时多数了，每滴体积偏小、直径偏小；溶液久置酒精挥发，浓度变大而仍按原浓度计算，直径偏小
9. 易错提醒：d = V/S 中的 V 是一滴溶液中纯油酸的体积，不是一滴溶液的体积，误用会使结果偏大很多

### WLF-22　选必3 2.2 探究等温情况下一定质量气体压强与体积的关系（9 个考点）⬜
先修：WLD-03、WLF-01
1. 实验目的：探究温度不变时，一定质量的气体的压强与体积的关系
2. 研究对象与方法：研究对象是注射器内被封闭的一段空气柱；用控制变量法，保持气体的质量和温度不变，研究压强 p 与体积 V 的关系
3. 器材及作用：注射器下端的开口用橡胶套封住，与柱塞一起封闭一段空气柱；与空气柱相连的压力表显示气体压强；注射器上的刻度读出空气柱的长度，体积等于长度乘以横截面积
4. 保证气体质量不变：柱塞上涂润滑油，使注射器密封良好、防止漏气；实验过程中不能拔下橡胶套
5. 保证气体温度不变：缓慢地推、拉柱塞；不用手握住注射器封有气体的部分；改变体积后稍等片刻，待压力表示数稳定再读数
6. 测量：推、拉柱塞改变空气柱的长度，记录多组空气柱长度和对应的压强；空气柱的横截面积不变，可以用长度代替体积，不必测横截面积
7. 数据处理：作 p-V 图像得到一条曲线，不易直接判断 p 与 V 的关系；改作 p-1/V 图像，各点在一条过原点的直线上，说明压强与体积的倒数成正比
8. 误差来源：漏气使气体质量减少，推拉过快或手握注射器使温度变化；若 p-1/V 图线的后段向下弯曲，说明漏气或温度降低，向上弯曲说明温度升高；读数时视线与刻度垂直可减小读数误差
9. 实验结论：在误差允许的范围内，一定质量的气体在温度不变时，压强与体积成反比，即 pV 为常量，这就是玻意耳定律（→ WLD-03）
