## 各期考点

**A1 运动的描述**（WLA-01～WLA-05）

### WLA-01　必一 1.1、1.2 质点、参考系、时间与位移（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/a-mechanics/projects/wla-01`
先修：—（系列起点）
1. 物理学的研究方法：实验与科学推理相结合；突出主要因素、忽略次要因素，建立理想化的物理模型
2. 质点：用来代替物体的有质量的点，是理想化模型；能否看成质点取决于物体的大小和形状对所研究的问题影响能否忽略
3. 参考系：描述运动时选来作为参考的物体；选不同的参考系，对同一运动的描述可能不同；通常选地面
4. 坐标系：为了定量描述物体的位置及其变化，在参考系上建立坐标系；直线运动用一维坐标轴
5. 时刻与时间间隔：在时间轴上分别对应点和线段；“第 3 s 末”是时刻，“第 3 s 内”“前 3 s”是时间间隔
6. 位移与路程：位移是由初位置指向末位置的有向线段，是矢量；路程是轨迹的长度，是标量；只有单向直线运动中位移大小才等于路程
7. 矢量与标量：矢量既有大小又有方向，标量只有大小；直线运动中矢量的正负表示方向，不表示大小
8. 直线运动的位置和位移：位移 Δx = x2 − x1；位移—时间图像（x-t 图像）表示位置随时间的变化，不是运动轨迹（→ WLA-05）

### WLA-02　必一 1.3、1.4 速度与加速度（8 个考点）⬜
先修：WLA-01
1. 速度 v = Δx/Δt：用位移与时间之比定义（比值定义法）；单位 m/s；速度是矢量，方向就是物体运动的方向
2. 平均速度与瞬时速度：平均速度对应一段时间或一段位移；Δt 非常小时的平均速度可以看作瞬时速度（极限思想）
3. 速率：瞬时速度的大小叫速率；平均速率 = 路程/时间，一般不等于平均速度的大小
4. 速度—时间图像（v-t 图像）：直观表示速度随时间的变化；匀速直线运动的 v-t 图像是平行于时间轴的直线
5. 加速度 a = Δv/Δt：描述速度变化的快慢，即速度的变化率；单位 m/s²；是矢量
6. 加速度的方向：与速度变化量 Δv 的方向相同；直线运动中 a 与 v 同向时加速，反向时减速
7. 从 v-t 图像看加速度：图线的斜率表示加速度；图线是曲线时，某点切线的斜率表示该时刻的加速度（→ WLA-05）
8. 概念辨析：速度、速度变化量、加速度三者没有必然联系；速度很大时加速度可以为 0，速度为 0 时加速度可以不为 0

### WLA-03　必一 2.2、2.3 匀变速直线运动的规律（8 个考点）⬜
先修：WLA-02
1. 匀变速直线运动：沿着一条直线且加速度不变的运动；v-t 图像是一条倾斜的直线；分为匀加速和匀减速
2. 速度与时间的关系 v = v0 + at：由加速度的定义式变形得到
3. 位移与时间的关系 x = v0t + ½at²：由 v-t 图线与时间轴所围的面积得出（把过程无限细分再累加的微元思想）
4. 速度与位移的关系 v² − v0² = 2ax：由前两式消去时间 t 得到
5. 公式的矢量性：v0、v、a、x 都是矢量，使用前先规定正方向（通常取 v0 的方向），结果的正负表示方向
6. 平均速度：匀变速直线运动中，一段时间内的平均速度等于 (v0 + v)/2，也等于这段时间中间时刻的瞬时速度
7. 连续相等时间 T 内的位移之差是恒量：Δx = aT²，是判断物体是否做匀变速直线运动的依据
8. 初速度为 0 的匀加速直线运动：v 与 t 成正比，x 与 t² 成正比

### WLA-04　必一 2.4 自由落体运动与竖直上抛运动（9 个考点）⬜
先修：WLA-03
1. 亚里士多德的观点：重的物体下落得快；伽利略用逻辑推理（轻、重两物体绑在一起下落）指出其中的矛盾
2. 自由落体运动：物体只在重力作用下从静止开始下落的运动；空气阻力可以忽略时，物体的下落可近似看作自由落体运动
3. 运动性质：自由落体运动是初速度为 0 的匀加速直线运动（可用频闪照相或打点计时器研究）；同一地点轻重物体下落一样快
4. 自由落体加速度 g：方向竖直向下；同一地点一切物体的 g 相同；不同地点一般不同，随纬度升高而增大；一般取 9.8 m/s²
5. 自由落体运动的规律：v = gt，h = ½gt²，v² = 2gh；匀变速直线运动的规律和推论都适用
6. 伽利略的研究过程：猜想 v 与 t 成正比 → 数学推理得 x 与 t² 成正比 → 用斜面“冲淡”重力验证 → 合理外推到竖直下落
7. 伽利略的科学方法：把实验和逻辑推理（包括数学推演）和谐地结合起来，开创了近代物理学的研究方法；近代实验科学由此兴起，研究自然从思辨转向实验和测量
8. 竖直上抛运动（教材正文未单列，按匀变速直线运动的规律理解）：只受重力，全程加速度为 g；取向上为正，v = v0 − gt，h = v0t − ½gt²
9. 竖直上抛的对称性：上升和下降经过同一位置时速度大小相等、方向相反，上升与下降时间相等

### WLA-05　必一 第1、2章 运动图像（8 个考点）⬜
先修：WLA-02、WLA-03
1. 图像中的物理量：坐标轴表示的物理量和单位，以及图线的斜率、面积、截距、交点，各有确定的物理意义
2. x-t 图像的斜率：表示速度；静止时图线平行于时间轴，匀速直线运动时是倾斜直线，变速运动时是曲线
3. x-t 图像的截距与交点：纵截距表示初始位置；两条图线的交点表示两物体在同一时刻位于同一位置
4. v-t 图像的斜率：表示加速度；匀速直线运动是平行于时间轴的直线，匀变速直线运动是倾斜直线
5. v-t 图像的面积：图线与时间轴所围的面积表示位移，时间轴上方为正、下方为负；两条图线的交点表示速度相同
6. a-t 图像：图线与时间轴所围的面积表示速度的变化量 Δv；匀变速直线运动的 a-t 图像是平行于时间轴的直线
7. 运动方向的变化：v-t 图线穿过时间轴时速度反向；x-t 图线的斜率由正变负（或相反）时速度反向
8. 概念辨析：x-t、v-t 图像只能描述直线运动，图线不是运动轨迹；图线是曲线表示变速，不表示物体做曲线运动

**A2 相互作用**（WLA-06～WLA-10）

### WLA-06　必一 3.1 重力与弹力（8 个考点）⬜
先修：WLA-01
1. 力：物体与物体之间的相互作用；单位牛顿（N）；力的三要素是大小、方向和作用点；可用力的图示或力的示意图表示
2. 重力：由于地球的吸引而使物体受到的力，G = mg，方向竖直向下
3. 重心：物体各部分受到的重力的等效作用点；位置与物体的形状和质量分布有关，可以不在物体上；薄板的重心可用悬挂法确定
4. 弹性形变与弹力：发生形变的物体由于要恢复原状，对与它接触的物体产生的力；产生条件是直接接触并发生弹性形变
5. 微小形变的观察：桌面、玻璃瓶等的形变很小，可借助光的反射或细管中液面的变化把形变放大显示
6. 弹力的方向：压力和支持力垂直于接触面，指向被压或被支持的物体；绳的拉力沿着绳指向绳收缩的方向
7. 胡克定律 F = kx：在弹性限度内，弹力与形变量成正比；x 是形变量而不是弹簧长度；劲度系数 k 由弹簧本身决定，单位 N/m
8. 概念辨析：弹力是施力物体发生形变产生的，书对桌面的压力是书的形变引起的，桌面对书的支持力是桌面的形变引起的

### WLA-07　必一 3.2 摩擦力（7 个考点）⬜
先修：WLA-06
1. 摩擦力：两个相互接触的物体发生相对运动或具有相对运动趋势时，在接触面上产生阻碍相对运动或相对运动趋势的力
2. 产生条件：接触面粗糙、相互挤压（有弹力）、有相对运动或相对运动趋势；有摩擦力一定有弹力，有弹力不一定有摩擦力
3. 滑动摩擦力的方向：沿着接触面，与物体相对于接触物的运动方向相反
4. 滑动摩擦力的大小 Ff = μFN：FN 是压力，不一定等于重力；动摩擦因数 μ 与接触面的材料和粗糙程度有关，没有单位
5. 静摩擦力：相对静止但有相对运动趋势时产生；方向沿接触面，与相对运动趋势的方向相反
6. 静摩擦力的大小：随外力变化，0 < F ≤ Fmax，不能用 μFN 计算；最大静摩擦力略大于滑动摩擦力，粗略计算时可认为相等
7. 概念辨析：摩擦力阻碍的是“相对”运动，方向可以与物体的运动方向相同，可以是动力；运动的物体可以受静摩擦力

### WLA-08　必一 3.3 牛顿第三定律与受力分析（8 个考点）⬜
先修：WLA-07
1. 作用力和反作用力：力的作用是相互的，两个物体之间的这一对力叫作用力和反作用力
2. 牛顿第三定律：两个物体之间的作用力和反作用力总是大小相等、方向相反，作用在同一条直线上
3. 实验依据：两个弹簧测力计（或力传感器）对拉，示数总是相等，且同时变化
4. 作用力与反作用力的特点：同时产生、同时变化、同时消失，性质相同，分别作用在两个物体上，效果不能抵消
5. 普遍性：牛顿第三定律与物体的运动状态无关，物体静止、匀速或加速时都成立
6. 概念辨析：一对相互作用力作用在两个物体上，一对平衡力作用在同一物体上；平衡力的性质不一定相同
7. 受力分析：先分析重力，再在研究对象与其他物体接触处分析弹力和摩擦力，最后分析其他力，画出受力示意图
8. 受力分析的原则：只分析研究对象受到的力；每个力都能找到施力物体；不另画“合力”“下滑力”等按效果命名的力

### WLA-09　必一 3.4 力的合成和分解（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/a-mechanics/projects/wla-09`
先修：WLA-08
1. 合力与分力：一个力单独作用的效果与几个力共同作用的效果相同，这个力叫那几个力的合力，是等效替代关系
2. 共点力：作用在物体的同一点，或作用线（延长线）交于一点的几个力
3. 平行四边形定则：以表示两个分力的线段为邻边作平行四边形，对角线表示合力
4. 合力的大小范围：|F1 − F2| ≤ F ≤ F1 + F2；两分力夹角越大合力越小；合力可以大于、等于或小于分力
5. 力的分解：力的分解是力的合成的逆运算，同样遵从平行四边形定则；不加限制时一个力可分解为无数对分力
6. 按实际需要分解：常按力的作用效果分解，如斜面上物体的重力分解为沿斜面和垂直斜面的两个分力
7. 正交分解：把力沿两个相互垂直的方向分解，F 在两个方向的分力为 F cosθ 和 F sinθ
8. 矢量和标量：矢量相加遵从平行四边形定则（三角形定则：两矢量首尾相接，从起点指向终点），标量相加遵从算术法则

### WLA-10　必一 3.5 共点力的平衡（7 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/a-mechanics/projects/wla-10`
先修：WLA-09
1. 平衡状态：物体受到几个力作用时，保持静止或匀速直线运动的状态，此时加速度为 0
2. 平衡条件：在共点力作用下物体平衡的条件是合力为 0
3. 平衡条件的分量形式：把各力正交分解，x 方向合力为 0，y 方向合力也为 0
4. 二力平衡与三力平衡：二力平衡时两力等大反向；三力平衡时任意两个力的合力与第三个力等大反向
5. 三力平衡的矢量关系：三个力的矢量首尾依次相接，组成封闭的三角形
6. 多力平衡：任意一个力与其余各力的合力等大反向；几个物体组成的系统保持平衡时，系统所受外力的合力也为 0
7. 概念辨析：速度为 0 不等于处于平衡状态，竖直上抛的物体到达最高点时速度为 0，但合力不为 0

**A3 牛顿运动定律**（WLA-11～WLA-13）

### WLA-11　必一 4.1 牛顿第一定律（8 个考点）⬜
先修：WLA-08
1. 亚里士多德的观点：必须有力作用在物体上，物体才能运动，没有力的作用物体就要静止
2. 伽利略的理想斜面实验：在可靠事实的基础上合理外推，得出若没有摩擦，运动的物体将以恒定速度一直运动下去
3. 笛卡儿的补充：如果运动中的物体不受力的作用，它将继续以同一速度沿同一直线运动，既不停下来也不偏离原来的方向
4. 牛顿第一定律：一切物体总保持匀速直线运动状态或静止状态，除非作用在它上面的力迫使它改变这种状态
5. 定律的地位：描述的是不受力的理想情况，不能用实验直接验证；它是在实验基础上经过推理概括得出的
6. 力和运动的关系：力不是维持物体运动的原因，而是改变物体运动状态的原因
7. 惯性：物体保持原来匀速直线运动状态或静止状态的性质，牛顿第一定律又叫惯性定律；质量是惯性大小的唯一量度
8. 概念辨析：惯性是物体的固有属性，不是力，与物体的速度、是否受力无关，不能说“受到惯性作用”

### WLA-12　必一 4.3、4.4 牛顿第二定律与力学单位制（8 个考点）⬜
先修：WLA-09、WLA-11
1. 牛顿第二定律：物体加速度的大小跟它受到的作用力成正比、跟它的质量成反比，加速度的方向跟作用力的方向相同
2. 表达式 F = ma：F 是物体所受的合力；取 1 N = 1 kg·m/s² 时比例系数 k = 1
3. 矢量性：加速度的方向总与合力的方向相同；可写成分量形式 Fx = max、Fy = may
4. 瞬时性：加速度与合力同时产生、同时变化、同时消失
5. 概念辨析：a = Δv/Δt 是加速度的定义式，a = F/m 表明加速度由合力和质量决定
6. 单位制：基本量的单位叫基本单位，由基本量根据物理关系推导出来的量的单位叫导出单位，二者组成单位制
7. 国际单位制：有七个基本单位；力学中的基本量是长度、质量、时间，基本单位是 m、kg、s；N、J、m/s 等是导出单位
8. 单位制的作用：计算时各量统一用国际单位，结果也是国际单位；可以根据单位检查物理关系式是否可能正确

### WLA-13　必一 4.5、4.6 牛顿运动定律的应用与超重、失重（8 个考点）⬜
先修：WLA-03、WLA-12
1. 力和运动的联系：加速度是联系物体受力情况和运动情况的桥梁
2. 两类基本问题：由受力情况确定运动情况，由运动情况确定受力情况；都要用到牛顿第二定律和运动学规律
3. 实重与视重：物体对支持物的压力或对悬挂物的拉力（测力计示数）叫视重；超重、失重时物体的重力并没有变化
4. 超重：物体对支持物的压力（或对悬挂物的拉力）大于物体所受重力的现象；加速度方向向上，加速上升或减速下降
5. 失重：物体对支持物的压力（或对悬挂物的拉力）小于物体所受重力的现象；加速度方向向下，加速下降或减速上升
6. 完全失重：物体向下的加速度等于 g 时，对支持物完全没有压力；绕地球运行的航天器中的物体处于完全失重状态，与重力有关的现象消失
7. 生活中的超重和失重：站在力传感器上下蹲时先失重后超重，站起时先超重后失重；电梯起动、制动时也会出现
8. 概念辨析：超重还是失重只由加速度的方向决定，与速度的方向无关

### WLA-14　必二 5.1、5.2 曲线运动与运动的合成与分解（8 个考点）⬜
先修：WLA-02、WLA-09
1. 曲线运动的速度方向：质点在某一点的速度方向沿曲线在这一点的切线方向；速度方向时刻改变，曲线运动一定是变速运动
2. 物体做曲线运动的条件：所受合力（加速度）的方向与它的速度方向不在同一条直线上
3. 合力与轨迹的关系：轨迹夹在速度方向与合力方向之间，合力指向轨迹弯曲的内侧（凹侧）
4. 合力对速率的影响：合力与速度夹角为锐角时速率增大，为钝角时速率减小，始终垂直时速率不变
5. 合运动与分运动：物体实际发生的运动是合运动；分运动同时进行、各自独立，互不影响
6. 运动的合成与分解：位移、速度、加速度都是矢量，它们的合成与分解都遵从平行四边形定则
7. 教材实例（蜡块的运动）：蜡块沿玻璃管匀速上升，玻璃管同时水平匀速移动，蜡块的合运动是匀速直线运动，轨迹为 y = (vy/vx)x
8. 概念辨析：合运动是直线还是曲线，看合初速度与合加速度是否共线；两个匀速直线运动的合运动仍是匀速直线运动，变速运动不一定是曲线运动

### WLA-15　必二 5.4 抛体运动的规律（9 个考点）⬜
先修：WLA-04、WLA-14
1. 抛体运动：以一定速度抛出、忽略空气阻力、只受重力作用的运动；加速度恒为 g，是匀变速曲线运动
2. 平抛运动：初速度沿水平方向的抛体运动；可分解为水平方向的匀速直线运动和竖直方向的自由落体运动
3. 平抛运动的速度：vx = v0，vy = gt，合速度 v = √(v0² + vy²)，与水平方向的夹角 θ 满足 tanθ = gt/v0
4. 平抛运动的位移：x = v0t，y = ½gt²，位移与水平方向的夹角 α 满足 tanα = gt/2v0
5. 平抛运动的轨迹：消去 t 得 y = gx²/2v0²，轨迹是一条抛物线
6. 飞行时间与水平射程：t = √(2h/g) 只由下落高度决定；水平射程 x = v0√(2h/g) 由初速度和高度共同决定
7. 速度的变化：加速度恒为 g，任意相等时间内速度的变化量 Δv = gΔt 相同，方向竖直向下
8. 一般的抛体运动（斜抛）：初速度与水平方向成 θ 角，水平方向做匀速直线运动 vx = v0cosθ，竖直方向做初速度为 v0sinθ、加速度为 g 的匀变速运动
9. 概念辨析：斜抛运动到最高点时竖直分速度为 0，但速度不为 0（等于 v0cosθ），加速度仍为 g

### WLA-16　必二 6.1、6.3 圆周运动与向心加速度（9 个考点）⬜
先修：WLA-14
1. 匀速圆周运动：线速度大小处处相等的圆周运动；线速度方向时刻改变，是变速运动，而且加速度方向也在变，是变加速运动
2. 线速度 v = Δs/Δt：Δs 是 Δt 内通过的弧长；线速度方向沿圆周在该点的切线方向
3. 角速度 ω = Δθ/Δt：Δθ 是半径转过的角度，用弧度制；单位是弧度每秒，符号 rad/s
4. 周期与转速：周期 T 是转一周所用的时间；转速 n 是单位时间转过的圈数，单位 r/s 或 r/min
5. 各量的关系：v = ωr，ω = 2π/T，v = 2πr/T；转速以 r/s 为单位时 ω = 2πn
6. 传动中的规律：同一转动物体上各点角速度相同；皮带、链条、齿轮传动不打滑时，轮缘上各点线速度大小相等
7. 向心加速度：做匀速圆周运动的物体加速度指向圆心；它只改变速度的方向，不改变速度的大小
8. 向心加速度的大小：an = v²/r = ω²r = ωv；【教材拓展】也可以由速度变化量 Δv 的矢量关系推导出来
9. 概念辨析：an 与 r 是正比还是反比要看前提，线速度一定时 an 与 r 成反比，角速度一定时 an 与 r 成正比

### WLA-17　必二 6.2、6.4 向心力与生活中的圆周运动（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/a-mechanics/projects/wla-17`
先修：WLA-13、WLA-16
1. 向心力：做匀速圆周运动的物体所受的指向圆心的合力，Fn = mv²/r = mω²r；向心力是按效果命名的力
2. 向心力的来源：可以是重力、弹力、摩擦力中的某一个力，也可以是几个力的合力或某个力的分力；受力分析时不另画向心力
3. 变速圆周运动：合力不指向圆心，可分解为指向圆心的分力 Fn（改变速度方向）和沿切线的分力 Ft（改变速度大小）
4. 一般的曲线运动：可以把曲线分成许多很短的小段，每一小段看作一小段圆弧，用圆周运动的方法分析
5. 火车转弯：弯道处外轨略高于内轨，以规定速度行驶时由重力和支持力的合力提供向心力，v0 = √(gr tanθ)；速度过大挤压外轨，过小挤压内轨
6. 汽车过拱形桥与凹形路面：拱形桥最高点 mg − FN = mv²/r，压力小于重力，v = √(gr) 时压力为 0；凹形路面最低点压力大于重力
7. 航天器中的失重现象：绕地球做匀速圆周运动的航天器中，地球引力全部用来提供向心力，航天员对座椅的压力为 0，处于完全失重状态
8. 离心运动：合力突然消失或不足以提供所需的向心力时，物体沿切线飞出或逐渐远离圆心；应用有洗衣机脱水筒，危害要防止（如转弯限速）；并不存在“离心力”

### WLA-18　必二 7.1、7.2 行星的运动与万有引力定律（9 个考点）⬜

1. 两种学说：地心说认为地球是宇宙的中心，日心说（哥白尼）认为太阳是中心；开普勒在第谷观测数据的基础上总结出行星运动规律
2. 开普勒第一定律：所有行星绕太阳运动的轨道都是椭圆，太阳处在椭圆的一个焦点上
3. 开普勒第二定律：对任意一个行星来说，它与太阳的连线在相等的时间内扫过的面积相等；因此行星在近日点速率大，远日点速率小
4. 开普勒第三定律：所有行星轨道的半长轴的三次方跟公转周期的二次方的比都相等，a³/T² = k；k 只与中心天体有关
5. 行星运动的近似处理：多数行星轨道接近圆，可看作以太阳为圆心的匀速圆周运动，a 取轨道半径
6. 太阳与行星间的引力：由向心力公式和开普勒第三定律得 F ∝ m/r²，再由牛顿第三定律得 F ∝ Mm/r²
7. 月—地检验：月球绕地球的向心加速度约为地面重力加速度的 1/60²，说明地面物体所受引力与天体间的引力遵从相同的规律
8. 万有引力定律：F = Gm1m2/r²，r 是两质点间的距离；质量分布均匀的球体，r 取两球心间的距离
9. 引力常量与定律的意义：卡文迪什用扭秤实验测出 G ≈ 6.67×10⁻¹¹ N·m²/kg²；万有引力定律第一次揭示了天上和地上的物体遵从同一规律

### WLA-19　必二 7.3 万有引力理论的成就（9 个考点）⬜
先修：WLA-18
1. 万有引力与重力：若不考虑地球自转，地面上物体所受重力等于地球对它的引力，mg = GMm/R²
2. 地球自转的影响：万有引力的一部分提供物体随地球自转的向心力，重力略小于万有引力，两极处二者相等，赤道处差别最大，但都很小
3. 重力加速度随高度变化：离地面高 h 处 g′ = GM/(R + h)²，高度越大 g′ 越小

6. 天体的密度：由求出的中心天体质量和它的体积，可以得到天体的平均密度 ρ = M/(4πR³/3)
7. 发现未知天体：海王星是先根据万有引力定律计算出轨道、再观测发现的，被称为“笔尖下发现的行星”
8. 预言彗星回归：哈雷用牛顿的引力理论计算彗星轨道，预言了它的回归，后来得到证实
9. 概念辨析：根据环绕天体的运动求出的是中心天体的质量，不能求出环绕天体自身的质量

### WLA-21　必二 8.1 功与功率（8 个考点）⬜
先修：WLA-09、WLA-12
1. 做功的两个要素：作用在物体上的力，物体在力的方向上发生的位移
2. 功的公式 W = Fl cosα：α 是力与位移的夹角；功是标量，是过程量，单位焦耳，1 J = 1 N·m
3. 正功和负功：0 ≤ α < 90° 时做正功，90° < α ≤ 180° 时做负功（也说物体克服这个力做功），α = 90° 时不做功；正负不表示方向
4. 总功：几个力对物体做的总功，等于各个力分别对物体做功的代数和，也等于这几个力的合力对物体做的功
5. 功率 P = W/t：表示做功快慢的物理量，单位瓦特（W）；额定功率是动力机械长时间正常工作的最大功率，实际功率可以小于额定功率；常见机械的功率差别很大，人体约百瓦量级，汽车约几十千瓦，高铁列车可达上万千瓦
6. 功率与速度 P = Fv：F 与 v 同向；v 是平均速度时 P 是平均功率，v 是瞬时速度时 P 是瞬时功率
7. 功率一定时 F 与 v 成反比：汽车发动机功率一定时，上坡需要较大牵引力，司机换低速挡减小速度
8. 概念辨析：摩擦力不一定做负功，静摩擦力和滑动摩擦力都可以做正功、做负功或不做功

### WLA-22　必二 8.2 重力势能与弹性势能（8 个考点）⬜
先修：WLA-21
1. 重力做功的特点：只跟物体运动的起点和终点的位置（高度差）有关，跟运动路径无关，WG = mgh1 − mgh2
2. 重力势能 Ep = mgh：h 是物体相对参考平面的高度；是标量，单位焦耳
3. 重力做功与重力势能变化的关系：WG = Ep1 − Ep2；重力做正功，重力势能减少；重力做负功，重力势能增加
4. 重力势能的相对性：数值与参考平面的选取有关，在参考平面下方时为负值；但重力势能的变化量与参考平面的选取无关
5. 重力势能的系统性：重力势能是地球与物体所组成的系统共有的
6. 弹性势能：发生弹性形变的物体的各部分之间，由于有弹力的相互作用而具有的势能
7. 弹性势能的大小：弹簧的弹性势能与形变量和劲度系数有关，形变量越大、劲度系数越大，弹性势能越大
8. 弹力做功与弹性势能变化：弹力做正功，弹性势能减少；弹力做负功，弹性势能增加；【教材拓展】弹力做的功可由 F-x 图线下的面积求得

### WLA-23　必二 8.3 动能和动能定理（8 个考点）⬜
先修：WLA-03、WLA-21
1. 动能表达式的得出：恒力 F 使物体在光滑水平面上由 v1 加速到 v2，由 W = Fl、牛顿第二定律和运动学公式得 W = ½mv2² − ½mv1²
2. 动能 Ek = ½mv²：物体由于运动而具有的能量；是标量，没有负值，单位焦耳
3. 动能是状态量：对应某一时刻的速度；速度方向改变而大小不变时动能不变（如匀速圆周运动）
4. 动能定理：力在一个过程中对物体做的功，等于物体在这个过程中动能的变化，W = Ek2 − Ek1
5. 动能定理中的 W：是合力做的功，即各个力做功的代数和
6. 适用范围：由恒力、直线运动推得，对变力做功和曲线运动同样适用
7. 物理意义：合力做正功，动能增加；合力做负功，动能减少；合力做的功是动能变化的量度
8. 概念辨析：动能定理是标量式，不能在某个方向上分别列式；速度和位移一般都相对地面

### WLA-24　必二 8.4 机械能守恒定律与能量守恒（9 个考点）⬜
先修：WLA-22、WLA-23
1. 追寻守恒量：伽利略的斜面实验中，小球总能回到与出发点几乎同样的高度，说明有某个量是守恒的
2. 机械能：动能、重力势能和弹性势能统称为机械能；通过重力或弹力做功，动能与势能可以相互转化
3. 机械能守恒定律：在只有重力或弹力做功的物体系统内，动能与势能可以互相转化，而总的机械能保持不变
4. 定律的推导：只有重力做功时，由动能定理 WG = Ek2 − Ek1 和 WG = Ep1 − Ep2 得 Ek1 + Ep1 = Ek2 + Ep2
5. 概念辨析：“只有重力或弹力做功”不等于“只受重力或弹力”，其他力不做功或做功代数和为 0 时机械能也守恒
6. 功是能量转化的量度：合力做功对应动能的变化，重力做功对应重力势能的变化，弹力做功对应弹性势能的变化
7. 机械能的变化：除重力和弹力以外的其他力做的功等于机械能的变化，做正功机械能增加，做负功机械能减少
8. 能量的转化：有摩擦等阻力做功时，机械能转化为内能等其他形式的能，机械能减少，但总能量守恒（→ WLD-06）
9. 能量守恒定律：能量既不会凭空产生，也不会凭空消失，只能从一种形式转化为另一种形式，或从一个物体转移到别的物体，总量保持不变（→ WLD-06）

### WLA-25　选必1 1.1、1.2 动量、冲量与动量定理（9 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/a-mechanics/projects/wla-25`
先修：WLA-12、WLA-23
1. 动量概念的提出：在碰撞实验中寻找“不变量”，发现两物体碰撞前后质量与速度的乘积之和保持不变，于是把 mv 定义为动量
2. 动量 p = mv：单位 kg·m/s；矢量，方向与速度的方向相同；是状态量
3. 动量的变化量 Δp = p′ − p：矢量运算，同一直线上规定正方向后化为代数运算；Δp 的方向与速度变化量的方向相同
4. 概念辨析 动量与动能：动量是矢量，动能是标量，Ek = p²/2m；动量变化时动能不一定变化，动能变化时动量一定变化
5. 冲量 I = FΔt：单位 N·s；矢量，恒力的冲量方向与力的方向相同；是过程量，表示力对时间的累积效应，与物体是否运动无关
6. 变力的冲量：F-t 图线与时间轴所围的面积表示冲量；也可以由动量定理通过动量的变化量求出
7. 动量定理：由牛顿第二定律和运动学公式推出 FΔt = mv′ − mv；物体在一个过程中所受合力的冲量等于它在这个过程始末的动量变化量
8. 动量定理的意义：F = Δp/Δt，合力等于动量的变化率；它是矢量式，可以在某一方向上使用；对变力同样成立，F 为平均作用力
9. 用动量定理解释现象：动量变化量一定时，作用时间越长作用力越小（安全气囊、跳远的沙坑、包装用的泡沫塑料）；作用时间越短作用力越大

### WLA-26　选必1 1.3 动量守恒定律（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/a-mechanics/projects/wla-26`
先修：WLA-08、WLA-25
1. 系统、内力和外力：相互作用的几个物体组成系统；系统中物体间的相互作用力叫内力，系统以外的物体施加的力叫外力
2. 定律的推导：两物体相互作用时，由牛顿第三定律和动量定理得 m1v1 + m2v2 = m1v1′ + m2v2′；内力只在系统内转移动量，不改变总动量
3. 动量守恒定律：如果一个系统不受外力，或者所受外力的矢量和为 0，这个系统的总动量保持不变
4. 近似守恒与分方向守恒：内力远大于外力时（如碰撞、爆炸）系统动量近似守恒；某一方向上外力的矢量和为 0 时，该方向上的动量守恒
5. 表达式的含义：矢量式，各速度相对同一参考系（通常是地面）；“守恒”指过程中任意两个时刻系统的总动量都相等
6. 概念辨析 动量守恒与机械能守恒：前者的条件是外力的矢量和为 0，后者的条件是只有重力或弹力做功；一个守恒时另一个不一定守恒
7. 与牛顿运动定律的关系：在牛顿运动定律适用的范围内可以由它推出；动量守恒定律只涉及过程的始末状态，不必考虑相互作用力的细节
8. 动量守恒定律的普适性：牛顿运动定律只适用于宏观、低速的情形，动量守恒定律在高速（接近光速）和微观领域依然成立，是自然界普遍适用的基本规律之一

### WLA-27　选必1 1.5 弹性碰撞和非弹性碰撞（8 个考点）⬜
先修：WLA-24、WLA-26
1. 碰撞的特点：作用时间极短，内力远大于外力，系统动量守恒；碰撞过程中物体的位移可以忽略
2. 按能量分类：碰撞前后系统动能不变的是弹性碰撞；动能有损失的是非弹性碰撞，损失的动能转化为内能等
3. 完全非弹性碰撞：碰后两物体结合在一起以共同速度运动，m1v1 + m2v2 = (m1 + m2)v，系统动能的损失最大
4. 弹性正碰（v2 = 0）的结果：由动量守恒和动能守恒得 v1′ = (m1 − m2)v1/(m1 + m2)，v2′ = 2m1v1/(m1 + m2)
5. 对结果的讨论：m1 = m2 时两球交换速度；m1 > m2 时两球都向前运动；m1 < m2 时入射球反弹；m1 远小于 m2 时入射球几乎以原速率弹回
6. 碰撞的特点：作用时间极短，内力远大于外力，系统动量守恒；碰撞过程中系统的总动能不会增加
7. 对心碰撞与非对心碰撞：碰前速度沿两球球心连线的是正碰，否则是斜碰；斜碰后速度不在同一直线上，动量守恒仍按矢量成立
8. 散射：微观粒子相互接近时不一定发生接触，这种“碰撞”叫散射；核反应堆中用慢化剂使中子减速利用的也是碰撞规律（→ WLE-09）

### WLA-28　选必1 1.6 反冲现象与火箭（8 个考点）⬜
先修：WLA-26
1. 反冲现象：一个物体在内力作用下分成两部分，一部分向某一方向运动，另一部分必然向相反方向运动
2. 反冲遵循动量守恒：内力远大于外力，系统动量守恒；原来静止时 0 = m1v1 + m2v2，两部分速度方向相反
3. 反冲中的能量：化学能、弹性势能等其他形式的能转化为机械能，系统的总动能增加
4. 爆炸：内力远大于外力，动量近似守恒；化学能转化为动能，总动能增加；与反冲的本质相同
5. 反冲的应用与防止：农田的喷灌装置自动旋转、章鱼和乌贼喷水前进是利用反冲；射击时枪身后坐，要把枪托抵在肩部以减小反冲的影响
6. 火箭的原理：燃料燃烧产生的高温高压燃气以很大的速度向后喷出，火箭获得向前的反冲速度；在没有空气的太空中同样可以加速
7. 影响火箭速度的因素：喷气速度和质量比（火箭开始飞行时的质量与燃料燃尽时的质量之比）；喷气速度越大、质量比越大，火箭获得的速度越大
8. 火箭的发展：我国古代已发明利用火药燃气反冲的火箭；现代运载火箭多采用多级结构，并用于发射卫星和载人飞船

### WLA-29　选必1 2.1、2.2 简谐运动及其描述（9 个考点）⬜
先修：WLA-05、WLA-16
1. 机械振动：物体在平衡位置附近的往复运动；平衡位置是振动物体原来静止时的位置
2. 弹簧振子：小球和弹簧组成的系统，是理想化模型（小球看成质点，忽略弹簧质量和摩擦）
3. 振子的位移—时间图像：用频闪照相或让振子带笔在匀速移动的纸带上描迹得到；位移从平衡位置指向振子所在的位置
4. 简谐运动：质点的位移与时间的关系遵从正弦函数的规律，x-t 图像是正弦曲线；它是最简单、最基本的振动
5. 振幅、周期和频率：振幅 A 是离开平衡位置的最大距离，表示振动的强弱；完成一次全振动的时间为周期 T，f = 1/T；一个周期内路程为 4A
6. 周期与振幅无关：简谐运动的周期（频率）由振动系统本身决定，与振幅无关
7. 表达式 x = A sin(ωt + φ)：ω = 2π/T = 2πf 叫圆频率；(ωt + φ) 叫相位，φ 是初相
8. 相位差：两个同频率简谐运动的相位差 Δφ = φ2 − φ1，表示振动步调的差异；Δφ = 0 时步调一致，Δφ = π 时步调相反
9. 从 x-t 图像获得信息：振幅、周期、任一时刻的位移；图线上某点切线的斜率表示该时刻的速度

### WLA-30　选必1 2.3 简谐运动的回复力和能量（8 个考点）⬜
先修：WLA-12、WLA-29
1. 回复力：使振动物体回到平衡位置的力，方向总是指向平衡位置；按效果命名，可以由一个力、几个力的合力或某个力的分力提供
2. 简谐运动的动力学特征：F = −kx；物体所受的力与它偏离平衡位置的位移大小成正比且总指向平衡位置，物体就做简谐运动；k 不一定是劲度系数
3. 加速度 a = −kx/m：大小与位移成正比，方向与位移相反；简谐运动是加速度不断变化的变加速运动
4. 竖直弹簧振子：平衡位置在弹力与重力相等处，回复力是弹力与重力的合力，以平衡位置为原点时仍满足 F = −kx
5. 各量随位置的变化：远离平衡位置时位移、回复力、加速度增大，速度减小；在平衡位置速度最大、加速度为 0，在最大位移处速度为 0、加速度最大
6. 能量的转化：振动中动能和势能相互转化；在平衡位置动能最大，在最大位移处势能最大
7. 机械能守恒：不计阻力时简谐运动的机械能守恒；振动的能量与振幅有关，振幅越大，能量越大
8. 概念辨析 速度与位移的方向：加速度总与位移反向，速度与位移可以同向也可以反向，取决于振子正在远离还是靠近平衡位置

### WLA-31　选必1 2.4 单摆（8 个考点）⬜
先修：WLA-17、WLA-30
1. 单摆模型：细线的质量和伸缩可以忽略，小球的直径比线长小得多；是理想化模型
2. 单摆的回复力：重力沿圆弧切线方向的分力 F = −mg sinθ；摆线拉力与重力沿摆线方向分力的合力提供向心力
3. 小角度近似：摆角很小时 sinθ ≈ x/l，回复力 F = −(mg/l)x，单摆的运动可看作简谐运动
4. 概念辨析 回复力与合力：摆球经过最低点时回复力为 0，但合力不为 0（提供向心力），最低点不是平衡状态
5. 科学史：伽利略发现了单摆运动的等时性；惠更斯确定了单摆的周期公式，并利用等时性发明了摆钟
6. 周期公式 T = 2π√(l/g)：摆长 l 是悬点到摆球球心的距离；周期只由摆长和当地的重力加速度决定，与振幅（小摆角时）和摆球质量无关
7. 摆钟：利用单摆的等时性计时；改变摆长可以调整摆钟走时的快慢
8. 单摆的能量：摆动中重力势能和动能相互转化，不计阻力时机械能守恒；摆球在最低点速度最大

### WLA-32　选必1 2.6 受迫振动与共振（8 个考点）⬜
先修：WLA-30
1. 固有振动与固有频率：振动系统不受外力作用时的振动叫固有振动，其频率叫固有频率，由系统本身决定
2. 阻尼振动：系统受到阻力，机械能逐渐转化为内能等，振幅逐渐减小的振动
3. 驱动力与受迫振动：作用于振动系统的周期性外力叫驱动力，系统在驱动力作用下的振动叫受迫振动
4. 受迫振动的频率：稳定后等于驱动力的频率，与系统的固有频率无关
5. 共振：驱动力的频率等于系统的固有频率时，受迫振动的振幅最大，这种现象叫共振
6. 共振曲线：横轴为驱动力频率，纵轴为振幅；驱动力频率越接近固有频率振幅越大，峰值处 f驱 = f固
7. 共振的应用：需要利用共振时，使驱动力的频率接近或等于固有频率，如共振筛、乐器的共鸣箱
8. 共振的防止：需要防止共振时，使驱动力的频率远离固有频率，如部队过桥便步走、火车过桥减速、机器转速避开机座的固有频率
