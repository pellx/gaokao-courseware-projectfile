**C1 机械波**（WLC-01～WLC-02）

### WLC-01　选必1 3.1、3.2 机械波的形成与描述（9 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/c-waves-and-light/projects/wlc-01`
先修：WLA-29
1. 波的形成：波源振动带动相邻质点振动，相邻质点依次带动下去，振动由近及远传播；各质点开始振动的方向与波源开始振动的方向相同
2. 机械波：机械振动在介质中的传播；产生机械波需要波源和介质
3. 波传递的是什么：传播的是振动这种运动形式，同时传递能量和信息；介质中的质点只在各自平衡位置附近振动，不随波迁移
4. 横波和纵波：质点振动方向与传播方向垂直的是横波，有波峰和波谷；在同一直线上的是纵波，有密部和疏部；声波是纵波，地震波既有横波也有纵波
5. 波的图像：横轴表示各质点的平衡位置，纵轴表示某一时刻各质点偏离平衡位置的位移；简谐波的图像是正弦曲线
6. 波长、周期和波速：波长 λ 是在振动中相位总相同的两个相邻质点间的距离；一个周期内波传播一个波长，v = λ/T = λf
7. 各量由什么决定：频率由波源决定，波速由介质决定，波长由两者共同决定；波从一种介质进入另一种介质时频率不变
8. 质点振动方向与波的传播方向：沿传播方向，后面的质点重复前面质点的振动，所以由波形和传播方向可以确定各质点的振动方向，反之亦然
9. 概念辨析 振动图像与波的图像：振动图像描述一个质点的位移随时间的变化，横轴是时间，可读出周期；波的图像描述某一时刻各质点的位移，横轴是位置，可读出波长

### WLC-02　选必1 3.3～3.5 波的反射、折射、衍射、干涉与多普勒效应（10 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/c-waves-and-light/projects/wlc-02`
先修：WLC-01
1. 波的反射：波遇到障碍物会返回原介质继续传播，反射角等于入射角；反射波的频率、波速和波长不变；回声是声波的反射
2. 波的折射：波从一种介质进入另一种介质时传播方向发生改变；频率不变，波速和波长改变
3. 波的衍射：波可以绕过障碍物继续传播；一切波都能发生衍射，“闻其声而不见其人”是声波的衍射
4. 发生明显衍射的条件：缝、孔的宽度或障碍物的尺寸跟波长相差不多，或者比波长更小；条件不满足时衍射依然存在，只是不明显
5. 波的叠加：几列波相遇后仍保持各自的运动特征继续传播；在重叠区域，质点的位移等于几列波单独传播时引起的位移的矢量和
6. 波的干涉：频率相同、相位差恒定、振动方向相同的两列波叠加，振动加强区和减弱区相互间隔且位置稳定；干涉和衍射都是波特有的现象
7. 加强点和减弱点（两波源振动步调相同）：到两波源的路程差为波长的整数倍时加强，振幅为 A1 + A2；为半波长的奇数倍时减弱，振幅为 |A1 − A2|
8. 概念辨析 加强点的位移：加强点仍在做振动，位移随时间变化，某些时刻为 0；“加强”指的是振幅最大，而不是位移始终最大
9. 多普勒效应：波源与观察者相互靠近时，观察者接收到的频率变大；相互远离时变小；波源本身的频率并没有改变；由奥地利物理学家多普勒首先发现
10. 多普勒效应的应用：交通中测量车辆速度，医学上用“彩超”测血流速度，天文学上由星体光谱线的移动测定星体相对地球的运动速度

**C2 光的折射与全反射**（WLC-03～WLC-04）

### WLC-03　选必1 4.1 光的折射（9 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/c-waves-and-light/projects/wlc-03`
先修：WLC-02
1. 光的反射和折射：光射到两种介质的分界面时，一部分光返回原介质发生反射，一部分光进入另一种介质发生折射
2. 折射定律：折射光线与入射光线、法线在同一平面内，折射光线与入射光线分别位于法线两侧；入射角的正弦与折射角的正弦成正比，sinθ1/sinθ2 = n12
3. 折射率：光从真空射入某种介质时，入射角的正弦与折射角的正弦之比 n = sinθ1/sinθ2，反映介质的光学性质
4. n = c/v：光在介质中的速度 v = c/n；光在真空中的速度最大，任何介质的折射率都大于 1
5. 光路可逆：在折射现象中光路是可逆的；光从介质射入空气时，折射角大于入射角
6. 光进入介质后的变化：频率不变，速度变小，波长变短，λ = λ0/n
7. 不同色光的折射率：同一种介质对不同色光的折射率不同，对紫光最大、对红光最小，紫光在介质中的速度较小；白光经三棱镜分解为彩色光带
8. 两面平行的玻璃砖与三棱镜：光通过平行玻璃砖后出射光线与入射光线平行但发生侧移；光通过三棱镜后向底边偏折
9. 生活中的折射现象：从水面上方看水中的物体，位置比实际的浅；插入水中的筷子看起来向上弯折

### WLC-04　选必1 4.2 全反射（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/c-waves-and-light/projects/wlc-04`
先修：WLC-03
1. 光疏介质与光密介质：两种介质相比，折射率较小的叫光疏介质，较大的叫光密介质；这是相对的概念，与介质的密度不是一回事
2. 全反射现象：光从光密介质射向光疏介质，入射角增大时折射角随之增大，折射光越来越弱、反射光越来越强，入射角达到某一角度时折射光完全消失
3. 临界角：折射角为 90° 时对应的入射角；光从介质射入空气（真空）时 sinC = 1/n，折射率越大，临界角越小
4. 发生全反射的条件：光从光密介质射入光疏介质；入射角等于或大于临界角
5. 全反射棱镜：截面为等腰直角三角形的玻璃棱镜，可使光的传播方向改变 90° 或 180°；全反射时几乎没有能量损失，比平面镜反射效果好
6. 光导纤维的工作原理：光纤由内芯和外套两层组成，内芯的折射率比外套的大，光在内芯与外套的界面上不断发生全反射，从一端传到另一端
7. 光纤的应用：光纤通信传输容量大、衰减小、抗干扰能力强；医学上用光导纤维制成内窥镜，观察人体内部器官
8. 生活中的全反射：水中或玻璃中的气泡看起来特别明亮，是光射到气泡表面时发生了全反射

**C3 光的干涉、衍射和偏振**（WLC-05～WLC-06）

### WLC-05　选必1 4.3 光的干涉（8 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/c-waves-and-light/projects/wlc-05`
先修：WLC-02、WLC-03
1. 杨氏双缝干涉实验：1801 年托马斯·杨成功观察到光的干涉现象，证明光是一种波
2. 相干光源：频率相同、相位差恒定、振动方向相同；实验中让同一束光通过双缝，得到两个相干光源
3. 亮条纹和暗条纹的条件：屏上某点到两缝的路程差等于波长的整数倍时出现亮条纹，等于半波长的奇数倍时出现暗条纹
4. 条纹间距 Δx = lλ/d：l 为双缝到屏的距离，d 为双缝间距
5. 干涉图样的特点：单色光的干涉条纹是等间距的明暗相间条纹；白光的干涉条纹是彩色的，中央为白色亮条纹
6. 光的颜色与波长：光的颜色由频率决定；红光波长最长、紫光最短，波长越长，干涉条纹间距越大
7. 薄膜干涉：薄膜前、后两个表面的反射光叠加形成干涉；竖直放置的肥皂膜上薄下厚，形成水平的条纹，白光照射时呈彩色
8. 薄膜干涉的应用：检查光学元件表面是否平整；在镜头等光学元件表面镀膜，增加透射光或反射光

### WLC-06　选必1 4.5、4.6 光的衍射、偏振与激光（10 个考点）🛠
工程：`~/gaokao-courseware-projectfile/physics/c-waves-and-light/projects/wlc-06`
先修：WLC-05
1. 光的衍射：光通过很窄的缝或很小的孔时，绕过缝或孔的边缘传播到相当宽的地方；障碍物或孔的尺寸与光的波长相差不多或比波长小时，衍射十分明显
2. 单缝衍射图样：中央亮条纹最宽最亮，两侧条纹变窄变暗；缝越窄、波长越长，中央亮条纹越宽；白光的衍射条纹是彩色的
3. 圆孔衍射和圆盘衍射：圆孔衍射图样是明暗相间的圆环；不透光圆盘的阴影中心出现亮斑（泊松亮斑），它的出现有力支持了光的波动说
4. 衍射光栅：由许多等宽、等间距的狭缝组成，衍射条纹又窄又亮，可用于分析光谱
5. 概念辨析 干涉与衍射图样：双缝干涉条纹等间距、亮度基本相同；单缝衍射条纹中央宽而亮，两侧窄而暗，间距不等
6. 衍射的意义：衍射现象说明“光沿直线传播”只是近似规律；光的干涉和衍射说明光具有波动性
7. 光的偏振：自然光在垂直于传播方向的平面内沿一切方向振动；通过偏振片后只剩下沿透振方向振动的光，成为偏振光；两偏振片透振方向垂直时光不能通过
8. 光是横波：只有横波才能发生偏振，光的偏振现象说明光是横波；自然光在水面、玻璃表面反射和折射时，反射光和折射光都是偏振光
9. 偏振的应用：照相机镜头前加偏振滤光片减弱反射光、立体电影、液晶显示
10. 激光的特性和应用：激光是人工产生的相干光；相干性好，可用于光纤通信、全息照相；平行度好，可用于精确测距、读取光盘；亮度高，可用于切割、焊接，医学上用作“光刀”

**C4 电磁振荡与电磁波**（WLC-07～WLC-08）

### WLC-07　选必2 4.1 电磁振荡（8 个考点）⬜
先修：WLB-06、WLB-19
1. 振荡电流与振荡电路：大小和方向都做周期性迅速变化的电流叫振荡电流；由线圈 L 和电容器 C 组成的 LC 电路是最简单的振荡电路
2. 放电过程：电容器放电，电荷量减少、电流增大，电场能转化为磁场能；放电完毕时电荷量为 0，电流和磁场能最大
3. 充电过程：线圈的自感作用使电流继续流动并逐渐减小，给电容器反向充电，磁场能转化为电场能；充电完毕时电流为 0
4. 电磁振荡：电路中的电荷、电流以及与之相联系的电场和磁场周期性相互转化的现象
5. 同步变化的物理量：电荷量、板间电压、电场强度、电场能同步变化；电流、线圈中的磁感应强度、磁场能同步变化；一组最大时另一组为 0
6. 周期和频率：T = 2π√(LC)，f = 1/(2π√(LC))，叫固有周期和固有频率；改变 L 或 C 可以改变振荡频率
7. 阻尼振荡与无阻尼振荡：电路有电阻发热、又向外辐射电磁波，振幅逐渐减小；适时补充能量可得到振幅不变的等幅振荡
8. 振荡图像：从电容器充满电开始放电时计时，q 随时间按余弦规律变化，i 按正弦规律变化

### WLC-08　必三 13.4，选必2 4.2～4.4 电磁场与电磁波（10 个考点）⬜
先修：WLC-01、WLC-07
1. 麦克斯韦电磁场理论：变化的磁场产生电场，变化的电场产生磁场；周期性变化的电场和磁场相互联系，形成不可分割的电磁场
2. 电磁波的预言与证实：麦克斯韦预言电磁波并指出光是电磁波；赫兹用实验证实了电磁波的存在，测得其速度等于光速；电磁场理论把电、磁、光统一起来，体现了场的统一性与多样性
3. 电磁波的特点：横波，电场、磁场与传播方向两两垂直；传播不需要介质；真空中速度 c = 3.0×10⁸ m/s，c = λf；能发生反射、折射、干涉、衍射
4. 电磁波的能量：电磁场是一种物质，电磁波具有能量，能传递能量和信息，例如微波炉加热食物、阳光使地面升温
5. 无线电波的发射：振荡频率要足够高，电路要开放；把信号加到频率很高的载波上叫调制，分调幅（AM）和调频（FM）
6. 无线电波的接收：接收电路固有频率与电磁波频率相同时产生电谐振，使电路产生电谐振的过程叫调谐；从接收到的振荡电流中还原出信号叫解调
7. 电磁波谱：按波长由长到短为无线电波、红外线、可见光、紫外线、X 射线、γ 射线
8. 各波段的特征与应用：无线电波用于通信和广播，微波用于雷达和微波炉；红外线热作用强，用于遥感和测温；紫外线能杀菌消毒、使荧光物质发光
9. X 射线与 γ 射线：X 射线穿透力强，用于医学透视和安检；γ 射线能量很高、穿透力更强，用于治疗肿瘤和工业探伤
10. 电磁波的应用及其影响：广播电视、移动通信、卫星导航、雷达等改变了人类的生活；过量电磁辐射危害健康，电磁波也会形成电磁污染
