本期考点

一、电功（W = UIt，静电力做功，电能转化为其他形式的能；1 kW·h = 3.6×10⁶ J）
二、电功率（P = W/t = UI，表示做功快慢）
三、焦耳定律（Q = I²Rt，热功率 P热 = I²R）
四、纯电阻电路（W = Q，P = UI = I²R = U²/R）
五、非纯电阻电路（UI > I²R，欧姆定律不适用）
六、电动机的能量转化（P出 = UI − I²r，η = P出/P入）
七、额定功率与实际功率（实际功率随实际电压改变）
八、家庭电路与安全用电（并联；短路、过载导线过热，装保险装置；节约用电）
